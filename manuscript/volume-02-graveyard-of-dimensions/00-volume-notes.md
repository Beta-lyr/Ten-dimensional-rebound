## 第01章《余波中的整数》

- **文件**：`manuscript/volume-02-graveyard-of-dimensions/ch-001-integers-in-the-aftermath.md`
- **主视角**：弥娅（新宇宙宇宙学家）
- **时间线 / 空间状态**：新宇宙 / N-D01 / S9
- **字数**：约 4,503 字（符合 4,500—7,000 区间）
- **五场景**：整数残差 → 事件簇检验 → 三类解释 → 公开边界 → 多源终态
- **落点**：序列中三个"8"被聚类为彼此无关事件（H-2 权重矩阵）；盲化事件簇检验 M3 确认三个 S8 终态事件簇为独立事件（间隔/损失权重/形状均不同，压缩伪影与仪器饱和解释被排除）；自然相变解释保留；弥娅撤回"战争标题"摘要、开放分类参数、只公开可复核统计问题——**"是否存在独立成核源"**；三组 S8 终态指纹归档，多源成核检验建立，第二卷新宇宙线从证明存在转向重建历史。
- **伏笔**：多个形状不同但终态相同的成核标记预示旧宇宙技术已出现独立实现路线（第5章维因确认事故资料成为工程基准、第10章两类箭头）。
- **约束合规**：未确认回声计划/量子反弹/维因记录/第三层实验见证；未把整数直接等同于战争年表（"维度战争"仅是否定语境）；未出现旧宇宙人物清晰声音；自然解释通过实质检验。
- **下承**：第02章《第二种装置》承接“技术扩散不再依赖单一数据库”。

## 第02章《第二种装置》

- **文件**：`manuscript/volume-02-graveyard-of-dimensions/ch-002-the-second-apparatus.md`
- **主视角**：独立复现工程师珂（接力配角）— 旧宇宙线 / O-C01 / 外部 S9、局部 S8
- **字数**：约 5,001 字（符合 5,000—8,000 区间）
- **五场景**：异构装置 → 独立标定 → 临界逼近 → 提交顺序 → 同一缺口
- **落点**：从未接触边界工程图纸的文明以自身相变计量体系重建装置（无 VAC 模块/配方/控制顺序）；十二组交换标定（材料/尺度/控制顺序）全部收敛到事故同一维度模场缺口——技术扩散不依赖原图纸；三重停机在临界线前触发，独立路线证明到临界线为止；珂先向本文明安全机构提交完整校准、对外只广播不可逆风险与终态指纹；**第二种装置证明技术扩散不再依赖单一数据库，冻结协议失去核心执行基础**。
- **伏笔**：该文明保留的设备差异成为弥娅识别"多源成核"的证据（第1章事件簇获得真实来源）；"校准速度/部署规模"成为唯一可限制项（第20章独立推导更强回收）。
- **约束合规**：未以间谍/秘密授权/维因秘密授权解释复现；未出现成熟可部署武器或远程投送装置；维因未参与实验；成核仅为临界线前验证（未真实成核）；工程师选择制造信息不对称。
- **下承**：第03章《禁入带》承接“第二种装置证明技术扩散不再依赖单一数据库，冻结协议失去核心执行基础”。

- **时间线 / 空间状态**：旧宇宙线 / O-C02 / S9 中存在扩张 S8 区（正文未点名"旧宇宙"）
- **字数**：约 5,014 字（符合 5,000—8,000 区间）

- **落点**：维因审查"无人目标"禁入带计划（联径节点/资源区/战略交叉路径）；蒙特卡洛可达集追踪暴露资源区/联径节点/生态区环境损失；"有限"被定义为启动权限与目标坐标，维因以泡壁可达集反驳；拒绝成核参数但共享泡壁观测与撤离窗口表（统一共享不选择性）；无上限环境损失附录写入审批表——正文伤亡为零、附录损失无上限；计划在附录阴影下通过；**受威胁文明获得更准确预警，但行动方也能从公开模型改进投放位置——防御共享与制造辅助纠缠**。

- **约束合规**：未让维因拥有否决所有文明的权力（"否决"仅否定语境）；未把行动方写成嗜战反派（进攻威胁真实）；未出现泡壁可被普通屏障停止；维因仍未转向删除知识。
- **下承**：第04章《有限投放》承接“受威胁文明获得更准确的泡壁预警，但行动方也能从公开模型改进投放位置”。

## 第04章《有限投放》

- **文件**：`manuscript/volume-02-graveyard-of-dimensions/ch-004-limited-deployment.md`
- **主视角**：战略交通协调者塔兰（接力配角）— 旧宇宙线 / O-C03 / S9→局部 S8
- **字数**：约 5,043 字（符合 5,000—8,000 区间）
- **五场景**：到达窗口 → 常规封锁 → 投放授权 → 真实路径 → 资源区失向
- **落点**：敌方舰队通过时间早于增援、常规封锁被高维绕行；三方案（等待增援/摧毁节点/低维投放）同一时钟演算——唯一按时的方案把战术胜利延长为环境灾难；**第一次主动战略投放发生**：无人交通交叉点成核、舰队被阻断（无交火），但泡壁继续进入三个邻接资源区；塔兰先启动资源区撤离再投放、发布公开责任广播（不伪装为敌方攻击）、记录资源区失向与断供传导；低维技术正式进入战略计划，"有限投放"成为可复制术语。
- **伏笔**：主动投放"成功"使文明相信降维可被管理（第8章应用于自身核心区、第36—39章演化为先发制人）；"事故区→隔离带→…→防御性低维相"语言链延续。
- **约束合规**：未让行动方预测全部扩张后果（泡壁进入资源区超出预期）；未把行动写成纯粹邪恶或毫无替代压力（进攻威胁真实、三方案均无无损解）；未把泡写成可远程关停（"远程关停"仅否定语境）；责任广播未掩盖资源区损失；协调者未被塑造成无辜执行者（主动记录责任）。
- **下承**：第05章《基准事故》承接“低维技术正式进入战略计划，其他文明开始把成核能力纳入威慑和预案”。

- **主视角**：维因（真空工程师，旧宇宙线）— 正文不得称本线为"旧宇宙"
- **时间线 / 空间状态**：旧宇宙线 / O-C03 / S9 与多处 S8 区（正文未点名"旧宇宙"）
- **字数**：约 5,021 字（符合 5,000—8,000 区间）
- **五场景**：扩散证据 → 工程基准 → 冻结争议 → 防御联盟 → 多路线收敛
- **落点**：三份装置报告无共同零件却都引用事故广播风险曲线——**第一次事故从警告变成工程基准**（警告与教材同源）；对照计算显示公开资料减少 20—60 次试错；冻结协议因第二例独立复现而失去执行基础（仅剩信念型文明维持）；维因选择继续提供 DEF-01 预警与泡壁观测、删除授权书"制造"一词、不参与新成核装置设计、签下双重用途个人责任；跨文明防御研究启动——获得比任何单一复现团队更完整的真空相数据集。

- **约束合规**：未让维因突然主张全面销毁知识；未把复制归因于一份泄露图纸；未提前制造 S7；DEF-01 明确只提供预警而非阻挡；维因仍相信可把后续工作限制在防御端（尚未认定必然武器化）。
- **下承**：第06章《泡壁之前》承接“跨文明防御研究正式启动，同时获得比任何单一复现团队更完整的真空相数据”（第二阶段：防御性降维）。
