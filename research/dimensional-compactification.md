# 第一部分　紧致化的含义

## 1. 维度并非只能“存在”或“不存在”

一个空间方向可以：

- 在宏观尺度展开；
- 具有有限且很小的周期尺度；
- 具有复杂紧致几何；
- 在不同位置具有不同有效尺度；
- 通过模量场表现为动态自由度。

对低能观察者而言，当紧致半径 `R` 足够小时，沿该方向运动所需的激发能量很高，于是该方向在日常尺度上不可访问。

项目中的“维度消失”应解释为：

> 一个原本宏观展开的空间方向进入低能不可访问的微观紧致态。

不得解释成：

- 坐标轴从数学上被删除；
- 空间被普通机械压力压扁；
- 物质被投影到屏幕；
- 时间维度同时消失。

## 2. Kaluza–Klein 模式

以圆形紧致维度为最简单示意，沿紧致方向的动量被量子化：

```text
p_n = n / R
```

低维观察者会把这些激发看作质量更大的 Kaluza–Klein 模式，示意关系为：

```text
m_n² = m_0² + n² / R²
```

当 `R` 很小时：

- 高阶模式很重；
- 低能过程只能看到零模；
- 额外维度表现为不可访问。

**小说接口：**

- 低维区域内部仍可存在高能残余模式；
- 普通生命和设备无法利用接近普朗克尺度的方向；
- 高维结构丢失不是“所有坐标数值归零”，而是可用模态和连接消失。

# 第二部分　模量与稳定

## 3. 紧致维度尺度是物理自由度

紧致空间的：

- 尺度；
- 形状；
- 扭曲；
- 通量；
- 拓扑；

通常对应低维有效理论中的标量自由度，统称模量。

如果模量没有稳定：

- 紧致尺度可能漂移；
- 有效物理常数变化；
- 低能粒子谱变化；
- 真空可能不稳定。

项目使用“维度模场”作为对控制宏观方向展开尺度的统一叙事术语。

它不是现实理论中的唯一标准场，也不应与某个具体字符串模量完全等同。

## 4. 模量稳定需要势能结构

稳定额外维度通常需要：

- 通量；
- 曲率；
- 量子修正；
- 膜或边界条件；
- 体标量场；
- 非微扰效应；
- 多种机制组合。

因此，本项目中的宏观空间方向不能无代价维持。

可以推导：

- 高维文明需要持续计量维度模态；
- 大型真空工程会改变局部稳定条件；
- 不同文明可能使用不同稳定实现；
- 一个方向发生紧致化会连带改变材料与粒子谱。

## 5. 重新展开不是简单反向操作

若一个维度已紧致化，要恢复宏观展开，需要：

- 改变模量势；
- 使区域越过势垒；
- 重新建立正确的真空态；
- 处理物质在缺失方向上的结构；
- 恢复拓扑与量子关联。

即使真空几何可以改变，已被破坏的复杂物质结构也不会自动复原。

这支持 Canon 中：

- 理论上不宣布绝对数学禁止；
- 工程上宏观不可逆；
- 量子反弹的重新展开属于宇宙整体新初态，不是文明对旧区域的恢复。

# 第三部分　局部紧致化与边界

## 6. 空间依赖的紧致状态

项目允许同一宇宙中存在：

- 外部 `S9` 真空；
- 内部 `S8` 真空；
- 二者之间的域壁或泡壁。

现实理论中，不同真空之间的过渡可由场配置和域壁描述；具体是否能对应“少一个宏观方向”取决于完整高维理论。

这是 B 层到 C 层的外推。

## 7. 维度取向不是绝对宇宙坐标轴

局部紧致化可以选择某个本征方向或方向组合。

这意味着：

- 不同泡的紧致取向可以不同；
- 泡相遇时可能产生复杂缺陷；
- 低维文明无法简单说“宇宙的第七轴被删除”；
- 空间方向名称只能是局部坐标约定。

## 8. 泡壁不是实体薄膜

泡壁应描写为：

- 场值快速变化区域；
- 有限厚度的过渡层；
- 模态谱发生重排的区域；
- 应力—能量和曲率可能集中之处。

不得写成可以用普通材料碰撞、切割或钻孔的机械壳。

# 第四部分　现实实验状态

## 9. 尚无额外维度发现

额外维度搜索包括：

- 碰撞机中的 Kaluza–Klein 激发或缺失能量；
- 引力定律短程偏离；
- 天体物理和宇宙学约束；
- 特定膜世界或扭曲几何信号。

截至核验日期，没有确认发现额外空间维度。

因此：

- 小说中的九个宏观空间维度属于 C 层；
- 现实三维世界中的额外维度若存在，通常被设想为紧致、扭曲或受限；
- 不能用“弦理论已经证明有十维”作为现实定论。

# 第五部分　正文约束

## 10. 可安全使用

- 额外维度可在低能尺度上因紧致化而不可见；
- 紧致尺度与形状可由动态模量描述；
- 稳定模量是额外维度理论的核心难题；
- 尺度变化会改变低能谱和有效常数；
- 真空过渡可形成域壁或泡状区域。

## 11. 必须标为小说公设

- 九个空间维度原本全部宏观展开；
- 文明能够选择单个宏观本征方向紧致化；
- 紧致化区域自动形成可扩张低维泡；
- 宇宙反弹后所有宏观方向重新展开；
- 多次降维依次形成稳定 `S8` 至 `S3` 宇宙环境。

## 12. 禁止误写

- “紧致化就是把一张纸卷起来，所以所有物体也像纸一样卷曲。”
- “方向消失后物体只会变薄，其他物理不变。”
- “模量稳定意味着可以随时调节维度且没有代价。”
- “弦理论已经确认现实存在六个紧致空间维度。”
- “量子反弹把旧物质沿紧致维度重新拉开即可复原。”
