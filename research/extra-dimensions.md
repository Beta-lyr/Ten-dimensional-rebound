# 第一部分　基础定义

## 1. 空间维度是独立位置自由度

在 `d` 个空间维度中，一个点需要 `d` 个独立空间坐标描述。

额外空间维度不是：

- 平行世界；
- 灵界；
- 额外时间；
- 观察层级；
- 意识维度；
- 数学抽象自动具有的物理实体。

项目中的完整十维时空：

```text
9个宏观空间维度 + 1个时间维度
```

“十维宇宙”不能在正文中被误写为十个空间维度。

## 2. 高维并不自动打破因果

在高维时空中：

- 局部光锥仍可定义；
- 信号仍沿时空路径传播；
- 额外方向可能提供更短测地线；
- 低维投影可能产生“看似超光速”的到达时间。

这不等于局部速度超过光速。

正文应区分：

```text
路径比低维投影短
≠
沿完整路径超光速
```

## 3. 遮挡与封闭

高维观察者可以绕过只在低维截面闭合的边界，但真正高维闭合体仍然存在。

因此：

- 高维建筑可以有内部和外部；
- 封闭成本随维数上升；
- 隐藏需要在更多方向控制信号；
- 高维观察者并非天然全知。

# 第二部分　力律与几何后果

## 4. 高维高斯定律示意

若场线在 `d` 个宏观空间维度中均匀扩散，包围面积随半径约为：

```text
A(r) ∝ r^(d-1)
```

点源场强通常示意为：

```text
F(r) ∝ 1 / r^(d-1)
```

在 `d > 2` 时，相应势能常具有：

```text
V(r) ∝ 1 / r^(d-2)
```

直接把三维电磁和引力推广到更多宏观维度，会显著改变：

- 原子束缚；
- 行星轨道；
- 散射；
- 热平衡；
- 星体结构。

这也是高维生命不能简单使用地球化学的原因。

## 5. 力律可以因场局域化而不同

高维理论未必要求所有场都在全部维度传播。

可能存在：

- 某些场局域在膜上；
- 引力进入体空间；
- 紧致化使远距离恢复三维有效力律；
- 不同尺度表现不同维数。

项目若要让 `S9` 生命稳定，必须采用 C 层公设：

> 高维真空和物质场结构共同产生可支持复杂束缚态的有效相互作用，而不是把三维库仑势和牛顿势机械推广到九维。

## 6. 高维拓扑直觉

高维空间可能允许：

- 绕过低维结；
- 多个结构中心不在低维投影中接触却在高维相连；
- 复杂管道互不相交；
- 更多独立旋转平面；
- 更高连接度的交通网络。

但这些优势伴随：

- 隐藏困难；
- 边界面积和控制复杂度上升；
- 身体与建筑连接数增加；
- 降维时大量拓扑连接突然失效。

# 第三部分　实验状态

## 7. 额外维度仍是假说

现实搜索尚未确认：

- Kaluza–Klein 粒子塔；
- 大额外维度；
- 扭曲额外维度；
- 微观黑洞作为额外维度证据；
- 短程引力偏离的确定信号。

因此：

- 不能写“现实科学已知宇宙其实有九个空间维度”；
- 可以写“若某类理论成立，额外维度可能紧致或局域化”；
- 研究笔记必须持续跟踪 PDG 和主要实验结果。

# 第四部分　小说接口

## 8. 高维交通

项目允许高维文明使用更短测地线和预建网络。

必须保留：

- 路径测绘；
- 节点稳定；
- 带宽；
- 延迟；
- 故障；
- 维度下降后节点永久失效。

高维交通不是任意瞬移。

## 9. 高维通信

允许：

- 使用高维路径缩短信号距离；
- 多节点中继；
- 不同模态编码。

禁止：

- 无载体瞬时通信；
- 量子纠缠超光速传信；
- 跨宇宙实时对话；
- 直接读取其他文明内部数据库。

## 10. 降维后的物理变化

每失去一个宏观方向，除几何路径外，还可能改变：

- 场模式；
- 粒子谱；
- 材料稳定性；
- 计算连接；
- 生命结构；
- 热输运；
- 社会网络。

正文不得只描写视觉变薄。

# 第五部分　正文约束

## 11. 可安全使用

- 额外维度会改变几何、力律和可用路径；
- 紧致维度在低能下可能不可见；
- 不同场可以具有不同有效维数；
- 高维封闭需要在全部方向闭合；
- 高维不等于全知或超因果。

## 12. 必须标为小说公设

- `S9` 物质具有稳定复杂化学；
- 高维生命能够长期演化；
- 高维交通网络在宇宙尺度成熟；
- 每次人工紧致化只减少一个宏观空间自由度。

## 13. 禁止误写

- “高维文明能看到人体所有内部，所以能读取思想。”
- “多一个维度就能进入任意上锁空间。”
- “高维运动等于瞬移。”
- “额外维度是另一个宇宙。”
- “所有高维生物天然比低维生物聪明。”
