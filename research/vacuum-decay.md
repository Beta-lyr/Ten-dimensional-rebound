# 第一部分　真空的物理含义

## 1. 真空不是“什么都没有”

量子场论中的真空是场的最低或局部稳定状态。

不同真空可能具有不同：

- 场期望值；
- 能量密度；
- 对称性；
- 粒子谱；
- 相互作用常数；
- 紧致化几何。

因此真空相变可能改变物质存在的基本条件。

## 2. 真真空与假真空

若某状态是局部能量最低点，但不是全局最低点，它可称为假真空或亚稳真空。

它可能通过量子隧穿衰变。

半经典衰变率常写成示意形式：

```text
Γ / V ≈ A exp(-B / ħ)
```

其中：

- `B` 与欧氏反弹解作用量有关；
- `A` 是涨落前因子；
- 具体数值取决于势能、场和引力。

不得把衰变率当作一个所有真空通用常数。

# 第二部分　泡成核

## 3. 临界泡

一个低能真空泡同时受到：

- 内外真空能差推动；
- 泡壁表面张力阻止。

小于临界尺度的泡可能坍缩。

超过临界尺度的泡可能扩张。

项目中第一次实验的关键误判可以来自：

- 低估临界尺度；
- 忽略额外模态；
- 有限区域测量无法捕捉慢不稳定；
- 关闭设备后泡已进入自持区。

## 4. 泡壁

泡壁是场从一种真空过渡到另一种真空的区域。

具有：

- 有限厚度；
- 能量密度；
- 应力；
- 可能的曲率耦合；
- 模式转换。

普通物质屏障无法像挡住弹体一样挡住真空相变。

## 5. 扩张速度

在许多相对论性真空相变模型中，泡壁可迅速加速并接近光速。

但其精确速度取决于：

- 场势；
- 引力；
- 与等离子体或物质的摩擦；
- 能量释放方式；
- 泡壁结构。

Canon 固定低维泡扩张接近但不超过局部光速，是 C 层具体化。

# 第三部分　引力影响

## 6. Coleman–De Luccia 机制

引力可能：

- 改变成核率；
- 改变临界半径；
- 抑制某些衰变；
- 改变泡内外几何；
- 产生视界和因果结构效应。

因此正文中的真空工程必须同时使用：

- 场模型；
- 曲率测量；
- 引力背景；
- 边界条件。

不能只计算普通势垒。

## 7. 不同真空并非简单高低能排序

在引力中：

- 真空能符号重要；
- de Sitter、Minkowski、AdS 具有不同因果结构；
- 高曲率修正可能改变结论；
- 某些跃迁受到禁止或极度抑制。

项目固定“低维真空能级低于外部”，但不应在正文中推导为所有紧致化必然如此。

# 第四部分　紧致维度相关不稳定

## 8. Bubble of Nothing

某些具有紧致维度的理论中，紧致圆可以在泡内平滑收缩到零，形成“无之泡”不稳定。

它与本项目低维真空泡不同：

| Bubble of Nothing | 低维真空泡 |
|---|---|
| 可能意味着时空区域终止 | 内部仍是较低宏观维数时空 |
| 依赖特定紧致几何和边界条件 | 由文明人工调制维度模场 |
| 不一定留下可生存低维内部 | 内部可形成 `S8` 至 `S3` 环境 |
| 现实理论研究对象 | 小说 C 层机制 |

不得直接把两者等同。

# 第五部分　低维泡外推

## 9. 项目机制映射

现实原型：

```text
亚稳真空
→ 量子或受激成核
→ 临界泡
→ 域壁
→ 自发扩张
```

小说外推：

```text
宏观展开维度由维度模场维持
→ 文明调制局部模场
→ 一个方向进入紧致态
→ 形成低维真空泡
→ 超临界后自动扩张
→ 泡内物质失去一个宏观自由度
```

## 10. 为什么传统武器无效

传统武器改变：

- 物质；
- 辐射；
- 局部温度；
- 局部曲率。

低维泡由真空场边界驱动。

除非武器能够重塑相关真空势和边界条件，否则：

- 爆炸不会恢复外部真空；
- 能量束可能反而增加扰动；
- 普通引力牵引不能拖走泡壁；
- 物质护盾无法承受相变边界。

## 11. 防御为何需要更低维相

这是小说公设中的固定困境。

写作时可解释为：

- 同层真空结构无法为泡壁提供稳定终止边界；
- 更低维相改变局部势能和允许的域壁连接；
- 泡传播路径被引导或闭合；
- 代价是生成新的更低维区域。

不得宣称这是 Coleman–De Luccia 理论的现实结论。

# 第六部分　实验和观测

## 12. 可观测量

可能包括：

- 真空涨落谱变化；
- 维度模态质量变化；
- 域壁应力；
- 局部曲率；
- 粒子传播自由度减少；
- 泡内外信号色散差异；
- 泡壁位置和速度。

第三卷遥远异常只应提供这些间接观测，不提供内部摄像式信号。

## 13. 中止边界

实验设备关闭只会停止外部驱动。

如果泡已超临界：

- 不保证停止；
- 可能继续依靠真空能差扩张；
- 中止窗口早于可见灾难窗口。

这是第一卷和第三卷事故共同的科学核心。

# 第七部分　正文约束

## 14. 可安全使用

- 假真空可通过泡成核衰变；
- 临界尺度决定泡坍缩或扩张；
- 泡壁是场过渡区，不是普通材料；
- 引力会改变真空衰变；
- 超临界泡可能自持扩张。

## 15. 必须标为小说公设

- 低维真空与一个空间方向紧致化直接对应；
- 文明能够工程触发；
- 泡壁宏观扩张必然不可逆；
- 更低维相可用于改变传播路径；
- 连续泡最终将宇宙降至 `S3`。

## 16. 禁止误写

- “真空泡就是没有空气的球。”
- “用足够强炸弹可以炸碎泡壁。”
- “所有真空泡都必然以光速扩张。”
- “真空能更低就一定意味着泡扩张。”
- “Bubble of Nothing 就是二维化武器。”
