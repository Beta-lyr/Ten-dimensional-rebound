# 第一部分　反弹的定义

## 1. 反弹不是普通爆炸

宇宙反弹指尺度因子从收缩转向膨胀的动力学过程。

它不同于：

- 物质在已有空间中爆炸；
- 某个中心向外喷射；
- 文明启动的设备；
- 时间倒流；
- 旧宇宙从同一状态重新播放。

在均匀宇宙模型中，反弹时常满足：

```text
H = 0
```

并从 `H < 0` 的收缩阶段转为 `H > 0` 的膨胀阶段。

## 2. 经典广义相对论的困难

在普通能量条件下，经典宇宙收缩可能走向奇点。

非奇点反弹通常需要：

- 量子引力修正；
- 特殊物质或有效负压；
- 修改引力；
- 高阶曲率；
- 膜碰撞或额外维度机制；
- 其他违反经典假设的效应。

没有一个机制被观测确立为宇宙真实历史。

# 第二部分　Loop Quantum Cosmology 示例

## 3. 有效 Friedmann 方程

简单 LQC 模型中常见有效形式：

```text
H² = (8πG/3) ρ (1 - ρ/ρ_c)
```

当能量密度接近临界值 `ρ_c` 时，修正项使 `H²` 回到零并形成反弹。

这只是特定量子化和对称化模型的有效方程，不是普遍量子引力定律。

## 4. LQC 的开放问题

包括：

- 与完整 loop quantum gravity 的关系；
- 量子化歧义；
- 非均匀性和各向异性；
- 跨普朗克扰动；
- 有效方程适用范围；
- 可区分的观测信号。

正文不能让角色说“量子引力必然产生这个方程”。

# 第三部分　扰动穿越

## 5. 反弹前状态可能影响反弹后

在具体模型中，反弹前的：

- 标量扰动；
- 张量扰动；
- 曲率扰动；
- 各向异性；
- 场的量子态；

可能影响反弹后谱。

但传递可能涉及：

- 模式混合；
- 增长模与衰减模转换；
- 振幅改变；
- 相位丢失；
- 非高斯性；
- 对反弹微观模型的强依赖。

## 6. 不能用简单连续性假设

接近反弹时：

- 经典变量可能失效；
- 某些规范变量发散；
- 普通匹配条件未必有效；
- 必须求解完整动力学。

项目可以借此支持低带宽统计遗迹，但不能直接推出任意可控通信。

# 第四部分　项目反弹机制

## 7. 固定过程

项目 Canon：

```text
母宇宙质量条件改变
→ 整体膨胀停止
→ 宇宙收缩
→ 经典广义相对论失效
→ 量子引力阶段
→ 反弹
→ 新膨胀阶段
→ 九个宏观空间维度重新展开
```

其中最后一步属于 C 层公设。

## 8. 维度重新展开的解释

不得写成：

- 旧宇宙紧致维度被逐块修复；
- 旧物质重新获得缺失坐标；
- 文明设备把维度拉开。

应写成：

> 新宇宙初始有效真空处于九个空间方向均宏观展开的状态。

这是新的宏观相，不是旧区域恢复。

## 9. 反弹阶段的叙事限制

允许描写：

- 经典距离失去常规意义；
- 因果范围急剧变化；
- 温度和曲率达到极端；
- 观测装置逐步失效；
- 回声编码是否保留成为唯一悬念。

避免描写：

- 人物在反弹中继续驾驶飞船；
- 精确秒表倒计时；
- 看到一个明亮中心爆炸；
- 与新宇宙人物对话；
- 完整人格进入“量子空间”。

# 第五部分　观测状态

## 10. 没有反弹的确定证据

潜在信号可能包括：

- 大尺度功率谱特征；
- 非高斯性；
- 特定张量谱；
- 原初引力波；
- 各向异性遗迹。

但模型简并和宇宙方差使解释困难。

弥娅的发现不能只依赖普通 CMB 异常，而应利用新宇宙高维观测能力和跨区域多尺度相关结构。

# 第六部分　正文约束

## 11. 可安全使用

- 经典奇点提示理论适用范围终止；
- 多种量子引力或修改引力模型可产生反弹；
- 反弹前扰动可能影响反弹后；
- 传递规则依赖具体模型；
- 反弹不是时间倒流或中心爆炸。

## 12. 必须标为小说公设

- 旧宇宙必然在质量归还后整体坍缩；
- 量子反弹确实发生；
- 新宇宙重新拥有 `S9`；
- 回声编码能够跨越；
- 新文明能够识别其人工统计结构。

## 13. 禁止误写

- “量子力学阻止任何宇宙奇点，所以反弹已被证明。”
- “反弹让熵归零。”
- “反弹前后所有物理量连续不变。”
- “时间在反弹点倒流。”
- “小宇宙或飞船可以完整穿越。”
