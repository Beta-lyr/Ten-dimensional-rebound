# 二、戏剧发动机

## 3. 主视角目标

- **表面任务：** 审查“无人目标”禁入带计划，把启动坐标之外的泡壁环境损失重新纳入战略评估。
- **深层需要：** 继续共享撤离与观测知识，却拒绝让防御模型成为对无限后果的零伤亡背书。
- **时间压力：** 行动方准备在资源交叉路径上启动，审批表只剩维因的环境风险签名。
- **不行动代价：** 计划会以“目标区无人口”为由通过，泡壁外扩责任被制度性排除。

## 4. 核心阻力

- **主要阻力：** 行动方把“有限”定义为启动权限和目标坐标，维因则只能提供概率路径而不能给出最终边界。
- **阻力类型：** 制度 + 物理不确定性
- **原方案失效点：** 第2场景暴露：真空泡的责任边界由未来泡壁路径决定，而不是由启动坐标和当时人口定义。

## 5. 核心问题

> 低维泡可以被政治上定义为“有限使用”吗，还是启动行为必然把不可控环境变化带入战略决策？

## 6. 初始判断与误判

| 项目 | 内容 |
|---|---|
| 初始模型 | 若成核点没有人口、投放尺度足够小，禁入带可被视为有限环境工程。 |
| 忽略变量 | 真空泡的责任边界由未来泡壁路径决定，而不是由启动坐标和当时人口定义。 |
| 首次暴露 | 场景2 |
| 章末修正 | 把行动效果从成核点改为所有可达泡壁路径，并为环境损失设置无上限项。 |
| 仍保留未知 | 拒绝提供成核参数是否真的能减慢计划，还是只会让行动方使用更差模型。 |

## 7. 可选方案与选择

| 方案 | 具体行动 | 现实收益 | 具体代价 |
|---|---|---|---|
| A 全面拒绝 | 拒绝共享任何模型和预警数据 | 不直接帮助行动实施 | 受威胁区域也失去撤离窗口 |
| B 有限背书 | 按启动区人口评估并签署零伤亡结论 | 行动可迅速获得授权 | 把泡壁外扩从责任中删除 |
| C 分层共享 | 拒绝成核参数，公开泡壁观测和撤离模型并附无上限环境项 | 提高第三方预警且不参与制造 | 公开路径模型仍可帮助选择投放位置 |

- **最终选择：** 维因拒绝为隔离带提供成核参数，但同意共享泡壁观测与撤离模型，继续坚持防御信息不应被扣留。
- **选择发生：** 场景4
- **立即代价：** 维因的附录使审批延期，并让他被双方指责既阻碍防御又泄露战术信息。
- **延迟代价：** 泡壁路径模型成为后续投放优化工具，防御共享与制造辅助继续纠缠。

- **本章伏笔：** “只计算启动意图、不计算最终范围”的制度语言会在第4章导致第一次主动战略投放。
- **计划回收：** 第9章“保存区”语言进一步合法化主动低维化；第40章新宇宙研究者回看这些术语变化。

# 七、正文执行

## 14. 开场、锚点与收束

- **开场动作/异常：** 评估表的伤亡栏写着零，旁边的泡壁模拟却没有终止边界。
- **视觉或感官锚点：** 一个被写成“∞/未知”的环境损失单元格
- **首次含义：** 像审查员无法完成的空白
- **章末含义：** 成为有限使用概念无法封闭后果的证据
- **章节最后画面/动作：** 评估报告把预计损失写成零，因为目标坐标上没有人口；维因在附录中加入了一个没有上限的环境损失项。

## 15. 本章专属要求与禁区

**必须做到：**
- 让禁入带方案具备真实防御价值。
- 区分成核参数与预警数据。
- 环境损失必须通过具体路径展示。

**不得出现：**
- 不得让维因拥有否决所有文明的权力。
- 不得把行动方写成明知必灭仍嗜战。
- 不得出现泡壁可被普通屏障停止。
