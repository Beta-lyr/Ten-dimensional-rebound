# 二、戏剧发动机

## 3. 主视角目标

- **表面任务：** 在长期广播目录持续失联时决定是否停止全向询问，并把未知文明从伙伴名单移入高风险分类。
- **深层需要：** 让沉默从一个可理解的防御动作逐步变成别人无法解释的威胁信号。
- **时间压力：** 每次全向询问都会暴露更新位置，回应率却已降到无法维持公共网络的水平。
- **不行动代价：** 观测者继续按开放时代协议广播，本文明成为越来越少数的可定位节点。

## 4. 核心阻力

- **主要阻力：** 继续广播可能维持合作，也可能让本文明成为唯一清晰目标；停止则会加速公共网络消失。
- **阻力类型：** 不可观测状态 + 自我暴露
- **原方案失效点：** 第2场景暴露：主动静默、坐标模糊和技术变化会产生相同无信号结果，远方无法区分。

## 5. 核心问题

> 当沉默既可能表示死亡、隐藏或技术变化时，远方文明为何无法从无信号中获得可靠结论？

## 6. 初始判断与误判

| 项目 | 内容 |
|---|---|
| 初始模型 | 没有回应主要意味着文明毁灭或通信设施失效，继续询问仍能发现幸存者。 |
| 忽略变量 | 主动静默、坐标模糊和技术变化会产生相同无信号结果，远方无法区分。 |
| 首次暴露 | 场景2 |
| 章末修正 | 停止全向询问，只对已验证伙伴保留低功率回应，并把未知状态标成不可判定。 |
| 仍保留未知 | 伙伴是否仍存在，降低广播会不会被其解释为本文明死亡或敌意。 |

## 7. 可选方案与选择

| 方案 | 具体行动 | 现实收益 | 具体代价 |
|---|---|---|---|
| A 持续询问 | 维持全向广播和公开目录 | 最大化重新联系机会 | 持续暴露位置且回应率极低 |
| B 完全关闭 | 停止所有发送与回应 | 最大化隐蔽 | 已验证伙伴也无法区分死亡与隐藏 |
| C 伙伴低功率 | 取消全向询问，只对认证伙伴响应 | 保留最低合作并减少暴露 | 伙伴列表会过时且未知文明被风险化 |

- **最终选择：** 观测者降低广播频率，保留只对已验证伙伴开放的低功率回应。
- **选择发生：** 场景4
- **立即代价：** 观测者关闭最后一条全向询问信号，目录不再自动把沉默标成死亡。
- **延迟代价：** 公开合作网络缩小，未知文明默认进入高风险分类，下一章盟友状态更难确认。

# 七、正文执行

## 14. 开场、锚点与收束

- **开场动作/异常：** 目录里同一个空白可以表示死亡、隐藏、故障或技术跃迁，系统却一直只给它一个图标。
- **视觉或感官锚点：** 一排无法区分原因的空白回应格
- **首次含义：** 最初像观测失败
- **章末含义：** 章末成为黑暗森林中的不确定状态
- **章节最后画面/动作：** 观测者关闭了最后一条全向询问信号，宇宙没有因此变得更黑，只是再没有证据证明谁还在听。

## 15. 本章专属要求与禁区

**必须做到：**
- 盲样本证明无信号不可分类。
- 停止全向询问不等于完全静默。
- 伙伴列表必须存在过时问题。

**不得出现：**
- 不得让所有失联都来自攻击。
- 不得让观测者确认黑暗森林定律。
- 不得出现全宇宙统一静默。
