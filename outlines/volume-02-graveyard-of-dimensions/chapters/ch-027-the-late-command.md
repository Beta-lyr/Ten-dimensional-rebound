# 二、戏剧发动机

## 3. 主视角目标

- **表面任务：** 在中央命令和本地观测互相过时时，决定是否支援、报复或拒绝自动执行。
- **深层需要：** 展示信息延迟如何让忠诚与背叛失去即时验证，而不是让角色因愚蠢误读命令。
- **时间压力：** 支援窗口和报复倒计时同时逼近，本地无法在行动前得到盟友最新状态。
- **不行动代价：** 自动系统将执行旧报复授权，本地资源也会按迟到命令离开。

## 4. 核心阻力

- **主要阻力：** 所有方案的证据都来自不同过去，没有任何行动能等到确定结论。
- **阻力类型：** 因果延迟 + 责任
- **原方案失效点：** 第2场景暴露：中央生成命令时掌握的本地状态同样过时，完整信息优势已经不存在。

## 5. 核心问题

> 当信息传播时间接近政治和战争决策周期时，统一治理如何被过时信息系统性破坏？

## 6. 初始判断与误判

| 项目 | 内容 |
|---|---|
| 初始模型 | 中央命令虽然旧，但基于更完整情报，服从比本地猜测更安全。 |
| 忽略变量 | 中央生成命令时掌握的本地状态同样过时，完整信息优势已经不存在。 |
| 首次暴露 | 场景2 |
| 章末修正 | 取消自动报复并拒绝迟到支援，记录决策所依赖的时间戳和未知。 |
| 仍保留未知 | 拒绝究竟救了盟友、纵容了攻击，还是只是改变了未来误解。 |

## 7. 可选方案与选择

| 方案 | 具体行动 | 现实收益 | 具体代价 |
|---|---|---|---|
| A 服从中央 | 执行支援和既定报复 | 维持联盟纪律 | 可能援助已不存在对象并攻击错误目标 |
| B 完全等待 | 暂停所有行动直到获得新确认 | 避免基于旧信息攻击 | 确认到达时所有窗口已关闭 |
| C 本地拒绝 | 取消自动报复并保留防御资源 | 避免不可逆错误并承认不确定 | 承担背叛指控和盟友可能损失 |

- **最终选择：** 指挥者取消自动报复并拒绝执行迟到的支援命令，承担被视为背叛共同体的风险。
- **选择发生：** 场景4
- **立即代价：** 指挥者使用自治密钥中止两套自动命令，中央将其标为拒令节点。
- **延迟代价：** 联盟从法律上的统一体变成只能事后比较选择的局部生存体。
