# 二、戏剧发动机

## 3. 主视角目标

- **表面任务：** 比较三个文明的保存原则，建立不以单一胜者为目标的因果档案。
- **深层需要：** 让维因从设计“正确文明核心”转向保存彼此冲突的删减理由。
- **时间压力：** 档案容量和中继连接即将因S5环境进一步下降，记录必须在统一摘要前冻结。
- **不行动代价：** 后世只会看到成功者的压缩规则，不知道被删除的价值和反对意见。

## 4. 核心阻力

- **主要阻力：** 档案制度要求可执行摘要，而维因想保留无法被一个规则解决的冲突。
- **阻力类型：** 信息压缩 + 价值冲突
- **原方案失效点：** 第2场景暴露：三种方案分别保住繁衍、制度和个体，却都以牺牲另两者为条件。

## 5. 核心问题

> 当容量和结构都有限时，规则、人口、知识与个体记忆分别能代表文明到什么程度？

## 6. 初始判断与误判

| 项目 | 内容 |
|---|---|
| 初始模型 | 可以从多个保存案例中提炼出一套普遍文明核心：人口、科学或连续个体中的最优组合。 |
| 忽略变量 | 三种方案分别保住繁衍、制度和个体，却都以牺牲另两者为条件。 |
| 首次暴露 | 场景2 |
| 章末修正 | 不建立统一清单，把互相矛盾的原则、失败案例和被删部分一起保存。 |
| 仍保留未知 | 有限带宽未来是否会再次把这些分歧压成单一教训。 |

## 7. 可选方案与选择

| 方案 | 具体行动 | 现实收益 | 具体代价 |
|---|---|---|---|
| A 人口核心 | 将可繁衍人口设为文明最低核心 | 适合长期生存规划 | 科学、制度和个体历史可被删除 |
| B 规则核心 | 优先保留科学和制度程序 | 无人延续也可运行 | 原成员与生态关系被降格 |
| C 分歧档案 | 保存三类选择、反对意见和损失 | 未来能看到因果而非唯一答案 | 占用更多带宽且无法直接指导行动 |

- **最终选择：** 维因拒绝建立统一文明核心清单，把分歧、反对意见和失败案例一并纳入因果档案。
- **选择发生：** 场景4
- **立即代价：** 维因取消统一“文明核心”章节，保留三套互相否定的案例。
- **延迟代价：** 这套分歧保存方法成为早期回声内容选择的制度原型。

### 场景1　压缩原则

- **地点/时间：** 连续性法庭 / 旧宇宙 / O-D09 / S5

- **具体行动：** 维因走访三个文明：一个优先保留可繁衍人口，一个保留科学制度，一个保留少数连续个体
- **反作用力：** 现有流程更倾向接受“可以从多个保存案例中提炼出一套普遍文明核心：人口、科学或连续个体中的最优组合。”，主视角没有足够理由立即改变资源或权限。

- **可见代价：** 放弃给后世一个简单答案
- **交付：** 一代与十代结果表

- **开场动作/异常：** 三份“文明核心”提案没有一项共同优先级，只有每份文件末尾不同的失去名单。
- **视觉或感官锚点：** 三份互相矛盾的核心清单
- **首次含义：** 最初像需要综合的政策材料
- **章末含义：** 章末成为必须保留分歧的历史对象
- **章节最后画面/动作：** 维因没有在三种方案中选出胜者，只在每份记录后写下同一句话：被删去的部分同样属于文明。

## 15. 本章专属要求与禁区

**必须做到：**
- 三个文明方案都要有可持续收益。
- 维因不选胜者但仍作出档案选择。
- 早期回声思想只能是制度雏形。

**不得出现：**
- 不得让维因正式建立回声计划。
- 不得让一个保存原则明显完美。
- 不得写成长篇抽象哲学辩论。
