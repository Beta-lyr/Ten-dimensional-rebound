# 第一部分　章节定位

## 1. 卷级功能

繁衍型后继者获得文明延续资源，记忆型后继者的短暂存在成为历史档案的一部分。

本章在第二卷中的更深层功能是：把文明连续与个体连续彻底分离，通过身体、记忆、繁衍和法律资格的删减建立残酷选择。

## 2. 本章核心科学问题

> 记忆相似度、生存稳定性和可繁衍性为何不能共同构成无争议的人格连续指标？

若原问题已经以问号结尾，正文不重复添加问号。本章不得同时引入第二个同等重要的新物理机制；其他设定只作为操作条件、历史证据或损失结果出现。

## 3. 本章人物选择

**最终选择：** 记忆型后继者放弃长期资源优先权，但要求其版本的经历被记录为独立生命，而非迁移失败。

**可被拒绝的替代方案：**

- 维持既有流程或等待更多信息，把当前风险转交给下一节点。
- 采用表面上更直接的方案，但接受更高的不可逆损失、信息垄断或扩散风险。

人物章节的选择必须通过资源、权限、身份、时间、信誉、文明能力或结构损失表现；物质系统和无人物章节则通过执行删减与状态转变表现，不能用抽象宣告替代过程。

## 4. 情感锚点

低维后继个体（接力配角）在无法证明结果安全、正确或会被未来理解的情况下，仍必须通过签署、删除、授权、公开、迁移、归还、拒绝或停止行动承担后果。

涉及人物时，情感不得通过长篇抒情独白直接说明，应由保留何种数据、放弃哪些成员、拒绝哪项权力、降低何种广播或允许何种不可逆变化来表现。无人物或物质系统视角则通过状态丢失和记录终止建立重量。

# 第四部分　科学说明设计

## 11. 核心概念进入正文的顺序

1. 先出现具体对象、异常、路径、设备结果、身份争议或宇宙参数；
2. 主视角为了作出决定，提出最低限度的工作解释；
3. 另一个角色、节点、样本或制度条款提供反证与限制；
4. 替代方案被认真测试，暴露其自身代价；
5. 人物作出不可撤销选择，或系统完成不可逆执行，或宇宙状态跨越理论边界；
6. 章末只保留下一章必须处理的结果或解释缺口。

## 12. 科学解释的合法载体

- 身体中心映射、记忆保留率、繁衍测试、连续性法庭和规则核心；
- 失败后的设备状态、迁移清单、法律记录、延迟命令或编码残差；
- 独立文明、不同数学路线或多节点验证产生的差异；
- 因维数下降而永久失去的能力，而非只靠旁白宣告“更低维”；
- 角色需要据此签署、撤离、删除、攻击、归还或公开的实际参数。

不得用“高维文明无法理解的技术”跳过关键机制。

## 13. 本章概念边界

- 十维始终指九个宏观空间维度加一个时间维度；
- 所有局部信息传播遵守完整时空中的局部光速上限；
- 低维泡的边界接近但不超过局部光速，普通物质屏障不能阻止；
- 曲率引导和相对冲只能在限定条件下改变路径或局部响应，不能成为无副作用宏观护盾；
- 主动低维化提高部分幸存率，不等于无损迁移；
- 量子反弹后维度重展属于新宇宙初态，不是旧区域恢复；
- 任何技术能力都必须保留工程限制、制度代价和失效方式。

## 14. 本阶段特有损失

人格连续、身体完整、原成员代表权和统一的文明定义。

正文必须让这一损失改变人物行动、文明资格、制度结构或后续可选方案，不能只作为背景说明。

# 第五部分　人物与冲突

## 15. 主视角的章内状态

**章首：** 主视角仍可维持上一阶段或上一章的既有判断。

**压力增加：** 新数据、传播、损失或延迟使原判断无法完整解释现实。

**误判风险：** 角色可能把短期幸存、统计优势、模型成功、权限控制或沉默误当成长期安全。

**选择节点：** 角色必须在至少两个都有真实代价的方案之间决定。

**章末：** 角色未获得最终答案，但已经失去退回章首状态的条件。

## 16. 配角功能限制

本章配角只能承担以下一种或数种功能：

- 提供独立复核、反例或替代工程路线；
- 执行主视角无法亲自完成的观测、迁移、维护或裁定；
- 提出有数据和生存压力支持的反对意见；
- 代表被统计排除、被延迟命令影响或被迫删减的群体；
- 让一项技术限制产生实际损失。

配角不得替主视角作出本章关键选择，也不得承担全部错误以保护核心人物形象。

## 17. 冲突升级阶梯

```text
可沿用的既有方案
→ 新环境或新证据暴露缺口
→ 替代方案显示不同代价
→ 权限、运力、时间或信任窗口缩小
→ 主视角必须选择
→ 选择产生不可撤销的新输入
```
