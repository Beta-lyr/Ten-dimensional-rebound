# 二、戏剧发动机

## 3. 主视角目标

- **表面任务：** 在S5降至S4时识别联径网络失效的真实原因，并按因果延迟切分自治节点。
- **深层需要：** 把“距离归来”写成邻接关系消失，而不是飞船单纯变慢。
- **时间压力：** 中央拓扑图仍把失联节点标成故障，资源和撤离命令持续发送到不可达路径。
- **不行动代价：** 中继过载，局部节点等待不存在的修复，错过自主行动窗口。

## 4. 核心阻力

- **主要阻力：** 承认路径永久消失等同承认统一治理结束，中央机构仍要求维护者维持共同现在的界面。
- **阻力类型：** 空间拓扑 + 治理惯性
- **原方案失效点：** 第2场景暴露：泡壁紧致了路径依赖的方向，可达集合本身改变，没有备用线路。

## 5. 核心问题

> 高维交通终止为何不是飞船变慢，而是整个邻接关系和可达路径集合发生改变？

## 6. 初始判断与误判

| 项目 | 内容 |
|---|---|
| 初始模型 | 联径断裂属于设备损坏，可以通过重路由和增加中继恢复原网络。 |
| 忽略变量 | 泡壁紧致了路径依赖的方向，可达集合本身改变，没有备用线路。 |
| 首次暴露 | 场景2 |
| 章末修正 | 停止维护虚假统一拓扑，按真实传播时间切分网络并下放自治。 |
| 仍保留未知 | 节点自治会保存更多文明，还是加速联盟分裂和误判。 |

## 7. 可选方案与选择

| 方案 | 具体行动 | 现实收益 | 具体代价 |
|---|---|---|---|
| A 持续重路由 | 把失联视为临时故障并增加中继 | 维持统一网络叙事 | 资源耗尽且命令继续误投 |
| B 关闭远端节点 | 从中央图删除不可达区域 | 减轻中继负担 | 远端文明失去合法身份和资源权 |
| C 因果切分 | 保留节点但标注真实延迟并授权自治 | 诚实反映可达性且允许本地行动 | 统一治理和实时资源分配终止 |

- **最终选择：** 维护者放弃维持虚假的统一拓扑图，按真实因果延迟切分网络并下放节点自主权。
- **选择发生：** 场景4
- **立即代价：** 维护者关闭实时全局图，中央失去对多个节点的即时控制。
- **延迟代价：** 节点进入不同“现在”，下一章迟到命令成为常态。
