# 二、戏剧发动机

## 3. 主视角目标

- **表面任务：** 在宇宙膨胀停止时冻结回声主要内容，把剩余资源转向纠错冗余。
- **深层需要：** 让末期文明接受“未被写入”也是真实损失，不能无限延迟内容选择。
- **时间压力：** 背景尺度和温度变化正在缩短通信、计算和节点同步窗口。
- **不行动代价：** 继续加入历史细节会使编码在坍缩前无法完成全局校验。

## 4. 核心阻力

- **主要阻力：** 每个新文明都能证明自己的历史值得加入，编码窗口却不能延长。
- **阻力类型：** 时间窗口 + 代表性
- **原方案失效点：** 第2场景暴露：膨胀终点后因果范围只会缩小，新增内容会破坏已完成的冗余结构。

## 5. 核心问题

> 宇宙整体从膨胀转向坍缩时，背景尺度变化如何压缩可用通信、计算和编码窗口？

## 6. 初始判断与误判

| 项目 | 内容 |
|---|---|
| 初始模型 | 只要宇宙尚未开始快速坍缩，仍可不断增加历史内容并在最后统一压缩。 |
| 忽略变量 | 膨胀终点后因果范围只会缩小，新增内容会破坏已完成的冗余结构。 |
| 首次暴露 | 场景2 |
| 章末修正 | 提前冻结三层内容，只允许增加纠错冗余和环境适配。 |
| 仍保留未知 | 冻结版本是否覆盖足够多文明，以及哪些末期事件将永久缺席。 |

## 7. 可选方案与选择

| 方案 | 具体行动 | 现实收益 | 具体代价 |
|---|---|---|---|
| A 持续收录 | 直到最后节点失联前不断加入历史 | 内容更全面 | 来不及完成鲁棒校验 |
| B 极限删减 | 只保留维数序列和存在证明 | 最易穿越 | 失去战争因果和实验见证 |
| C 内容冻结 | 锁定三层主体，后续资源只增强冗余 | 提高保留概率 | 大量晚期文明永久不被记录 |

- **最终选择：** 观测者提前冻结回声主要内容，只允许增加纠错冗余，不再加入新的历史细节。
- **选择发生：** 场景4
- **立即代价：** 观测者关闭所有新增历史入口，拒绝最后一批内容申请。
- **延迟代价：** 回声从历史项目变成固定编码系统，未入选文明无法再进入下一宇宙证据。
