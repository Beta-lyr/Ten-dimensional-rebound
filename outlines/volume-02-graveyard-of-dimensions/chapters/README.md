## 使用说明

本目录只保存每章专属的目标、误判、替代方案、五场景因果、科学载体、资源代价、信息边界与章间接口。通用物理规则、原创边界和通用验收项统一读取 `canon/`、`research/`、`outlines/00-master-outline.md` 和本卷卷纲，不再逐章复制。

## 第二卷关键连续性

- 第01、10、15、19、25、30、35、40、45、50章属于新宇宙解码线；其余主体属于旧宇宙历史线，第49章为无人物反弹桥接章。
- 第11章只完成极小S7成核与对冲极限验证；它不是大范围战争高潮。
- 第12—24章分别推进材料、生命、计算、身份与文明连续性，不能重复为一般“被压扁”。
- 第29章后维因退出主动历史，后续旧宇宙章节不得让其重新主持工程。
- 第31—40章先形成S3物理与通信条件，再形成黑暗森林行为；不得把黑暗森林写成天然法则。
- 第41—47章依次完成缺失质量、归还协议、回声三层、膨胀终点与因果范围收缩。
- 第48章终止旧宇宙局部记录，第49章完成量子反弹与新S9重展，第50章只进入实验设计，不发生第三卷实验。

- 第03章《禁入带》：`ch-003-exclusion-zone.md` — 受威胁文明获得更准确的泡壁预警，但行动方也能从公开模型改进投放位置。
- 第04章《有限投放》：`ch-004-limited-deployment.md` — 低维技术正式进入战略计划，其他文明开始把成核能力纳入威慑和预案。
- 第05章《基准事故》：`ch-005-the-baseline-accident.md` — 跨文明防御研究正式启动，同时获得比任何单一复现团队更完整的真空相数据。
- 第06章《泡壁之前》：`ch-006-before-the-wall.md` — 受威胁文明获得可计算的撤离窗口，但研究也开始探索比 S8 更低能的真空状态。
- 第07章《逃逸方向》：`ch-007-escape-direction.md` — 幸存群体获得继续存在的基础，但文明内部首次将“可迁移性”写入生存资格。
- 第08章《保存区》：`ch-008-preservation-zone.md` — 部分生命和基础设施按预设方向幸存，案例被其他文明视为可复制的防御成功。
- 第09章《成功案例》：`ch-009-the-success-case.md` — 文明仍采用保存区方案，但维因的多维损失矩阵成为后来回声第二层的历史分类基础。
- 第10章《两类箭头》：`ch-010-two-arrows.md` — 历史研究从“谁攻击了谁”转向“何种制度使更多文明主动放弃方向”。
- 第11章《更低的真空》：`ch-011-a-lower-vacuum.md` — 实验提供了 S7 物质稳定谱，多个文明开始重构材料与生命载体。
- 第12章《失稳谱》：`ch-012-instability-spectrum.md` — S7 文明获得生产能力，但“保存现有生命”与“保存未来制造能力”首次直接冲突。
- 第13章《不可复制的器官》：`ch-013-the-unreplicable-organ.md` — 一代完整幸存者与可繁衍后继体同时存在，产生文明代表权冲突。
- 第14章《无人延续》：`ch-014-continuity-without-survivors.md` — 六类维度难民方案获得清晰雏形，不同文明开始采用彼此不兼容的连续性标准。
- 第15章《损失分类》：`ch-015-taxonomy-of-loss.md` — 新宇宙研究开始接触历史选择问题，安全风险也从物理异常扩大到信息内容。
