# 二、戏剧发动机

## 3. 主视角目标

- **表面任务：** 设计允许匿名、分阶段和部分行动的质量归还协议，并推动第一批文明在无强制条件下执行。
- **深层需要：** 证明黑暗森林中仍可能通过可验证公共参数合作，同时不把归还写成普遍善意。
- **时间压力：** 质量缺口已确认，宇宙演化窗口缩短；每个文明都担心自己先归还而别人搭便车。
- **不行动代价：** 所有小宇宙继续等待他人，母宇宙参数无法越过可坍缩区间。

## 4. 核心阻力

- **主要阻力：** 每个参与者都能搭便车，协议又不能通过坐标或强制权惩罚拒绝者。
- **阻力类型：** 公共行动 + 匿名验证
- **原方案失效点：** 第2场景暴露：中心不可建立，承诺不可验证；母宇宙参数本身可以作为匿名行动的公共反馈。

## 5. 核心问题

> 在黑暗森林中，文明如何验证一项要求自我牺牲的宇宙公共行动，而不暴露坐标或依赖绝对信任？

## 6. 初始判断与误判

| 项目 | 内容 |
|---|---|
| 初始模型 | 只有建立可信中心或确认多数文明承诺后，个体文明才会理性归还。 |
| 忽略变量 | 中心不可建立，承诺不可验证；母宇宙参数本身可以作为匿名行动的公共反馈。 |
| 首次暴露 | 场景2 |
| 章末修正 | 发布多源冗余、分阶段验证协议，用参数变化证明行动而不识别行动者。 |
| 仍保留未知 | 响应规模是否足够、拒绝者比例多大，以及归还会在何时改变整体演化。 |

## 7. 可选方案与选择

| 方案 | 具体行动 | 现实收益 | 具体代价 |
|---|---|---|---|
| A 等待多数承诺 | 收集足够文明签名后统一归还 | 降低单方牺牲风险 | 签名真假和当前状态不可验证 |
| B 强制定位 | 识别小宇宙并要求归还 | 理论上提高参与率 | 暴露坐标并触发冲突 |
| C 参数验证 | 允许匿名分阶段归还，以母宇宙参数变化公开证明 | 无需中心和绝对信任 | 无法阻止拒绝者搭便车 |

- **最终选择：** 协调者发布多源冗余、分阶段验证的归还协议，接受无法强迫拒绝者参与。
- **选择发生：** 场景4
- **立即代价：** 协调者先提交一批可验证但不可定位的归还，并放弃知道谁响应。
- **延迟代价：** 第一批参数变化诱发更多行动，归还者集合以统计而非名单形成。
