# 二、戏剧发动机

## 3. 主视角目标

- **表面任务：** 比较屏障、逃逸、曲率引导和相对冲，给受威胁文明一份不夸大能力的防御选项表。
- **深层需要：** 把“阻止泡壁”的政治期待改成速度、路径和损失分布的有限工程问题。
- **时间压力：** 一个S8泡正在逼近联径密集区，各文明要求在撤离计划冻结前选择主防御路线。
- **不行动代价：** 资源会继续投入无法阻挡泡壁的物质屏障，撤离窗口在错误承诺中耗尽。

## 4. 核心阻力

- **主要阻力：** 受威胁文明只愿资助能够承诺“停止”的方案，而诚实模型只能给出窗口和代价。
- **阻力类型：** 物理 + 沟通
- **原方案失效点：** 第2场景暴露：泡壁是真空相边界，不是物质前沿；同层高能结构只能改变局部传播代价。

## 5. 核心问题

> 面对无法消除的低维真空泡，防御究竟能改变什么：速度、路径、损失分布，还是相本身？

| 初始模型 | 足够高能的屏障或反向曲率可以像抵消冲击波一样把泡壁推回。 |
| 忽略变量 | 泡壁是真空相边界，不是物质前沿；同层高能结构只能改变局部传播代价。 |
| 首次暴露 | 场景2 |
| 章末修正 | 将防御按预警、逃逸、路径引导和改变终态四类分开，并把“延缓”从“阻止”中删除。 |
| 仍保留未知 | 更低真空对冲是否会生成比原泡更危险的新相。 |

## 7. 可选方案与选择

| 方案 | 具体行动 | 现实收益 | 具体代价 |
|---|---|---|---|
| A 物质屏障 | 集中材料和能量构造阻挡层 | 技术成熟且易于解释 | 泡壁会重组屏障并浪费撤离资源 |
| B 逃逸与引导 | 投资预警、路径迁移和局部曲率梯度 | 可增加部分幸存率 | 依赖提前部署且无法改变终态 |
| C 真空对冲 | 研究更低能相改变泡壁终态 | 模型中唯一可能稳定终止局部传播 | 必须先制造更低维真空 |

- **最终选择：** 维因支持继续验证曲率引导与逃逸方案，同时明确拒绝把“延缓”写成“阻止”。
- **选择发生：** 场景4
- **立即代价：** 维因拒绝在报告标题使用“防护罩”，导致联盟无法向公众承诺完全安全。
- **延迟代价：** 对冲选项被保留在研究列表，S7第一次成为可计算目标。

## 14. 开场、锚点与收束

- **开场动作/异常：** 四种防御方案摆在同一张表上，只有最后一列写着“改变终态”，那一列也写着“S7”。
- **视觉或感官锚点：** 被划掉的“阻止”一词
- **首次含义：** 代表文明仍期待可逆防御
- **章末含义：** 成为维因坚持有限能力描述的标记
- **章节最后画面/动作：** 所有方案中，唯一能在模型里改变泡壁终态的选项，都要求先制造一个更低的真空。

## 15. 本章专属要求与禁区

**必须做到：**
- 四类防御必须改变不同变量。
- 物质屏障失败要由真空相机制解释。
- S7只作为对冲需求出现。

**不得出现：**
- 不得出现无副作用曲率护盾。
- 不得让泡壁任意减速以方便撤离。
- 不得把逃逸写成所有人口都可用。
