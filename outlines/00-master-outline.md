## 0. 文件职责

本文件是《十维回声》的全书叙事控制层。

它不重新定义宇宙物理、人物固定身份、文明制度、技术能力或原创边界，而是把 Canon 中已经确定的真实历史，组织成三卷长篇能够执行、审查和修订的叙事结构。

本文件负责确定：

- 三卷各自承担的叙事任务；
- 真实宇宙历史与读者获知顺序之间的区别；
- 第一卷、第二卷和第三卷之间不可跳过的因果接口；
- 维因、弥娅、赫森和伊蓝的跨卷人物弧线；
- 科学概念、文明制度和危险知识的分卷引入顺序；
- 全书核心选择、高潮、最低点和开放式结局；
- 跨卷伏笔的埋设、转化与回收位置；
- 哪些问题必须回答，哪些问题必须永久保持不确定；
- 修改任一卷时必须执行的全书级影响检查；
- 全书最终应让读者获得的认知、情感和伦理体验。

本文件不负责：

- 替代 `canon/00-series-bible.md`；
- 重新解释降维、量子反弹或回声编码的物理机制；
- 为所有配角固定姓名、文明归属和个人结局；
- 规定每章的完整场景顺序；
- 直接编写正文；
- 用后期剧情反向修改高优先级 Canon；
- 把全书主题写成人物能够直接说出的标准答案。

当本文件与 Canon 冲突时，必须修改本文件。

当卷级大纲、章节地图、章节细纲或正文与本文件冲突时，应优先修改低优先级文件。不得通过新增万能技术、隐藏宇宙意志、跨宇宙人格继承或人物突然改变立场保留冲突内容。

# 第一部分　全书创作契约

## 1. 一句话故事

在上一个拥有九个宏观空间维度的宇宙中，真空工程师维因为终止战争参与设计局部空间隔离技术，却开启了连续降维和黑暗森林形成的历史；旧宇宙毁灭并发生量子反弹后，新宇宙宇宙学家弥娅从原初引力关联中发现这段警告，却必须重新制造一次微型降维现象才能证明警告真实，并在知识封锁与全面公开之间寻找只能延缓风险的第三条路径。

## 2. 全书核心命题

全书围绕一个问题展开：

> 一个文明能否把毁灭留下的记忆转化为智慧，而不是转化为下一件武器？

这个问题不得被写成可以由单一人物、单一政策或单一技术彻底解决的问题。

全书只能给出以下有限结论：

- 历史能够增加文明作出选择前的时间；
- 知识治理能够改变危险扩散的速度；
- 公开和封锁都能减少某类风险，同时制造另一类风险；
- 文明可以改进决策条件，却不能永久取消危险知识独立出现的可能；
- 旧宇宙警告新宇宙，并不意味着新宇宙自动获得智慧；
- 全书结局只能证明循环被延缓，不能证明循环已经被打破或必然重启。

## 3. 三组固定矛盾

### 3.1 知识与危险

科学知识是否应当公开，不能由“知识天然无罪”或“危险知识必须销毁”单独回答。

全书必须逐步展示：

```text
实验资料公开
→ 事故得到公共验证
→ 复制门槛降低
→ 封锁需求出现
→ 封锁权形成垄断
→ 透明需求反弹
→ 公开拼接降低工程门槛
→ 有限公开成为暂时边界
```

### 3.2 安全与垄断

危险知识需要受控，但控制者本身也会成为宇宙中最危险的权力中心之一。

赫森的逻辑必须成立：

> 只要一个参与者拒绝约束，其他参与者的善意便可能失效。

伊蓝的逻辑也必须成立：

> 秘密不会消除危险，只会让危险失去监督。

两者都不能成为全书最终答案。

### 3.3 警告与传播

任何能够让其他文明相信降维真实存在的证据，都必须包含一定程度的可验证结构。

因此全书固定因果为：

```text
警告若不可验证
→ 文明可以将其视为神话或欺骗

警告若足够可信
→ 文明会更接近重建理论

警告若包含完整工程参数
→ 警告直接成为武器说明书

警告若完全不含物理结构
→ 无法承担跨宇宙历史证据功能
```

十维回声只能在这组矛盾中成立。

## 4. 全书主题推进方式

主题不得通过长篇演讲直接宣布。

主题必须通过以下行动逐步显现：

- 维因接受隔离工程；
- 维因允许第一次实验；
- 维因组织恢复和救援；
- 维因公开事故资料；
- 文明以防御名义复制技术；
- 文明主动降低自身维度；
- 文明决定保留哪些生命、知识和历史；
- 维因删除部分研究；
- 独立推导证明知识无法恢复为未知；
- 旧宇宙决定向未知未来发送警告；
- 弥娅决定继续解码；
- 弥娅支持进行真实验证实验；
- 赫森授权实验并要求权限分离；
- 伊蓝要求多文明见证；
- 三人面对数据不可逆扩散；
- 赫森推动静默；
- 伊蓝推动公开；
- 弥娅建立有限公开边界；
- 赫森降低广播功率；
- 弥娅拒绝把遥远异常解释为确定攻击。

## 5. 全书固定类型与风格

作品类型固定为：

- 硬科幻；
- 宇宙文明史；
- 维度战争；
- 科学发现与技术扩散；
- 知识治理；
- 克制的人物伦理冲突。

全书不得逐渐转化为：

- 超能力冒险；
- 时间旅行故事；
- 神秘主义宇宙轮回；
- 高维神族操纵低维文明；
- 以舰队数量和爆炸规模为主的战争小说；
- 以阴谋揭露代替制度因果的政治惊悚；
- 主要依靠私人爱情改变宇宙历史的故事。

## 6. 全书叙事规模

正式结构基线为：

| 卷 | 卷名 | 章节基线 | 建议正文规模 | 主要时间线 |
|---|---|---:|---:|---|
| 第一卷 | 《第十个方向》 | 30章 | 约18万—24万字 | 旧宇宙起点 + 新宇宙证据线 |
| 第二卷 | 《诸维之墓》 | 50章 | 约30万—42万字 | 旧宇宙完整历史 + 新宇宙解码线 |
| 第三卷 | 《重启之后》 | 45章 | 约24万—34万字 | 新宇宙现实决策线 |
| 全书 | 三卷长篇 | 125章 | 约72万—100万字 | 两个宇宙周期 |

章节数和字数属于规划基线，不属于物理 Canon。

允许因正文节奏微调，但不得删除固定因果节点、跨卷接口或人物必要选择。

# 第二部分　真实历史与叙事历史

## 7. 真实宇宙历史

在作品世界中，事件真实顺序固定为：

```text
旧宇宙完整 S9 时代
→ 高维开放秩序形成
→ 文明冲突与边界需求上升
→ 维因参与局部维度闭锁工程
→ 第一次人工低维真空泡形成
→ 恢复失败与泡壁扩张
→ 首个殖民文明遭遇降维
→ 事故资料公开
→ 多文明复制技术
→ 防御性降维出现
→ S9→S8
→ S8→S7
→ S7→S6
→ S6→S5
→ S5→S4
→ S4→S3
→ 三维黑暗森林时代形成
→ 小宇宙质量缺失问题出现
→ 质量归还广播获得回应
→ 回声计划完成三层编码
→ 旧宇宙整体坍缩
→ 量子反弹
→ 新宇宙重新展开 S9
→ 新文明独立演化
→ 弥娅发现原初关联异常
→ 第一层证明旧宇宙存在
→ 第二层重建连续降维历史
→ 第三层要求真实真空相验证
→ 新宇宙制造微型 S8 区域
→ 实验失控并被局部限制
→ 数据不可逆扩散
→ 静默与公开政策冲突
→ 有限公开与最终广播
→ 遥远空间自由度异常
→ 来源永久不确认
```

任何卷级、章节级或正文级调整不得改变上述事件顺序。

## 8. 叙事顺序

读者接收信息的顺序不同于真实历史：

### 第一卷

读者先看到：

- 新宇宙中的背景异常；
- 一个看似仍处于开放时代的高维文明；
- 一项具有现实人道目标的隔离工程；
- 第一次人工降维灾难；
- 一份变成复制资料的警告；
- 当前宇宙之前存在另一个宇宙；
- `9 → 8 → 7 → 6 → 5 → 4 → 3` 的维数递减序列。

读者尚不知道：

- 旧宇宙如何连续降维；
- 黑暗森林如何形成；
- 回声计划由谁建立；
- 量子反弹如何发生；
- 弥娅为何能够接收这些信息。

### 第二卷

读者获得：

- 第一次事故之后的复制和军备化；
- 每次维数下降造成的不同文明能力损失；
- 维因防御研究的失败；
- 维因退出主动历史；
- 三维空间与黑暗森林的形成；
- 质量归还和回声计划；
- 旧宇宙坍缩及量子反弹；
- 弥娅所在时代属于新宇宙；
- 第三层回声只能通过真实实验完成验证。

读者尚不知道：

- 新宇宙实验是否会发生；
- 实验如何失控；
- 数据是否能够封锁；
- 静默、公开和有限公开如何形成；
- 结尾异常是否人为。

### 第三卷

读者获得：

- 实验治理与权限分离；
- 新宇宙第一次微型降维；
- 控制失败与永久低维缺陷；
- 数据不可逆扩散；
- 静默与公开方案的真实收益和反作用；
- 有限公开方案；
- 最终广播；
- 遥远异常和三种并存解释。

读者直到结尾仍然不知道：

- 哪个文明最先完成武器化；
- 异常是否属于自然相变、实验或攻击；
- 弥娅方案延缓了多久；
- 新宇宙是否必然再次降维。

## 9. 因果线、证据线与决策线

三卷分别承担三种叙事功能。

| 叙事功能 | 主要卷 | 回答的问题 |
|---|---|---|
| 因果线 | 第一卷、第二卷旧宇宙部分 | 事情怎样发生 |
| 证据线 | 第一卷、第二卷弥娅部分 | 后来者怎样证明事情曾发生 |
| 决策线 | 第三卷 | 知道历史后怎样选择 |

三种线不得互相替代。

弥娅不能通过直觉直接获得旧宇宙真相。

旧宇宙历史不能只作为弥娅读到的档案摘要存在。

第三卷不能通过重新讲述旧宇宙历史代替现实政策冲突。

## 10. 两个宇宙周期的联系

旧宇宙与新宇宙之间仅通过十维回声建立联系。

允许传递：

- 高度压缩的数学结构；
- 维数递减序列；
- 战争因果骨架；
- 部分统计相关性；
- 有限的实验见证关系；
- 极少量经过压缩的个人陈述。

禁止传递：

- 完整意识；
- 人体或生命结构；
- 文明数据库；
- 飞船；
- 完整工程图纸；
- 逐字历史；
- 实时通信；
- 弥娅向维因发送回复。

维因与弥娅的联系固定为：

```text
维因参与造成历史
→ 维因留下有限记录
→ 记录被回声计划压缩
→ 弥娅通过证据理解其选择
```

不得转化为人格继承、转世、梦境对话或命运安排。

# 第三部分　三卷总体功能

## 11. 第一卷《第十个方向》

### 11.1 卷级任务

第一卷必须完成：

- 建立完整高维宇宙的可信日常；
- 证明开放坐标和共享交通具有现实收益；
- 证明普通边界在高维空间中难以成立；
- 建立局部维度闭锁工程的人道目标；
- 让维因基于合理数据支持实验；
- 完成第一次人工降维；
- 完成恢复失败、泡壁扩张和首个文明级灾难；
- 让维因公开事故资料；
- 让其他文明开始独立复现；
- 让弥娅证明旧宇宙存在；
- 让弥娅识别维数递减序列。

### 11.2 卷级核心问题

> 当一项实验具有真实的人道价值、可验证的科学依据和无法完全测量的灾难风险时，是否有足够理由允许它发生？

第一卷必须让读者理解：

- 维因有理由支持；
- 支持仍然造成不可逆后果；
- 后果不是单一低级错误；
- 事故后的正确选择仍会制造新危险。

### 11.3 卷级因果链

```text
开放路径被反复绕过
→ 非杀伤边界需求成立
→ 局部闭锁被设计为可撤销
→ 实验成功形成 S8 区域
→ 恢复序列失败
→ 泡壁自发扩张
→ 无关殖民文明进入路径
→ 救援无法保存全部结构
→ 事故公开
→ 复制项目启动
```

### 11.4 卷首输入

- 旧宇宙仍为完整 `S9`；
- 高维文明坐标公开；
- 真空稳定性争议存在但未形成普遍恐惧；
- 维因相信工程可以解决政治边界问题；
- 新宇宙弥娅只发现无法解释的原初关联异常。

### 11.5 卷末输出

向第二卷交付：

- 第一次人工降维已成为公共事实；
- 低维真空泡宏观不可逆；
- 事故资料已经公开；
- 至少三个文明开始复制；
- 维因第一次怀疑知识公开原则；
- 弥娅证明旧宇宙存在；
- 弥娅识别连续维数递减序列；
- 连续降维历史尚未展开。

### 11.6 第一卷不得完成

- 不得爆发全面维度战争；
- 不得从 `S9` 直接写到 `S3`；
- 不得出现成熟黑暗森林；
- 不得建立回声计划；
- 不得发生量子反弹；
- 不得解释弥娅所在时代的完整宇宙位置；
- 不得引入静默、公开或有限公开政策；
- 不得让维因预见全部历史。

## 12. 第二卷《诸维之墓》

### 12.1 卷级任务

第二卷必须完成：

- 降维技术复制和战略化；
- 防御性降维成为文明保存方案；
- 五次后续维数下降；
- 每次维数下降造成不同文明能力损失；
- 维度难民和文明删减；
- 维因的防御研究再次被武器化；
- 维因删除和封锁知识失败；
- 维因转向保存历史因果；
- 维因退出主动历史；
- 三维空间形成；
- 黑暗森林从物理条件和历史经验中形成；
- 质量归还获得大范围回应；
- 回声计划完成；
- 旧宇宙坍缩并发生量子反弹；
- 弥娅、赫森和伊蓝进入新宇宙主线；
- 第三层实验必要性被确认。

### 12.2 卷级核心问题

> 当停止研究会让现存文明失去防御机会，而继续研究必然降低下一次降维门槛时，维因还应不应该继续工作？

答案必须分阶段变化：

```text
继续研究具有现实必要性
→ 防御成果变成新武器
→ 删除和封锁成为尝试
→ 独立推导证明知识无法回到未知
→ 修复和消除都失败
→ 责任转向保存因果教训
```

### 12.3 六次维数下降的差异化任务

| 变化 | 主要文明损失 | 叙事重点 |
|---|---|---|
| `S9→S8` | 高维连接与交通网络 | 事故转为战略武器 |
| `S8→S7` | 稳定材料和高维化学 | 文明重新设计物质基础 |
| `S7→S6` | 高并行计算和群体意识 | 文明决定删除哪些知识 |
| `S6→S5` | 复杂生命结构 | 保存文明与保存个体分离 |
| `S5→S4` | 高维交通和统一治理 | 距离与信息延迟回归 |
| `S4→S3` | 公开可见性和实时确认 | 隐藏、猜疑与先发制人成熟 |

### 12.4 卷首输入

- 事故资料已经公开；
- 多文明开始复现；

- 结尾异常来源。

## 32. 全书结尾永久未知

以下信息不得在正文、附录、后记式情节或角色推断中获得确定答案：

- 遥远异常是自然相变、实验还是攻击；
- 哪个文明最先完成武器化；
- 有限公开延缓了多少时间；
- 新宇宙是否必然重复旧宇宙；
- 黑暗森林是否能够永久消除；
- 宇宙是否存在更早周期；
- 十维回声是否是唯一跨反弹警告。

## 33. 信息揭示违规处理

若低优先级文件提前泄露后续真相，应优先：

1. 删除确定性解释；
2. 将结论改为观测；
3. 将单一解释改为多模型；
4. 限制视角人物权限；
5. 把信息移至正式回收位置；
6. 更新 `revisions/continuity-issues.md`。

不得通过新增失忆、欺骗旁白或“此前所有资料都是假的”修复泄露问题。

# 第十一部分　视角与叙事规则

## 47. 视角基本规则

- 一章原则上只保留一个主要视角；
- 特殊宇宙尺度章节可以无人物，但不得连续大量使用；
- 主视角只能知道机构、设备和时代允许的信息；
- 不使用全知旁白提前确认尚未揭示的真相；
- 旧宇宙跨纪元叙事应使用接力视角，不让单个人物覆盖全部历史；
- 弥娅线必须通过证据推进，不通过感应推进。

## 48. 第一卷视角结构

推荐：

- 维因及旧宇宙相关视角约四分之三；
- 弥娅约四分之一；
- 首个受灾殖民文明可获得有限独立视角；
- 双线切换必须形成问题、观测或因果对应。

## 49. 第二卷视角结构

推荐：

- 旧宇宙历史约八成；
- 新宇宙解码约两成；
- 维因只覆盖其真实生命和活跃时期；
- 后续历史由难民、材料设计者、治理者、三维文明记录者、归还者和回声工程参与者接力；
- 不以编年史旁白代替人物选择。

## 50. 第三卷视角结构

核心视角固定围绕：

- 弥娅；
- 赫森；
- 伊蓝；
- 少量实验、审查、监测或公共网络配角。

事故段必须保持连续，不频繁插入无关文明支线。

政策段必须通过：

- 权限变化；
- 数据版本；
- 设施关闭；
- 监测部署；
- 坐标精度变化；
- 广播行为；
- 研究迁移；

表现冲突，不得写成连续会议演讲。

## 51. 宇宙尺度叙事

允许无人物叙事的场景：

- 大范围维数变化；
- 旧宇宙坍缩；
- 量子反弹；
- 新宇宙重新展开；
- 无法由单一角色观测的长期统计变化。

无人物叙事仍必须受限于：

- 可描述的物理过程；
- 已建立的观测框架；
- 当前揭示顺序；
- 不赋予宇宙人格；
- 不宣称未知解释为确定事实。

# 第十二部分　战争、灾难与文明损失

## 52. 战争描写原则

降维战争不得写成：

- 舰队数字竞赛；
- 能量束颜色和爆炸规模竞赛；
- 单一英雄摧毁敌方终极装置；
- 军事领袖通过一次奇袭结束战争；
- 维度武器像常规炸弹一样只影响目标区域。

重点必须是：

- 武器改变物理环境；
- 防御决策制造更长期风险；
- 文明失去基础能力；
- 信息延迟造成错误判断；
- 逃亡者必须删减自身；
- 技术存在本身改变所有参与者行为。

## 53. 六次维数下降不得重复

每次降维的主要损失固定不同：

1. 连接；
2. 材料；
3. 计算；
4. 生命；
5. 治理；
6. 信任。

视觉描写必须服务于这种差异，不能反复使用“物体被压扁”“建筑碎裂”“世界变薄”作为唯一表现。

## 54. 个体尺度锚点

每次宏观灾难至少保留一个个体或小群体尺度锚点，例如：

- 无法随交通网络撤离的结构中心；
- 必须被材料重构方案排除的生命类型；
- 在计算删减中被删除的历史库；
- 主动低维化后不再被法律承认为原个体的幸存者；
- 因通信延迟收到已经失效命令的治理节点；
- 归还质量前最后关闭小宇宙的记录者。

个体锚点不得转化为“一个人的爱情决定宇宙命运”。

# 第十三部分　知识治理结构

## 55. 全书三次知识治理失败

### 55.1 第一次：事故公开

目的：

- 警告其他文明；
- 共享风险；
- 防止重复。

失败方式：

- 资料成为复制基础。

### 55.2 第二次：旧宇宙封锁和删除

目的：

- 降低武器化门槛；
- 消除关键工程参数。

失败方式：

- 多文明已经掌握；
- 理论可独立推导；
- 删除制造技术垄断；
- 防御需求持续存在。

### 55.3 第三次：新宇宙完整删除或完整公开

完整删除失败：

- 多文明见证；
- 自动求援记录；
- 缓存和审计副本；
- 已经理解理论的人；
- 外部独立重建。

完整公开失败：

- 不完整资料可被拼接；
- 工程门槛显著下降；
- 透明不能自动建立信任。

## 56. 有限公开四层结构

最终方案应保持四层区分：

### 第一层：历史事实

公开：

- 旧宇宙存在；
- 连续降维；
- 文明损失；
- 量子反弹；
- 回声来源的统计证据。

### 第二层：观测证据

公开：

- 可重复观测；
- 纠错结构；
- 事故观测结果；
- 永久缺陷的非工程化测量。

### 第三层：理论边界

有限公开：

- 降维可能性；
- 不可逆性；
- 风险条件；
- 不足以直接计算成核阈值的验证关系。

### 第四层：工程参数

继续封锁：

- 真空势具体参数；
- 成核阈值；
- 场调制结构；
- 边界稳定算法；
- 扩展和投送方法；
- 设备配置。

有限公开不等于这些参数永远不会被发现。

## 57. 公共回声验证网络

网络只能承担：

- 保存公共历史证据；
- 提供独立验证；
- 防止单一机构篡改；
- 标记证据与解释；
- 记录版本和审计链。

网络不得承担：

- 全宇宙政府；
- 强制关闭所有实验；
- 储存完整工程参数；
- 自动判断异常为敌对行为；
- 预测未来；
- 保证永久和平。

- 所有文明重新互信；
- 历史已经拯救未来。


低优先级内容不得反向修改高优先级结论。

## 66. 修改 Master Outline 的条件

只有以下情况需要修改本文件：

- Canon 正式变更；
- 三卷功能重新分配；
- 卷间接口发生变化；
- 核心人物跨卷弧线调整；
- 全书信息揭示顺序改变；
- 跨卷伏笔回收位置改变；
- 全书结局含义改变；
- 正式原创边界调整。

以下变化通常不需要修改本文件：

- 单章标题调整；
- 配角姓名变化；
- 场景地点变化；
- 单章篇幅变化；
- 不影响卷级结构的章节拆分或合并；
- 技术外观变化；
- 对话和具体描写修订。

## 67. 修改卷纲时的影响检查

修改任一卷级大纲前必须检查：

1. 是否改变卷首输入；
2. 是否改变卷末输出；
3. 是否破坏下一卷起点；
4. 是否提前泄露后卷信息；
5. 是否改变人物必要选择；
6. 是否删除科学概念的首次引入；
7. 是否造成伏笔无回收；
8. 是否让某一方案显得绝对正确；
9. 是否新增无代价技术；
10. 是否改变终局不确定性。

## 68. 修改章节时的影响检查

- 时间线和空间维数正确；

- 人物存在能够拒绝的替代方案；
- 选择产生具体代价；
- 新增信息未越过揭示阶段；
- 伏笔有明确回收位置；

- 不反向改变卷级结论。

# 第十八部分　全书最终摘要

## 77. 三卷一句话

### 第一卷《第十个方向》

一项为终止战争而设计的可撤销空间隔离工程，制造了第一个不可逆扩张的低维真空泡，而公开警告让技术第一次成为可复制知识。

### 第二卷《诸维之墓》

文明为了防御、保存和延续不断主动或被动降低自身维度，直到宇宙只剩三维并形成黑暗森林；旧宇宙最终只能把失败的因果压缩成回声送往量子反弹之后。

### 第三卷《重启之后》

新宇宙为验证警告重新制造降维现象，并在数据无法删除后陷入静默与公开的双重风险，只能以有限公开延长选择时间，随后面对一个无法确认来源的空间自由度异常。

## 78. 全书因果摘要

```text
维因试图用工程结束战争
→ 工程改变真空状态
→ 事故被公开
→ 知识开始复制
→ 防御推动连续降维
→ 三维环境形成黑暗森林
→ 旧宇宙在归还质量后坍缩
→ 回声穿越量子反弹
→ 弥娅发现并解码历史
→ 验证历史重新制造危险
→ 数据扩散引发知识治理冲突
→ 有限公开暂时降低风险
→ 文明开始按最坏可能重新组织
```

## 79. 四名人物最终位置

| 人物 | 起点 | 终点 |
|---|---|---|
| 维因 | 相信工程可以隔离战争 | 承认无法修复宇宙，只能保存错误因果 |
| 弥娅 | 相信完整理解是科学责任 | 接受理解必须分层，目标只是延长选择时间 |
| 赫森 | 相信集中控制可以管理风险 | 接受公共验证，但首先降低自身暴露 |
| 伊蓝 | 相信透明能够消除垄断 | 接受部分参数延迟传播，继续保护公共验证权 |

## 80. 全书最终固定含义

《十维回声》不是关于谁拥有最强降维武器。

它讲述：

- 科学发现如何改变政治选择；
- 防御如何制造下一件武器；
- 文明保存为何必然伴随删减；
- 历史证据为何同时具有危险；
- 安全为什么需要权力；
- 权力为什么又会制造不信任；
- 公开为什么能够保护真相；
- 公开为什么也会降低危险门槛；
- 知道毁灭方式为什么仍不足以避免毁灭。

全书最后留下的不是答案，而是一种被延长的责任：

> 宇宙重新获得了十维，但它没有重新获得无知。
