# 二、戏剧发动机

## 3. 主视角目标

- **表面任务：** 建立能同时呈现持续战争、节点摧毁、撤离和真空风险的决策模型，并决定闭锁是否值得继续。
- **深层需要：** 承认不可知风险不能被平均值消失，同时不以“不确定”为借口逃避现实伤亡。
- **时间压力：** 边境伤亡和断供数据按周期增加，授权者要求在下一预算窗口前筛掉至少两种方案。
- **不行动代价：** 工程选择将由政治压力和确定伤亡单独决定，真空风险既不会被理解也不会消失。

## 4. 核心阻力

- **主要阻力：** 确定伤亡有高质量数据，真空相风险只有模型上限；任何统一数字都会伪装未知。
- **阻力类型：** 认知 + 制度
- **原方案失效点：** 第2场景暴露被忽略变量：极低概率、宇宙尺度且不可逆的后果不能由平均值与日常伤亡完全互换。

## 5. 核心问题

> 如何比较持续发生的确定伤亡与概率极低、后果极高的真空相风险？

## 6. 初始判断与误判

| 项目 | 内容 |
|---|---|
| 初始模型 | 把所有结果换算为统一期望损失，就能比较四种方案并得到客观排序。 |
| 忽略的变量 | 极低概率、宇宙尺度且不可逆的后果不能由平均值与日常伤亡完全互换。 |
| 首次暴露 | 场景2 |
| 章末修正 | 保留可计算比较，但把不可逆后果、证据缺口和否决阈值单列，不允许被平均掉。 |
| 仍保留的未知 | 宏观真空相自维持的真实概率，因为没有任何实测样本。 |

## 7. 可选方案与选择

| 方案 | 具体行动 | 现实收益 | 具体代价 |
|---|---|---|---|
| A 单一期望值 | 将所有损失压成一个平均数排序 | 决策快速、易向授权者说明 | 不可逆尾部风险被低概率掩盖 |
| B 禁止比较 | 因未知风险拒绝继续工程评估 | 避免用虚假精度授权实验 | 持续战争和节点摧毁自动胜出 |
| C 分层区间 | 比较确定损失，同时把不可逆风险与证据缺口单列 | 保留决策能力和否决条件 | 结论更复杂且不能给出“绝对安全” |

- **最终选择：** 维因接受风险可以比较但不能被一个平均值抹平，仍判断继续工程比放任冲突更可接受。
- **选择发生：** 场景3
- **立即代价：** 维因修改模型后，闭锁方案失去原先最漂亮的低损失排名，项目审查被延长。
- **延迟代价：** 工程署将以后用这套框架为真实成核授权，模型遗漏会成为他的专业责任。

# 七、正文执行

## 14. 开场、锚点与收束

- **开场动作/异常：** 模型第一次运行给出一个精确到六位的排名，最危险的一项却没有任何概率值。
- **视觉或感官锚点：** 损失模型里那一格空白概率
- **首次含义：** 数据缺失导致的暂时技术问题
- **章末含义：** 所有后续授权都无法消除的未知类别
- **章节最后画面/动作：** 所有已知模型都给出可接受区间，但审计者在结论后保留了一项没有概率值的条目：宏观真空相自维持。

## 15. 本章专属要求与禁区

**必须做到：**
- 让维因认真提高风险标准。
- 让持续战争的确定伤亡保持压力。
- 让审计者反对意见被正式保留。

**不得出现：**
- 不得让模型证明实验绝对安全。
- 不得把政治压力写成直接造假命令。
- 不得提前确认宏观泡必然自持。
