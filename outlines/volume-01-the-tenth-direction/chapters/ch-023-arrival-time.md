# 二、戏剧发动机

## 3. 主视角目标

- **表面任务：** 在本地节点持续失稳的窗口内分配撤离运力，并建立远距撤离、结构压缩和留守记录三条保存轨道。
- **深层需要：** 把“保存更多生命”从权限排序改成文明功能与个体连续性之间的公开选择。
- **时间压力：** 每关闭一个漂移节点都减少运力，泡壁到达估计还在提前。
- **不行动代价：** 高权限完整个体先占满路径，剩余人口和维持生命所需设施同时失去机会。

## 4. 核心阻力

- **主要阻力：** 质量、路径、认证和时间都有限；任何名单都在“生命数量”和“文明延续条件”之间排除另一类对象。
- **阻力类型：** 资源 + 制度
- **原方案失效点：** 第3场景暴露被忽略变量：没有基础设施、生命种子和身份档案，完整个体到达远方也无法维持文明或后续人口。

## 5. 核心问题

> 当预警无法显著领先近光速泡壁时，交通网络还能完成哪些撤离，哪些任务在物理上已经来不及？

## 6. 初始判断与误判

| 项目 | 内容 |
|---|---|
| 初始模型 | 把所有稳定路径用于撤离最多完整个体，能最大化可计数的幸存者。 |
| 忽略的变量 | 没有基础设施、生命种子和身份档案，完整个体到达远方也无法维持文明或后续人口。 |
| 首次暴露 | 场景3 |
| 章末修正 | 建立三轨保存并公开运力权衡，不允许单一高权限名单独占最后路径。 |
| 仍保留的未知 | 结构压缩载体能保存多少主体连续性，留守广播能否离开泡壁。 |

## 7. 可选方案与选择

| 方案 | 具体行动 | 现实收益 | 具体代价 |
|---|---|---|---|
| A 完整个体优先 | 按当前身份权限撤离最多完整生命 | 立即幸存人数清晰 | 基础设施和低权限群体被放弃 |
| B 文明设施优先 | 优先运走生命种子、制造系统和档案 | 提高长期重建概率 | 大量现存个体无撤离席位 |
| C 三轨分配 | 拆分远距撤离、低维压缩和留守记录 | 分散失败模式并保留多类连续性 | 每条轨道都只能部分成功 |

- **最终选择：** 交通协调者拒绝把全部运力用于撤离少数高权限完整个体，保留部分运力运输文明基础设施与生命载体。
- **选择发生：** 场景4
- **立即代价：** 交通协调者撤销既有权限排序，亲自承担重新分配造成的延误与反对。
- **延迟代价：** 三轨方案把更残酷的“保存什么”问题交给身份档案系统。

- **地点/时间：** 殖民文明预警接收室 / 旧宇宙 / O-B05 / S9，泡壁接近
- **在场人物：** 首个受灾殖民文明的交通协调者（章节级配角，姓名待定）、高权限撤离代表
- **入场条件：** 工程署向殖民文明发送最高级别预警和全部必要风险数据
- **具体行动：** 殖民文明的交通协调者接收工程署预警并核对本地异常
- **反作用力：** 预警来源正是事故制造机构，可信度与责任纠缠。
- **科学/制度载体：** 工程署预警校验包
- **状态变化：** 本地治理机构仍决定按最坏区间行动。
- **可见代价：** 必须相信事故制造者提供的预警数据

# 七、正文执行

## 14. 开场、锚点与收束

- **开场动作/异常：** 工程署的预警尚未播完，本地一条联径路径已经从稳定列表里消失。
- **视觉或感官锚点：** 不断缩短的最后路径质量表
- **首次含义：** 还能带走多少人的技术数字
- **章末含义：** 变成生命、设施与记录互不兼容的选择表
- **章节最后画面/动作：** 最后一条稳定路径能够带走的质量，被换算成两种互不兼容的名单：生命，或保存生命所需的设施。

## 15. 本章专属要求与禁区

**必须做到：**
- 殖民文明必须自主验证预警。
- 撤离受质量、路径和认证共同限制。
- 三轨方案各有真实失败风险。

**不得出现：**
- 不得让工程署远程指挥殖民文明。
- 不得完成全员撤离。
- 不得提前出现成熟无损低维化。
