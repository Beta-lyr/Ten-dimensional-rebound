# 二、戏剧发动机

## 3. 主视角目标

- **表面任务：** 整合纠错、年代、初始条件与信息处理证据，形成“当前宇宙之前存在过可留下结构的宇宙阶段”的第一层证明。
- **深层需要：** 在获得改变宇宙观的结论时，仍拒绝补写发送者、目的和完整历史。
- **时间压力：** 多个节点已各自接近结论；若没有共同最小表述，公共发布会碎裂成互相矛盾的版本。
- **不行动代价：** 前宇宙假说被安全机构、宗教解释或学术宣传分别占用，证据层级失去统一。

## 4. 核心阻力

- **主要阻力：** 不同节点的证据形式和结论强度不同，必须找到不依赖单一设备与过度解释的共同交集。
- **阻力类型：** 认知 + 制度
- **原方案失效点：** 第2场景暴露被忽略变量：能证明的是前一宇宙阶段和信息处理能力，不能证明文明类型、具体发送者或通信意图。

## 5. 核心问题

> 哪些证据足以从‘早于文明的异常’推进到‘当前宇宙之前存在过具有信息处理能力的宇宙阶段’？

## 6. 初始判断与误判

| 项目 | 内容 |
|---|---|
| 初始模型 | 纠错和年代证据的简单叠加已足以证明旧宇宙文明发送了信息。 |
| 忽略的变量 | 能证明的是前一宇宙阶段和信息处理能力，不能证明文明类型、具体发送者或通信意图。 |
| 首次暴露 | 场景2 |
| 章末修正 | 签署最低但确定的存在证明，并把剩余结构定义为待解码历史骨架。 |
| 仍保留的未知 | 旧宇宙经历了什么、如何跨越阶段、整数关系代表什么。 |

## 7. 可选方案与选择

| 方案 | 具体行动 | 现实收益 | 具体代价 |
|---|---|---|---|
| A 强叙事结论 | 宣布发现旧宇宙文明的主动消息 | 公众易理解且研究目标清晰 | 超出证据并固定发送者意图 |
| B 继续保留内部 | 等待整数和历史内容解开再发布 | 避免不完整结论 | 让单一机构垄断宇宙史起点 |
| C 最小存在证明 | 公布前宇宙阶段与结构化初始条件，明确低带宽限制 | 结论可独立验证且不过界 | 留下大量公众无法立即回答的问题 |

- **最终选择：** 弥娅签署存在证明并允许跨文明公布，同时明确不把未知历史解释为神意、预言或人格信息。
- **选择发生：** 场景4
- **立即代价：** 弥娅删除所有人格化和目的性措辞，接受一个比她私下模型更弱的公共结论。
- **延迟代价：** 存在证明使整数关系和剩余结构获得全球资源，也开启危险历史重建。
