# 二、戏剧发动机

## 3. 主视角目标

- **表面任务：** 通过宇宙演化和相位关系判断R-17最晚形成时间，排除当前文明后期写入模型。
- **深层需要：** 在研究开始具有安全含义时，继续保护竞争假说和可独立验证的方法。
- **时间压力：** 异常已经进入跨文明复核，机构必须决定是否把它纳入安全监测名单。
- **不行动代价：** 安全机构会按最坏解释限制数据，或学术网络按普通自然异常降低优先级。

## 4. 核心阻力

- **主要阻力：** 后期模型能拟合局部幅度，却无法同时满足九方向相位和宇宙演化；结论措辞又会改变安全权限。
- **阻力类型：** 认知 + 制度
- **原方案失效点：** 第3场景暴露被忽略变量：后期写入必须留下传播、能量或相位演化痕迹，无法与宇宙初始涨落完全共同演化。

## 5. 核心问题

> 如何判断异常是在宇宙初始条件中形成，还是由当前宇宙后期文明伪造？

## 6. 初始判断与误判

| 项目 | 内容 |
|---|---|
| 初始模型 | 若当前文明曾写入异常，经过足够复杂的高维路径也可能伪装成原初关联。 |
| 忽略的变量 | 后期写入必须留下传播、能量或相位演化痕迹，无法与宇宙初始涨落完全共同演化。 |
| 首次暴露 | 场景3 |
| 章末修正 | 确认异常最晚在宇宙极早期已存在，同时拒绝把“原初”直接等同于“前宇宙人工信息”。 |
| 仍保留的未知 | 异常是自然初始条件、未知量子引力遗迹，还是前一宇宙阶段留下的结构。 |

## 7. 可选方案与选择

| 方案 | 具体行动 | 现实收益 | 具体代价 |
|---|---|---|---|
| A 威胁信号 | 按人工后期写入处理并限制数据 | 提前防范未知文明活动 | 把未证实解释固化为安全事实 |
| B 普通异常 | 维持现有开放研究等级 | 避免安全机构介入 | 忽视异常早于文明的可能 |
| C 原初候选 | 公开年代检验，保留三类来源模型 | 允许独立复核并避免身份判断 | 研究权限更复杂且争议扩大 |

- **最终选择：** 弥娅同意进行来源年代审查，但反对安全机构提前把异常定义为威胁信号。
- **选择发生：** 场景4
- **立即代价：** 弥娅接受来源年代审查和额外权限记录，但阻止异常被直接列为敌对信号。
- **延迟代价：** 安全部门开始持续关注研究，第二卷治理分歧获得制度前兆。
