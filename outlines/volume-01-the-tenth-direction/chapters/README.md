## 使用说明

本目录只在每章文件中保存章节专属内容。下列通用规则不再逐章复制：

- Canon 与总纲优先级；
- 十维定义、局部光速、泡壁和工程不可逆规则；
- 通用原创边界；
- 通用场景删除测试；
- 通用正文验收清单。

编写正文前依次读取：

1. `canon/00-series-bible.md`；
2. `canon/01-physics-rules.md` 至 `canon/07-original-work-boundaries.md`；
3. `outlines/00-master-outline.md`；
4. 第一卷 `00-volume-outline.md` 与 `01-chapter-map.md`；
5. 本目录对应章节细纲。

## 场景共同标准

每个场景必须拥有具体目标、具体对象、合理阻力、状态转折、可见代价和下一场景交付物。只有世界观解释、可以任意交换顺序或可以原样复制到其他章节的场景应删除。

## 第一卷关键边界

- 第01—04章只建立异常与双线，不确认宇宙周期关系。
- 第05—15章证明工程具有现实理由，并让风险、替代方案和权限结构全部落地。
- 第16—20章完成真实成核、短期成功与恢复失败；事故不是低级操作错误。
- 第21—26章分别推进弥娅证据链与殖民文明自主选择。
- 第27—30章完成事故公开、复制启动、旧宇宙存在证明和递减序列。
- 第一卷不得进入成熟降维战争、黑暗森林、回声计划和量子反弹。
