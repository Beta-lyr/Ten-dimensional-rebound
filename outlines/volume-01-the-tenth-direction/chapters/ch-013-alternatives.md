# 二、戏剧发动机

## 3. 主视角目标

- **表面任务：** 在获得真实成核审查前，重新执行节点摧毁、引力屏障、同步撤离与局部闭锁的完整替代方案评估。
- **深层需要：** 证明支持闭锁不是因为项目投入或个人声誉，而是在更差选项中重新作出的选择。
- **时间压力：** 边境冲突已越过原损失区间，多方要求在本轮审查后进入启动或永久终止。
- **不行动代价：** 工程署会因沉没成本默认继续，或因恐惧默认回到节点摧毁，两种都缺乏新证据。

## 4. 核心阻力

- **主要阻力：** 每个替代方案都解决一部分风险并制造另一种确定损失，政治不信任又使同步执行方案无法成立。
- **阻力类型：** 制度 + 认知
- **原方案失效点：** 第1场景暴露被忽略变量：边境条件、撤离承诺和引力屏障技术都已变化，替代方案的成本必须重新计算。

## 5. 核心问题

> 为什么三种看似更保守的方案仍无法形成低伤亡、可持续的高维边界？

## 6. 初始判断与误判

| 项目 | 内容 |
|---|---|
| 初始模型 | 前期已否决的方案不值得重新审查，真正问题只剩闭锁系统是否通过测试。 |
| 忽略的变量 | 边境条件、撤离承诺和引力屏障技术都已变化，替代方案的成本必须重新计算。 |
| 首次暴露 | 场景1 |
| 章末修正 | 认真重算后仍确认闭锁是最低可证明损失方案，但附加完整恢复演练与多方启动条件。 |
| 仍保留的未知 | 真实成核是否会让理论优势在瞬间失效。 |

## 7. 可选方案与选择

| 方案 | 具体行动 | 现实收益 | 具体代价 |
|---|---|---|---|
| A 节点摧毁 | 定点摧毁争夺核心并重建外围网络 | 最快终止当前穿越 | 即时平民损失与长期交通崩解 |
| B 引力屏障 | 部署多层高曲率屏障 | 不改变真空相 | 仍可从额外方向绕行并伤害民用通行 |
| C 同步撤离 | 双方撤出并冻结区域 | 避免高风险实验 | 缺乏可信同步与身份验证 |
| D 局部闭锁 | 在严格中止链下执行真实成核 | 可能不毁物质地阻断通行 | 不可知的宏观相变尾部风险 |

- **最终选择：** 维因在记录中明确否决替代方案，但保留其失败条件，拒绝把闭锁方案描述成唯一真理。
- **选择发生：** 场景5
- **立即代价：** 维因再次支持闭锁，并要求把所有替代方案和反对意见附在启动文档中。
- **延迟代价：** 他失去“只是沿既定项目推进”的辩护，真实成核成为经过重新选择的责任。

# 七、正文执行

## 14. 开场、锚点与收束

- **开场动作/异常：** 审查桌上最先被重新打开的，正是工程署半年前已经盖章否决的节点摧毁方案。
- **视觉或感官锚点：** 四个方案的损失区间叠图
- **首次含义：** 证明没有无代价答案
- **章末含义：** 闭锁只是在已知选项中最低，而非安全
- **章节最后画面/动作：** 替代方案全部被否决后，报告的结论仍不是“安全”，而是“当前最低可证明损失”。

## 15. 本章专属要求与禁区

**必须做到：**
- 替代方案必须得到认真测试。
- 让同步撤离因可信执行失败而非角色愚蠢。
- 维因再次选择闭锁并承担责任。

**不得出现：**
- 不得把其他方案写成荒谬陪衬。
- 不得提前出现泡壁扩张。
- 不得让政治角色强迫造假。
