# 二、戏剧发动机

## 3. 主视角目标

- **表面任务：** 验证殖民文明残缺广播与工程监测是否指向同一泡壁过程，并决定向所有受威胁区域开放哪些风险资料。
- **深层需要：** 把责任从机构声誉和技术控制转向让其他文明拥有可行动的事实。
- **时间压力：** 更多区域进入未来光锥；每次等待完整解码都减少下一批预警领先量。
- **不行动代价：** 殖民广播被当作本地故障，其他文明无法独立识别泡壁与生命损失。

## 4. 核心阻力

- **主要阻力：** 残缺信号既不完整又包含独立证据；公开足够验证的数据必然降低部分理论门槛。
- **阻力类型：** 信息 + 制度
- **原方案失效点：** 第3场景暴露被忽略变量：事故制造者的结论缺乏独立可信度，受灾文明明确要求所有接收者验证记录。

## 5. 核心问题

> 一段来自降维后残缺载体的广播，如何证明结构损失真实，又为何不能还原完整个体和文明？

## 6. 初始判断与误判

| 项目 | 内容 |
|---|---|
| 初始模型 | 只要工程署发布结论和撤离指令，就能警告其他文明而不暴露技术。 |
| 忽略的变量 | 事故制造者的结论缺乏独立可信度，受灾文明明确要求所有接收者验证记录。 |
| 首次暴露 | 场景3 |
| 章末修正 | 公开传播模型、识别特征和生命损失时序，继续隐藏精确场参数与设备结构。 |
| 仍保留的未知 | 这些验证资料会让先进文明多快重建成核理论。 |

## 7. 可选方案与选择

| 方案 | 具体行动 | 现实收益 | 具体代价 |
|---|---|---|---|
| A 只发撤离结论 | 发布危险区与行动指令 | 传播快且技术暴露少 | 接收者无法验证事故真伪 |
| B 内部完整解码 | 等待恢复更多殖民广播再发布 | 减少误报与误解 | 错过其他区域预警窗口 |
| C 开放风险资料 | 发布泡壁识别、路径区间和生命损失数据 | 允许独立验证和本地行动 | 提供可供理论推导的结构信息 |

- **最终选择：** 维因不以机构声誉或技术保密为由延迟预警，转而公开泡壁识别、路径计算和生命损失数据。
- **选择发生：** 场景4
- **立即代价：** 维因放弃机构对事故叙事的控制，公开能够证明工程失败的原始时序。
- **延迟代价：** 第27—29章无法再把事故资料恢复为秘密，防御研究也将借此启动。

# 七、正文执行

## 14. 开场、锚点与收束

- **开场动作/异常：** 残缺广播第一次被解码成可读结构时，没有姓名，只有一串与工程监测完全相同的连接丢失顺序。
- **视觉或感官锚点：** 两条来自不同文明却重合的损失曲线
- **首次含义：** 判断广播真伪的技术对照
- **章末含义：** 证明任何只报结论的警告都不够
- **章节最后画面/动作：** 余波信号的最后一句不是请求救援，而是要求所有收到者独立验证工程署的记录。

## 15. 本章专属要求与禁区

**必须做到：**
- 让受灾文明广播保持独立主体性。
- 把公开字段与制造参数分开。
- 维因尚未形成成熟永久封锁立场。

**不得出现：**
- 不得恢复完整发送者人格。
- 不得公开完整设备图纸。
- 不得让广播宽恕或单纯控诉维因。
