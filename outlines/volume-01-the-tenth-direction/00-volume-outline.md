# 第一部分　第一卷创作契约

## 1. 卷定位

第一卷负责建立：

1. 完整十维时空中的高维文明日常；
2. 高维开放秩序为何在当时具有现实基础；
3. 维因参与的局部维度闭锁工程为何被视为合理方案；
4. 第一次人工降维如何从“工程成功”转化为不可逆灾难；
5. 事故警告为何同时成为技术传播起点；
6. 弥娅如何在另一个宇宙周期中证明旧宇宙存在。

第一卷不是全面战争卷，也不是旧宇宙历史总结卷。

它必须聚焦一个有限、清晰且不可撤销的起点：

> 一项被设计为终止战争的非杀伤性边界技术，如何创造出战争再也无法停止的物理条件。

## 2. 核心戏剧问题

第一卷的核心戏剧问题是：

> 当一项实验同时具有真实的人道价值、可验证的科学依据和不可完全测量的灾难风险时，维因是否有足够理由允许它发生？

卷内给出的答案必须是：

- 他在当时拥有足够理由支持实验；
- 他的判断仍然造成了不可逆后果；
- 后果不能被归结为一个低级错误；
- 事故后的正确选择仍会制造下一层危险。

第一卷不回答：

- 降维战争是否必然发生；
- 黑暗森林是否不可避免；
- 知识应当永久封锁还是完全公开；
- 新宇宙能否避免旧宇宙历史；
- 十维回声由谁建立；
- 旧宇宙如何完成量子反弹。

## 3. 卷内主题命题

第一卷的主题不应由人物直接演讲，而应通过四次选择逐步形成：

1. **接受工程：**用物理边界替代军事毁灭；
2. **继续观测：**在事故发生后保留控制和测量能力；
3. **组织救援：**承认相变正在威胁无关文明；
4. **公开警告：**让所有文明知道风险，同时让它们获得复现路径。

卷末形成的主题结论是：

> 技术的危险不只来自它被错误使用，也来自它一旦被证明可行，便会永久改变所有文明的选择空间。

## 4. 第一卷的读者体验目标

读者在本卷中应依次经历：

1. 对高维宇宙的陌生感；
2. 对开放文明秩序的可信感；
3. 对隔离工程目标的认同或至少理解；
4. 对实验成功的短暂释放；
5. 对“装置已关闭但过程仍在继续”的认知反转；
6. 对近光速泡壁和有限预警的压迫感；
7. 对首个殖民文明毁灭的具体损失感；
8. 对公开警告的道德必要性感；
9. 对警告变成复制资料的寒意；
10. 对弥娅所见递减序列的历史尺度恐惧。

不得让读者在实验前就把维因团队视为明显愚蠢或邪恶。

不得让读者在卷末获得“只要维因不公开就不会有战争”的简单答案。

# 第二部分　范围、规模与结构基线

## 5. 固定时间范围

### 5.1 旧宇宙线

第一卷旧宇宙线固定覆盖：

```text
O-A03 → O-A04 → O-A05 → O-B01 → O-B02 → O-B03 → O-B04 → O-B05 → O-B06 → O-B07 → O-B08
```

空间环境为：

```text
外部 S9；第一次实验区及其扩张区域转为 S8
```

第一卷旧宇宙线不得完整进入 `O-C01` 之后的早期军备化过程。

卷末只允许出现：

- 至少三个文明体系开始独立复现；
- 降维研究项目被重新启动或获得授权；
- 事故数据被转入军事和防御研究；
- 维因意识到公开警告已经越过其控制范围。

不得在第一卷展示成熟的战略降维武器、连续维度战争或主动低维化文明体系。

### 5.2 弥娅线

第一卷弥娅线固定覆盖：

```text
N-B04 → N-C01 → N-C02 → N-C03 → N-C04 → N-C05 → N-C06
```

空间环境始终为新宇宙 `S9`。

卷内叙事可以在内部文档中标记为“新宇宙线”，但正文前中段不得直接告诉读者：

- 弥娅处于量子反弹后的新宇宙；
- 旧宇宙已经完成坍缩；
- 十维回声由旧宇宙文明主动制造；
- 维因与异常结构存在何种具体关系。

第一卷末只确认：

> 当前宇宙之前存在过另一个宇宙阶段。

弥娅同时识别宏观空间维数递减序列，但尚不能还原战争过程。

## 6. 章节规模基线

第一卷按 **30 章** 规划。

允许在编写 `01-chapter-map.md` 时于 **28—32 章**之间调整，但必须保持六个阶段的相对比例和关键事件顺序。

建议篇幅：

- 中文正文约 18 万至 24 万字；
- 单章以完成一个主要科学问题和一个人物选择为准；
- 不以统一章长作为硬性标准；
- 实验、救援和广播阶段允许使用较短章节增加因果压力；
- 高维日常与工程准备阶段可使用较长章节建立空间和制度可信度。

章节总数与篇幅属于卷级规划，不属于不可修改物理 Canon。调整时不得牺牲关键因果节点。

## 7. 双时间线比例

推荐比例：

| 时间线 | 章节占比 | 叙事功能 |
|---|---:|---|
| 旧宇宙维因线 | 约 73%—77% | 推动真实历史和不可逆因果 |
| 弥娅线 | 约 23%—27% | 建立谜团、验证结构和卷末揭示 |

弥娅线不是与维因线等量并行的第二主线。

旧宇宙线回答“事情怎样发生”。

弥娅线回答“一个后来者怎样证明这些事情曾经发生”。

两条线不得通过梦境、意识、预言、量子感应或实时通信发生联系。

## 8. 六阶段结构

第一卷采用以下六阶段：

| 阶段 | 建议章节 | 暂定阶段名 | 主要功能 |
|---|---:|---|---|
| 第一阶段 | 1—4 | 背景噪声 | 建立异常、高维陌生感和双时间线 |
| 第二阶段 | 5—9 | 开放路径 | 建立开放宇宙、冲突背景与工程合理性 |
| 第三阶段 | 10—15 | 可撤销边界 | 完成工程设计、风险审查和启动授权 |
| 第四阶段 | 16—20 | 第十个方向 | 第一次人工降维、表面成功与恢复失败 |
| 第五阶段 | 21—26 | 泡壁 | 确认扩张、组织救援并发生首次文明级灾难 |
| 第六阶段 | 27—30 | 警告 | 公开事故、技术扩散和旧宇宙存在证明 |

前三章标题与基本功能固定为：

1. `ch-001-background-noise.md`：《背景噪声》；
2. `ch-002-open-universe.md`：《开放宇宙》；
3. `ch-003-boundary-project.md`：《边界工程》。

后续章节标题在 `01-chapter-map.md` 中确定。

# 第三部分　双时间线叙事规则

## 9. 两条线的结构关系

两条时间线采用“因果线—证据线”结构，而不是普通的双主角平行冒险结构。

### 9.1 维因线：因果线

维因线必须连续展示：

```text
文明冲突存在
→ 非杀伤隔离具有现实需求
→ 闭锁工程获得多方授权
→ 第一次人工成核成功
→ 恢复序列失败
→ 低维泡自发扩张
→ 无关殖民文明进入路径
→ 救援无法保存全部生命
→ 事故数据被公开
→ 其他文明开始复现
```

任一箭头不得省略为旁白结论。

### 9.2 弥娅线：证据线

弥娅线必须连续展示：

```text
发现异常相关性
→ 排除单一仪器误差
→ 多节点重复观测
→ 识别低复杂度与纠错结构
→ 排除新宇宙已知文明来源
→ 证明异常早于当前宇宙文明
→ 完成存在证明
→ 识别维数递减序列
```

弥娅不得因为某个直觉、梦境或单次观测直接相信旧宇宙。

## 10. 交叉剪辑原则

时间线切换必须满足至少一个功能：

- 前一条线提出一个问题，后一条线提供另一尺度上的观测；
- 前一条线作出一个决定，后一条线展示其遥远历史痕迹；
- 前一条线得到短暂成功，后一条线出现与成功不相容的异常；
- 前一条线失去信息，后一条线展示信息经过极端压缩后的残余；
- 两条线共同强化同一主题，但不直接解释彼此。

禁止使用：

- 相同台词跨时代机械重复；
- 维因刚触碰设备，弥娅立刻“感应”到波动；
- 毫无因果关系的纯形式蒙太奇；
- 为制造悬疑故意截断已经可以自然说明的信息；
- 通过章节标题提前标明“旧宇宙”“新宇宙”。

## 11. 时间线识别策略

### 11.1 对作者和大纲

所有章节大纲必须明确标记：

- `旧宇宙 / O-A 或 O-B / S9 或局部 S8`；
- `新宇宙 / N-B 或 N-C / S9`。

### 11.2 对正文读者

正文前段不直接使用“旧宇宙”“新宇宙”作为章节标签。

读者应通过以下差异逐步判断：

- 两条线拥有不同的机构、技术接口和社会结构；
- 弥娅线中的宇宙学问题与维因线中的工程问题并不处于同一社会事件中；
- 弥娅观测到的异常早于所有已知文明；
- 两条线之间没有可建立普通因果通信的时间关系；
- 卷末“当前宇宙不是第一个宇宙”才完成明确分类。

不得依赖刻意隐瞒明显事实欺骗读者。

读者可以较早怀疑两条线不同时，但不应在第一阶段就获得确定答案。

# 第四部分　第一阶段：背景噪声（建议第 1—4 章）

## 12. 阶段任务

第一阶段负责：

- 以弥娅的异常观测打开全书；
- 建立新宇宙高维观测工作的可信感；
- 转入维因所在的完整十维开放宇宙；
- 让读者理解高维不是神秘空间，而是具有更多运动、连接和工程方向的物理环境；
- 引出边境冲突与维度隔离工程；
- 固定维因主动加入工程，而非被强迫制造武器。

## 13. 第一章锚点：《背景噪声》

**时间线：** `N-B04—N-C01`  
**视角：** 弥娅  
**核心科学问题：** 相隔超出普通因果接触范围的原初区域，为何出现统计对应？  
**人物选择：** 弥娅选择保留并继续复核一组不稳定、尚不足以发表的异常结果。

本章必须完成：

- 展示弥娅依赖多节点原初关联观测网络，而非单人望远镜；
- 通过观测流程体现九个宏观空间维度，但不进行百科式介绍；
- 异常首先表现为背景噪声中不该重复的相关关系；
- 给出至少两种自然解释或设备解释；
- 弥娅不宣布“人工信号”；
- 结尾出现一个在不同观测路径中保持不变的对应结构。

本章不得出现：

- “十维回声”正式名称；
- 旧宇宙、量子反弹、维因；
- 维数递减序列的完整含义；
- 任何跨宇宙人物声音。

## 14. 第二章锚点：《开放宇宙》

**时间线：** `O-A03—O-A04`  
**视角：** 维因  
**核心科学问题：** 九个宏观空间方向如何改变交通、边界和文明邻接？  
**人物选择：** 维因接受前往边境冲突区评估非杀伤隔离方案。

本章必须完成：

- 通过维因的移动、工作或会议展示高维交通，而不是先解释九维几何；
- 展示联径共同体如何由共享路径而非传统领土维持；
- 说明坐标公开在当时具有安全和经济收益；
- 展示冲突真实存在，但尚未形成黑暗森林；
- 提出传统封锁无法覆盖所有高维绕行路径的问题；
- 引入真空稳定性争议，但不立刻说明降维装置。

## 15. 第三章锚点：《边界工程》

**时间线：** `O-A04—O-A05`  
**视角：** 维因  
**核心科学问题：** 能否通过改变局部空间通行条件建立非杀伤边界？  
**人物选择：** 维因主动加入边界协调工程署并接受闭锁系统的边界设计职责。

本章必须完成：

- 明确工程的五项目标；
- 明确维因不是唯一发明者；
- 介绍边界协调工程署的多方授权性质；
- 让风险反对意见具有专业依据；
- 让支持工程的理由具有真实的人道价值；
- 结尾确定长期测绘和模型验证将开始。

## 16. 第四章功能

第四章建议返回弥娅线，完成 `N-C02` 的第一轮复核。

必须展示：

- 弥娅主动邀请独立节点检查数据；
- 一项看似足以解释异常的仪器误差被排除；
- 另一项自然模型仍然成立；
- 弥娅的研究尚未成为全宇宙事件；
- 结尾显示异常在一个更大尺度上重复。

## 17. 阶段人物状态

### 维因

阶段开始：

- 认为边境冲突可以被转化为工程约束；
- 相信高维交通开放是可维持秩序；
- 对真空风险保持专业谨慎，但不认为技术本身改变政治结构。

阶段结束：

- 主动承担闭锁边界设计；
- 接受“实验成功可以降低总体伤亡”的目标；
- 尚未作出成核决定。

### 弥娅

阶段开始：

- 只研究原初宇宙统计；
- 不相信跨宇宙信息已被证明。

阶段结束：

- 确认异常值得长期研究；
- 仍把它视为自然宇宙学或计量问题；
- 尚未提出人工编码结论。

## 18. 阶段结尾推动力

第一阶段结束时，应同时建立两个待解决问题：

1. 维因能否制造一条真正不可穿越、又可撤销的物理边界？
2. 弥娅所见的对应关系究竟是未知自然规律，还是某种结构化信息？

# 第五部分　第二阶段：开放路径（建议第 5—9 章）

## 19. 阶段任务

第二阶段负责让读者相信：

- 高维开放秩序不是幼稚乌托邦；
- 边境冲突也不是单纯善恶战争；
- 局部维度闭锁系统不是明显的灭绝装置；
- 真空稳定、开放扩张和独立防御三种立场均有现实基础；
- 工程获得批准的制度链比单一命令更复杂；
- 弥娅的异常开始表现出不易由自然噪声解释的结构。

## 20. 旧宇宙主要事件

本阶段应完成：

1. 展示边境冲突的实际伤亡或交通破坏；
2. 说明传统高维封锁会被额外路径绕过；
3. 说明直接摧毁交通节点会伤及大量非参战文明；
4. 建立局部维度闭锁的初步模型；
5. 介绍 `VAC-01` 至 `VAC-08` 的功能关系，但不一次性列出全部设备说明；
6. 让真空稳定派提出低能真空相可能自发扩张的警告；
7. 让支持者提供亚临界扰动会衰减的真实实验数据；
8. 确认实验区远离主要聚居区，但不存在绝对无风险区域；
9. 建立首个受灾殖民文明与实验区的拓扑距离，而不把它提前写成注定牺牲者。

## 21. 文明立场配置

本阶段至少出现以下三类功能角色：

### 21.1 开放扩张立场代表

主张：

- 实验和基础理论应接受跨文明复核；
- 可撤销边界比摧毁交通网络更符合开放秩序；
- 不能因未知风险永久冻结真空研究。

真实盲点：

- 低估技术资料脱离原治理结构后的复制速度。

### 21.2 真空稳定立场代表

主张：

- 高维真空可能只是亚稳态；
- 一旦出现更低能相，装置关闭不代表相变停止；
- 风险模型不能只依赖亚临界实验。

真实盲点：

- 无法给出可替代的低伤亡边境方案；
- 其限制政策会被部分文明视为技术垄断。

### 21.3 独立防御立场代表

主张：

- 任何统一工程都可能被某一方控制；
- 各文明应保留自主边界和撤离能力；
- 工程参数不应完全公开。

真实盲点：

- 自主复现和秘密防御会降低共同监督能力。

三类角色不必固定为三个单一人物，也不得被写成未来阵营的简单预演。

## 22. 维因的关键选择

维因必须在本阶段完成两次主动选择：

### 22.1 接受可计算风险框架

他确认：

- 当前战争造成的确定损失正在持续；
- 闭锁实验具有低概率、极高后果风险；
- 多节点模型仍判断风险低于继续战争；
- 实验具有中止和恢复系统。

他据此继续工程，而非因为政治上级强迫。

### 22.2 保留外部审计

维因支持让非工程署节点获得部分观测权限。

这一选择：

- 增强实验可信度；
- 为事故后的独立确认保留条件；
- 也使后续数据更难被单一机构完全封锁。

## 23. 弥娅线推进

弥娅线在本阶段应推进至 `N-C03` 前半：

- 多尺度数据中出现重复但不完全相同的结构；
- 局部缺失后，其他区域可以补全部分关系；
- 异常复杂度低于随机模型预期；
- 弥娅开始怀疑其具有纠错功能；
- 她仍优先寻找自然机制；
- 她决定公开观测方法和统计检验，而非公开未经证明的结论。

## 24. 科学概念顺序

本阶段重点建立：

1. 高维测地线和联径节点；
2. 高维边界为何难以封闭；
3. 维度模场和局部空间本征方向；
4. 亚稳真空和相变势垒；
5. 亚临界扰动与真正成核的区别；
6. 多尺度纠错结构的统计含义。

不得在本阶段完整解释低维泡近光速扩张规律。

## 25. 阶段结尾推动力

第二阶段应以以下状态结束：

- 闭锁系统完成基本设计；
- 实验区长期测绘得到可接受结果；
- 风险争议没有消失，但工程进入正式验证流程；
- 弥娅第一次使用“编码假说”作为待检验模型；
- 两条线都从“是否存在问题”推进到“如何验证问题”。

# 第六部分　第三阶段：可撤销边界（建议第 10—15 章）

## 26. 阶段任务

第三阶段负责完成实验前的全部合理性建设。

读者必须清楚：

- 工程目标是什么；
- 各模块分别能控制什么；
- 哪些风险已经被识别；
- 哪些风险只能通过真实成核检验；
- 谁拥有启动权限；
- 为什么最终仍然选择实验；
- 维因在哪些具体技术判断上承担责任。

## 27. 工程链展开

章节不应逐条照搬技术文档，而应通过故障、审查和协作展示八个模块：

| 模块 | 剧情展示方式 |
|---|---|
| `VAC-01` 真空状态层析阵列 | 不同节点对实验区真空势给出细微差异 |
| `VAC-02` 维度模态选择器 | 选择一个局部本征方向并处理交叉耦合 |
| `VAC-03` 维度模场激发器 | 分阶段提升功率，不能一次完成成核 |
| `VAC-04` 各向异性边界阵列 | 维因设计初始泡壁取向与边界梯度 |
| `VAC-05` 高维曲率锚定结构 | 保持实验区与交通路径的几何关系 |
| `VAC-06` 成核隔离腔 | 隔离普通物质过程，但不承诺限制真空相变 |
| `VAC-07` 泡壁监测网 | 建立局部和远程观测，暴露信号传播延迟 |
| `VAC-08` 恢复与中止系统 | 在亚临界测试中成功，在真正成核后失败 |

## 28. 实验前失败模式

本阶段至少安排三次没有造成灾难的失败或异常：

1. 模态交叉耦合导致测试中止；
2. 曲率锚定引起另一方向的应力积累；
3. 不同真空层析模型对低能相稳定性给出差异。

这些失败的功能是：

- 证明团队并非无视风险；
- 展示中止系统在成核前确实有效；
- 让维因逐步修正参数；
- 建立“过去可以中止”这一后来误判的经验基础。

不得用这些测试暗示真正成核后已经存在成功恢复样本。

## 29. 授权结构

正式实验启动必须经过：

- 工程署内部技术审查；
- 外部真空稳定风险审计；
- 实验区邻近节点的条件同意；
- 交通网络维护者确认撤离路径；
- 交战方接受临时停火窗口；
- 联径共同体工程担保；
- 多方授权签名同步生效。

没有单一人物拥有“一键启动”权力。

维因必须对以下内容给出肯定意见：

- 边界阵列达到设计精度；
- 曲率锚与交通网络兼容；
- 恢复序列在现有测试中有效；
- 风险模型未发现宏观自发扩张证据。

这使他对实验负有不可转移的责任，但不等于他独自决定全部工程。

## 30. 实验替代方案审查

为避免“为什么不做其他方案”的漏洞，本阶段必须明确审查并否决至少三种替代方案：

### 30.1 摧毁高维交通节点

缺点：

- 会切断大量非参战文明；
- 可能造成长期资源和医疗灾难；
- 节点可在其他方向重建；
- 无法真正结束边境冲突。

### 30.2 建立普通物质或引力屏障

缺点：

- 可被额外空间方向绕过；
- 所需规模和能量不可持续；
- 只能拖延，无法形成稳定隔离。

### 30.3 全面撤离争议区

缺点：

- 双方均不相信对方会同步撤离；
- 迁移本身会改变交通和资源均衡；
- 无法处理后续再次进入问题。

替代方案失败不能证明闭锁实验“必然正确”，只能解释它为何成为当时最可接受的方案。

## 31. 弥娅线推进

弥娅线推进至 `N-C03—N-C04`：

- 她证明纠错关系不是普通周期噪声；
- 异常在不同观测节点间保持结构，但幅度不同；
- 一部分学者支持未知自然机制；
- 一部分机构担心异常来自早期未知文明；
- 弥娅反对将异常立刻解释为威胁；
- 她设计一项可以排除“当前宇宙文明伪造”的时间来源检验。

赫森和伊蓝不得正式进入主线。

可以出现安全审查或开放科学争论的制度前兆，但不得由两名核心人物代表。

## 32. 阶段高潮：启动决定

第三阶段结尾固定为正式启动决定。

维因的选择必须建立在：

- 真实战争压力；
- 多轮成功中止测试；
- 多方模型的一致区间；
- 邻近文明的撤离准备；
- 对可撤销性的有限信心；
- 不进行实验同样会造成确定伤亡。

结尾不应表现为英雄式倒计时。

更合适的结束方式是：

- 多方授权依次完成；
- 交通网络进入实验静默；
- 维因确认恢复序列已加载；
- 成核区从普通空间中被测量系统单独标记；
- 下一阶段开始真正越过相变势垒。

# 第七部分　第四阶段：第十个方向（建议第 16—20 章）

## 33. 阶段任务

第四阶段是全卷中点和认知反转中心。

它必须依次完成：

1. 真正成核；
2. 人工降维在工程意义上成功；
3. 隔离目标短暂实现；
4. 恢复与中止系统启动；
5. 低维区域没有恢复；
6. 泡壁持续移动；
7. 团队从庆祝转入故障诊断；
8. 维因仍将问题视为可修复工程事故。

## 34. 第一次成核场景

第一次人工降维必须遵守：

- 没有传统爆炸；
- 没有神秘光芒替代物理过程；
- 一个传播自由度在实验区内消失；
- 不同方向的探针得到不对称响应；
- 部分设备连接因结构不可嵌入而中断；
- 泡内物质不再保持原高维结构；
- 外部仪器首先把结果判断为“闭锁成功”。

场景重点是仪器和几何关系发生改变，而不是能量奇观。

## 35. 标题意象“第十个方向”

“第十个方向”是卷名和文学意象，不是正式物理术语。

在本阶段，它可以承担三层含义：

1. 完整十维时空中原本被视为理所当然的自由；
2. 实验区中第一个不再能够被宏观物质使用的方向；
3. 文明为了建立边界而主动放弃的可能性。

正文不得把它解释为“第十个空间维度”。

角色在技术场景中应使用：

- 目标维度模态；
- 局部空间本征方向；
- 宏观空间自由度；
- 紧致化方向。

## 36. 表面成功

实验成功后必须给出短暂、真实的正面结果：

- 目标交通路径被阻断；
- 交战双方无法跨越闭锁区；
- 没有立即出现传统大规模伤亡；
- 工程署收到停火或谈判窗口延长的消息；
- 多个观测节点确认闭锁几何符合预期。

这一段不能省略。

只有让实验确实实现原目标，后续灾难才不是简单的“实验从一开始就失败”。

## 37. 恢复失败

恢复序列依次执行：

1. 停止外部激发；
2. 反向调制目标模态；
3. 降低边界梯度；
4. 释放曲率锚定；
5. 比较真空状态是否回到基线。

固定结果：

- 外部能量输入停止；
- 设备按设计关闭；
- 已成核低维相继续存在；
- 泡壁没有回到初始边界；
- 反向调制只扰动泡外区域；
- 低维泡已经跨过临界尺度。

维因的核心认知错误在此显现：

> 装置可以关闭，但新真空相已经不再属于装置。

## 38. 维因的阶段选择

恢复失败后，维因不能立即得出全部宇宙结论。

他必须选择：

- 保持泡壁监测网运行；
- 暂不完全切断所有设备，以继续获得数据；
- 尝试通过曲率和边界调整限制扩张；
- 向邻近交通节点发出风险升级通知；
- 反对把事故暂时掩盖为普通设备故障。

这一选择同时具有两面：

- 保留观测帮助确认扩张并组织撤离；
- 维因仍然相信更精确控制能够修复问题。

## 39. 弥娅线对应推进

本阶段弥娅完成时间来源检验的一部分：

- 异常结构不能由新宇宙已知文明在后期写入；
- 它与原初引力背景共同存在；
- 其统计年龄接近当前宇宙初始条件；
- “未知自然机制”和“前宇宙信息”成为主要竞争解释。

弥娅不得在本阶段已经证明旧宇宙存在。

## 40. 阶段结尾推动力

第四阶段结尾必须确认：

- 低维泡正在扩大；
- 扩大不是设备残余能量造成；
- 至少一个远离实验区的独立节点观测到泡壁位移；
- 扩张速度正在接近局部光速；
- 现有中央控制无法长期领先泡壁。

卷内冲突由“能否完成实验”正式转为“能否限制一场不可逆相变”。

# 第八部分　第五阶段：泡壁（建议第 21—26 章）

## 41. 阶段任务

第五阶段负责把局部工程事故扩大为第一次文明级降维灾难。

它必须完成：

- 多节点确认扩张；
- 计算泡壁未来路径；
- 发现首个殖民文明位于路径上；
- 展示预警无法远远领先近光速泡壁；
- 组织交通、信息和生命结构撤离；
- 证明高维生命不能无损降维；
- 让维因从修复工程转向减少损失；
- 让殖民文明拥有自身选择，而非只作为灾难背景。

## 42. 扩张确认

扩张确认必须来自多个独立证据：

- 泡壁监测网位置变化；
- 传播模态减少区域扩大；
- 高维交通路径失效；
- 引力与色散模式发生方向性改变；
- 曲率锚定结构被相变改写；
- 远程节点测得一致的相变前沿。

不能只由维因一句判断完成。

## 43. 首个殖民文明

第一卷暂不强制固定其正式名称，但章节地图必须为其建立独立文明档案。

固定性质：

- 它不是联径共同体核心成员；
- 它不是交战双方之一；
- 它的聚居和生命结构高度依赖即将紧致化的方向；
- 它具有自己的治理机构、工程能力和内部争议；
- 它不是等待维因拯救的被动群体；
- 它会根据有限时间独立决定保存对象和广播内容。

不得让该文明的主要功能只是原谅或谴责维因。

## 44. 救援限制

救援必须受到以下约束：

- 预警信号与泡壁都受局部光速限制；
- 交通节点在泡壁接近前已出现失稳；
- 大规模迁移需要路径、身份和载体转换；
- 高维生命不能简单装入低维容器；
- 主动结构压缩仍处于早期研究；
- 无法同时保存全部人口、身体结构和数据库；
- 某些撤离路径会把泡壁风险引向其他区域；
- 工程署无权替殖民文明决定谁被保留。

## 45. 殖民文明的必要选择

该文明必须至少作出三类选择：

### 45.1 个体撤离与公共设施之间的选择

是否用有限交通能力撤离少数完整个体，还是运输能保存更多文明信息的设备。

### 45.2 生命结构与记忆之间的选择

早期压缩载体无法同时保留原身体、完整感知和全部记忆。

### 45.3 求援信息与技术风险之间的选择

为了让其他文明理解降维后果，它必须广播足够具体的观测数据；这些数据同样提高技术可验证性。

这些选择应成为第一卷最重要的个体尺度情感锚点之一。

## 46. 维因的必要选择

本阶段维因必须完成从“修复优先”到“损失限制优先”的转变。

他应依次：

1. 继续尝试边界限制；
2. 接受宏观恢复已经不可行；
3. 把计算资源转向泡壁路径和撤离窗口；
4. 公开工程署此前保留的风险数据给受威胁文明；
5. 接受这些资料可能暴露闭锁系统结构；
6. 不以保护机构声誉为由延迟预警。

他不能：

- 单独驾驶设备进入泡壁完成英雄牺牲；
- 通过一个新装置停止扩张；
- 亲自决定殖民文明全部保存名单；
- 提前形成第二卷中的完整知识封锁立场。

## 47. 第一次文明级降维

灾难描写必须体现：

- 泡壁不是爆炸冲击波；
- 高维结构在失去一个宏观方向后无法保持连接；
- 不同生命和设备依据结构依赖出现不同结果；
- 直接毁灭、不完整投影和有限主动压缩同时存在；
- 低维区域内不是“所有东西变成普通八维版本”；
- 幸存载体付出记忆、感知、器官或身份连续性损失；
- 泡壁通过后，原文明不再能以原结构继续存在。

应选择少量具体锚点，而不是罗列全部灾难：

- 一个多中心生命失去保持同一主体的连接；
- 一座依赖额外方向支撑的聚居结构发生功能断裂；
- 一段撤离记录在降维后只剩不完整信息；
- 一个主动压缩载体能够广播，却已无法确认自身是否仍是原个体。

## 48. 弥娅线推进

弥娅在本阶段接近 `N-C05`：

- 证明异常结构早于所有已知文明；
- 排除当前宇宙后期伪造；
- 发现其包含一个可以作为“存在证明”的自洽数学关系；
- 她仍需独立节点完成最终复核；
- 异常中开始出现有限整数序列，但含义未定。

## 49. 阶段结尾推动力

第五阶段以首个殖民文明毁灭后的有限广播结束。

广播必须包含：

- 泡壁到达前后的观测差异；
- 高维生命结构损失；
- 主动压缩的代价；
- 对其他文明停止同类实验的警告；
- 对工程署责任的判断；
- 足以证明事故真实性的数据。

广播不能成为对维因的宽恕书，也不能只是控诉。

它的存在迫使工程署决定：是否公开更完整的事故资料。

# 第九部分　第六阶段：警告（建议第 27—30 章）

## 50. 阶段任务

第六阶段负责完成全卷的道德高潮、制度高潮和信息高潮。

核心冲突不再是能否阻止泡壁，而是：

> 在低维泡已经无法恢复、其他文明正在询问真相时，应公开多少信息？

## 51. 事故后的三种方案

工程署和相关文明至少形成三种方案：

### 51.1 全面封锁

理由：

- 防止其他文明复制；
- 保护仍可能存在的控制方法；
- 避免恐慌和抢先研究。

问题：

- 外部节点已持有部分数据；
- 殖民文明已发出独立广播；
- 封锁会让工程署成为唯一掌握者；
- 无法让受威胁区域进行有效撤离。

### 51.2 仅发布灾难结论

理由：

- 告知风险而不公开工程细节。

问题：

- 其他文明无法独立验证；
- 容易被解释为政治操纵；
- 已有观测数据足以让部分文明继续推导；
- 缺少证据会刺激秘密复现。

### 51.3 发布可验证事故数据

理由：

- 证明低维泡不可恢复；
- 提供泡壁识别和撤离依据；
- 防止工程署修改历史；
- 请求跨文明防御协作。

问题：

- 可验证资料包含可复现的核心结构；
- 广播无法限制接收者用途；
- 技术一旦进入公共网络便不可撤回。

维因最终支持第三种方案。

## 52. 维因的卷内高潮选择

维因支持公开事故数据的理由必须包括：

- 泡壁仍在扩张，其他文明需要识别方法；
- 工程署已经失去对全部副本的控制；
- 隐瞒会让首个受灾文明再次失去发言权；
- 不公开真实错误会使其他团队重复同一假设；
- 他仍相信共同验证可能阻止复制实验。

他不应在此时已经形成成熟的“危险知识永久封锁”理论。

他的错误必须是：

> 他把公开数据的主要接收者想象成会共同停止实验的科学共同体，低估了安全机构和独立文明会把同一资料视为必须抢先掌握的能力。

## 53. 事故广播内容

公开广播至少包含：

1. 一个宏观空间自由度确实消失的观测证据；
2. 定向维度模场激发与成核的关系；
3. 关闭外部装置后泡壁继续扩张；
4. 普通屏障和曲率锚无法停止相变；
5. 高维生命在泡壁处发生结构损失；
6. 泡壁速度及预警限制；
7. 原始闭锁系统的功能模块关系；
8. 首个殖民文明的灾难和幸存记录；
9. 停止同类实验的明确建议。

广播不得包含：

- 完整制造图；
- 精确真空势参数全集；
- 所有材料和能源配置；
- 后期军事化投送方法；
- 更低维防御理论。

即便如此，多个先进文明仍能独立推导核心过程。

## 54. 复制信号

卷末旧宇宙线固定出现至少三个独立复制迹象。

三者应体现不同动机，而非都写成邪恶军方：

1. **防御复现：**某文明认为必须理解低维泡才能保护自身；
2. **稳定研究：**某机构试图验证是否存在可控制的低维相；
3. **战略准备：**某独立防御文明不愿让联径共同体垄断技术。

复制迹象可以表现为：

- 相似的维度模态激发谱；
- 新建真空工程区的能源特征；
- 请求工程署提供缺失参数；
- 公开宣布独立验证；
- 秘密节点被监测到成核准备。

第一卷不得展示这些项目已经发动攻击。

## 55. 弥娅完成存在证明

弥娅线在卷末完成 `N-C05`：

- 多个独立观测节点复核异常；
- 异常相关性不能由当前宇宙内部普通过程建立；
- 它与宇宙初始条件共同存在；
- 其结构表现出主动压缩和纠错特征；
- 当前宇宙之前存在一个具有信息处理能力的宇宙阶段。

弥娅可以得出：

> 当前宇宙不是第一个宇宙。

她不得得出：

- 旧宇宙由维度战争毁灭；
- 回声由维因建立；
- 旧宇宙文明完整控制了量子反弹；
- 新宇宙必须进行降维实验。

## 56. 递减序列

存在证明完成后，弥娅从第一层与第二层边缘结构中识别：

```text
9 → 8 → 7 → 6 → 5 → 4 → 3
```

卷末她只能较有把握地判断：

- 该序列对应宏观空间自由度数量；
- 递减不是单次事件；
- 每个数字之间存在大尺度历史间隔；
- 旧宇宙经历过连续多次空间维数下降。

她尚不知道：

- 每次下降由谁发动；
- 是否全部属于战争；
- 三维为何形成黑暗森林；
- 旧宇宙如何从三维进入坍缩；
- 回声计划的组织者。

## 57. 卷尾交叉结构

建议卷尾采用以下顺序：

1. 维因确认公开广播已进入不可撤回的共享网络；
2. 工程署收到第一个独立复现请求或观测；
3. 第二个文明的真空实验区出现同类激发谱；
4. 第三个文明拒绝停止自主研究；
5. 维因第一次意识到警告没有减少知识，而是统一了问题的表达方式；
6. 转入弥娅线；
7. 弥娅完成旧宇宙存在证明；
8. 递减序列被重建；
9. 她确认旧宇宙不是在一次事故中失去维度；
10. 全卷结束。

卷尾不应解释“十维回声”全部来源。

可以在最后一页首次让弥娅或研究系统为该异常提出临时名称，但“十维回声”成为正式称呼的时机可留给第二卷开端。

# 第十一部分　人物卷内弧线

## 60. 维因的第一卷弧线

### 60.1 卷首状态

维因相信：

- 技术可以把政治问题转化为可测量约束；
- 隔离比摧毁更符合工程伦理；
- 风险可以由多节点审查和恢复系统控制；
- 科学数据公开会提高安全性。

### 60.2 第一阶段选择

主动加入边界协调工程署。

意义：

- 他不是被迫制造武器；
- 他真诚相信工程可以减少伤亡。

### 60.3 第二、三阶段选择

在多轮审查后支持真正成核。

意义：

- 他对关键风险判断承担责任；
- 其判断来自当时证据，而不是狂妄宣言。

### 60.4 第四阶段选择

恢复失败后保留观测和控制尝试。

意义：

- 为后续确认和撤离提供数据；
- 暴露其“更精确工程可以修复问题”的惯性。

### 60.5 第五阶段选择

把资源从恢复转向撤离和损失限制。

意义：

- 他开始承认宏观不可逆；
- 责任从维护装置转向面对受害者。

### 60.6 第六阶段选择

支持公开可验证事故数据。

意义：

- 他拒绝隐瞒；
- 他低估警告的复制价值；
- 其合理伦理选择成为第二卷危险的起点。

### 60.7 卷末状态

维因：

- 已知低维泡不可恢复；
- 已知首个文明被毁灭；
- 已知事故广播促成独立复现；
- 第一次怀疑无条件公开原则；
- 尚未理解连续降维战争会把宇宙压缩到三维；
- 尚未转向成熟的知识封锁或回声思想。

## 61. 弥娅的第一卷弧线

### 61.1 卷首状态

弥娅：

- 把异常视为普通宇宙学问题；
- 不相信跨宇宙信息已有证据；
- 相信公开方法和独立复核足以解决科学争议。

### 61.2 第一阶段选择

继续复核尚不足以发表的异常。

### 61.3 第二阶段选择

公开观测方法，邀请其他节点挑战结果。

### 61.4 第三阶段选择

提出人工编码假说，但不以此替代自然解释。

### 61.5 第四、五阶段选择

设计时间来源检验，证明异常不是当前宇宙文明后期写入。

### 61.6 第六阶段选择

在独立复核完成前拒绝宣布旧宇宙存在；证据完成后公开第一层结论。

### 61.7 卷末状态

弥娅：

- 证明当前宇宙不是第一个宇宙；
- 识别宏观空间维数递减序列；
- 尚不知道维因身份；
- 尚不知道降维战争完整历史；
- 尚未面对赫森和伊蓝的正式政策冲突；
- 仍把继续解码视为明确的科学责任。

## 62. 核心人物缺席规则

赫森和伊蓝在第一卷不得正式进入主线。

允许：

- 出现安全审查、开放复核和数据权限争论；
- 出现后来会支持两种立场的制度条件；
- 出现匿名或非核心配角承担局部观点。

禁止：

- 让赫森提前领导封锁回声；
- 让伊蓝提前提出全域公开协议；
- 让两人在第一卷直接决定弥娅研究方向；
- 把第三卷政策争论提前演完。

## 63. 第一卷必要配角功能

章节地图至少需要以下配角功能，但本文件不固定姓名、物种或最终生死：

### 63.1 工程风险审计者

功能：

限制：

- 不能精确预言全部灾难；

### 63.2 交通与撤离协调者

功能：

- 展示高维路径、节点容量和撤离限制；
- 把抽象泡壁速度转化为具体时间窗口；

功能：

- 展示多方授权和政治责任；
- 让工程不是实验室内部事件；

功能：

- 提供灾难中的独立主体视角；
- 作出文明保存选择；
- 形成有限幸存广播。

限制：

- 不能只负责原谅维因；
- 不能成为维因的私人亲属或爱情关系；
- 不能凭个人牺牲停止泡壁。

### 63.5 弥娅的独立复核者

功能：

- 质疑仪器、统计和自然模型；
- 提供独立节点数据；
- 防止弥娅成为单人发现宇宙真相的天才神话。

### 63.6 数据权限或公共证据维护者

功能：

- 展示为何观测方法可共享而原始数据仍有权限层级；
- 为卷末“事故数据无法完全封锁”建立制度基础。

## 64. 配角使用限制

- 单一配角不得承担三个以上关键制度功能；
- 不以配角突然背叛制造第一次事故；
- 不设置秘密反派提前推动武器化；
- 不让配角替维因作出成核或公开广播的关键选择；
- 不让配角替弥娅完成存在证明；
- 配角死亡不能只用于刺激主角情绪；
- 第一卷可有个体损失，但私人关系不得压过文明尺度因果。

# 第十四部分　高维世界的场景设计

## 67. 高维描写原则

第一卷需要让读者理解高维环境，但不能让每个场景都成为几何说明课。

每个高维场景最多突出一个主要空间效果：

- 路径；
- 遮挡；
- 连接；
- 边界；
- 身体结构；
- 建筑内部与外部；
- 交通邻接；
- 观测方向。

## 68. 第一卷必须出现的高维场景类型

### 68.1 高维通勤或交通

展示：

- 低维投影中遥远区域通过较短高维测地线连接；
- 交通仍需要节点、坐标、维护和时间；
- 不存在无代价瞬移。

### 68.2 高维会议或聚居空间

展示：

- 普通三维房间不能形成完整封闭；
- 参与者可以从额外方向进入；
- 权限边界依赖多方向结构或场，而非墙壁。

### 68.3 高维生命工作状态

展示维因或其他生命至少两种特征：

- 多中心身体结构；
- 额外方向连接器官；
- 非正面视野；
- 结构版本同步；
- 通过多个空间区域保持同一主体。

### 68.4 高维工程现场

展示：

- 设备分布在多个方向和区域；
- 单一三维示意图不足以描述全部连接；
- 测量、控制和能源模块不在同一位置；
- 维因只能负责部分系统。

### 68.5 降维后的连接丢失

展示：

- 不是物体被简单压扁；
- 依赖目标方向的连接无法在低维中保持；
- 结构、功能和身份同时受到影响。

## 69. 禁止的高维表达

不得把高维写成：

- 精神境界；
- 灵魂层级；
- 神圣空间；
- 全知视角来源；
- 可以任意观察低维内部的万能能力；
- 不受能源、材料和因果限制的世界。

“不可理解”只能是人物的暂时感受，随后必须由可观测效果取代。

# 第十五部分　主题、意象与情感锚点

## 70. 主题对照

第一卷主要使用以下对照：

| 前半卷 | 后半卷 |
|---|---|
| 开放路径 | 失效路径 |
| 可撤销授权 | 不可撤销相变 |
| 共享坐标带来合作 | 共享数据带来复制 |
| 边界用于减少伤亡 | 边界自行扩张并造成灭绝 |
| 仪器提高控制能力 | 仪器只能记录失去控制 |
| 科学公开提高可信度 | 科学公开降低复现门槛 |

## 71. 重复意象

### 71.1 路径

卷首：路径代表开放、交通和文明连接。  
卷中：路径成为必须被闭锁的军事通道。  
卷后：泡壁摧毁路径，撤离路线失效。  
卷末：知识通过另一类路径扩散。

### 71.2 边界

卷首：政治边界在高维中难以维持。  
卷中：工程试图创造可撤销物理边界。  
卷后：低维泡壁成为不受政治控制的边界。  
卷末：文明无法再为知识建立可靠边界。

### 71.3 噪声

卷首：弥娅把异常视为背景噪声。  
卷中：维因团队把小幅异常视为测量噪声或模型误差。  
卷末：两条线都发现噪声中保存了不可忽略的结构。

### 71.4 方向

卷首：更多方向意味着更多自由和绕行可能。  
卷中：工程选择一个方向进行闭锁。  
卷后：失去一个方向意味着生命结构和文明能力损失。  
卷末：递减序列说明方向将继续失去。

## 72. 情感锚点

第一卷的情感不依赖主线爱情关系。

建议使用以下锚点：

- 维因签署实验边界条件；
- 风险审计者保留一项未被模型消除的异议；
- 团队在成核成功后短暂确认停火窗口；
- 恢复系统按设计完成，但空间没有恢复；
- 殖民文明决定放弃部分个体或部分历史；
- 不完整投影的幸存载体无法确认自身连续性；
- 维因把完整事故数据附在警告广播中；
- 第一个复制项目使用了广播中的同一验证方法；
- 弥娅在远后时代确认这些痕迹不是自然噪声。

人物情感应通过：

- 修改参数；
- 拒绝签署；
- 开放权限；
- 删除或保留数据；
- 调整撤离优先级；
- 中止无效恢复；
- 发出广播；
- 接受无法验证的后果。

# 第十七部分　悬念与问题管理

## 77. 第一卷主悬念

主悬念不是“实验会不会出事”，因为卷名和总纲允许读者预期灾难。

真正的悬念应是：

1. 为什么如此危险的实验会被合理文明批准？
2. 成功的隔离为何会转化为自发扩张？
3. 面对不可逆事故，什么选择仍然算正确？
4. 事故数据公开后，文明会把它当警告还是能力？
5. 弥娅发现的异常和维因的历史之间存在怎样的时间关系？

## 78. 次级问题及回收位置

| 问题 | 提出阶段 | 第一卷回收 |
|---|---|---|
| 弥娅异常是否为仪器故障 | 第一阶段 | 第二阶段排除主要故障 |
| 高维边界能否建立 | 第一阶段 | 第四阶段短暂成功 |
| 闭锁是否可撤销 | 第二阶段 | 第四阶段证明不可撤销 |
| 真空稳定派担忧是否成立 | 第二阶段 | 第四、五阶段部分成立 |
| 首个殖民文明能否撤离 | 第五阶段 | 无法完整撤离，有限保存 |
| 是否应公开事故数据 | 第五阶段 | 第六阶段选择公开 |
| 公开能否阻止复制 | 第六阶段 | 卷末明确失败 |
| 弥娅异常是否为人工结构 | 第二阶段 | 第六阶段完成存在证明 |
| 旧宇宙是否只经历一次事故 | 卷末 | 递减序列证明不是一次 |

## 79. 留给第二卷的问题

第一卷结束后必须保留：

- 第一次事故资料如何被军事化；
- 防御研究为何会推动更低维相；
- 六次维度下降如何改变文明；
- 维因何时从修复转向知识封锁；
- 回声思想如何出现；
- 三维黑暗森林怎样形成；
- 旧宇宙如何坍缩和反弹；
- 弥娅如何解码历史骨架；
- 赫森和伊蓝何时进入主线。

不得为了第一卷的完整感提前回答这些问题。

# 第十八部分　灾难与冲突写作边界

## 80. 工程事故不是阴谋

第一次降维事故不得由以下原因触发：

- 内鬼修改一个参数；
- 敌对文明秘密破坏；
- 维因故意扩大实验；
- 操作员按错按钮；
- 管理者无视明确必然毁灭证据；
- 人工智能突然获得恶意；
- 未经铺垫的自然异常。

事故固定源于：

- 对未知低能真空相的错误模型；
- 把亚临界测试外推到真正成核；
- 高估恢复序列对新相的控制；
- 低估低维泡自发扩张；
- 多方制度在战争压力下接受了低概率极高后果风险。

## 81. 冲突不是善恶对抗

旧宇宙阶段必须同时存在：

- 支持实验且希望减少伤亡的人；
- 反对实验且无法提供替代方案的人；
- 要求开放审计的人；
- 担心公开带来复制的人；
- 希望自主防御而拒绝集中控制的文明。

任何一方都不得提前拥有作者的完整答案。

## 82. 灾难规模控制

第一卷灾难规模应满足：

- 足以证明降维具有文明灭绝能力；
- 足以改变全宇宙安全议程；
- 不等于全面宇宙战争；
- 不直接造成全旧宇宙 `S9→S8`；
- 不摧毁联径共同体全部核心；
- 不让维因失去所有社会和技术接口；
- 为第二卷保留技术复制和防御研究空间。

## 83. 战斗场面限制

第一卷可以有边境冲突和撤离压力，但不得以舰队大战作为主要高潮。

战争展示重点应是：

- 为什么传统封锁失败；
- 为什么工程隔离获得支持；
- 交通和信息如何受高维几何影响；
- 泡壁如何改变所有参与者决策；
- 武器尚未正式出现，安全行为已经开始改变。

# 第十九部分　第一卷固定结局

## 84. 旧宇宙线固定结局

第一卷旧宇宙线必须以以下状态结束：

- 第一次人工降维成功；
- 低维真空泡不可逆并持续扩张；
- 首个殖民文明遭到文明级毁灭；
- 少量不完整载体或记录完成广播；
- 维因支持发布可验证事故数据；
- 至少三个文明体系启动独立降维研究；
- 维因第一次意识到警告本身正在传播能力；
- 全面维度战争尚未爆发。

## 85. 弥娅线固定结局

第一卷弥娅线必须以以下状态结束：

- 异常被证明具有人工压缩和纠错结构；
- 异常早于当前宇宙所有已知文明；
- 当前宇宙之前存在过另一个宇宙阶段；
- 弥娅识别 `9→8→7→6→5→4→3` 的宏观空间维数序列；
- 她不知道每次下降的完整原因；
- 她决定继续解码。

## 86. 最后一层含义

卷尾必须让读者理解：

> 旧宇宙并不是在第一次降维事故中立刻毁灭。第一次事故只创造了一个能够被所有文明重新发现和使用的选择。

同时必须保留：

> 新宇宙中的发现者正在重新打开这条知识路径，但她尚未知道理解历史本身会产生何种代价。

不得以确定战争爆发、确定文明灭亡或确定循环重启作为结尾。

# 第二十一部分　第一卷禁止项

## 91. 剧情禁止项

第一卷不得：

- 爆发全面宇宙维度战争；
- 让旧宇宙整体从 `S9` 降至 `S8`；
- 展示成熟战略降维武器；
- 引入更低维防御技术解决第一次泡壁；
- 恢复已降维区域；
- 让维因阻止低维泡；
- 让维因预见宇宙最终降至三维；
- 让维因建立完整回声计划；
- 让弥娅完整读取维因记忆；
- 让弥娅知道回声计划创建者；
- 出现质量归还广播；
- 完整描写旧宇宙坍缩和量子反弹；
- 让赫森或伊蓝正式主导政策冲突；
- 让原作人物直接登场；
- 大篇幅复述原作历史。

## 92. 技术禁止项

第一卷不得出现：

- 无代价超光速通信；
- 普通物质屏障停止真空泡；
- 泡壁识别敌我；
- 关闭装置即关闭已经成核的低维泡；
- 通过一个反向按钮恢复空间维度；
- 高维生命无损进入低维；
- 单人便携式降维装置；
- 无限能源；
- 未经 Canon 的新型终极防御；
- 以“高维无法理解”为理由跳过工程逻辑。

## 93. 人物禁止项

维因不得被写成：

- 疯狂科学家；
- 唯一发明者；
- 被领导强迫的无责任执行者；
- 通过自我牺牲获得完全赎罪的英雄；
- 主动隐瞒已确认扩张风险的人；
- 卷末已经形成第三卷式有限公开方案的人。

弥娅不得被写成：

- 凭直觉相信旧宇宙的人；
- 维因转世或意识容器；
- 单独完成全部观测和解码的人；
- 通过梦境接收历史的人；
- 第一卷就知道降维战争全貌的人。

## 94. 原创边界禁止项

第一卷不得：

- 复制或近似改写原作正文；
- 模仿特定现实作家的句式；
- 让原作主要人物参与第一次降维；
- 把第一次降维设定为原作事件的幕后操控；
- 把人类文明设定为旧宇宙高维时代核心；
- 使用原作标志性场景的改名版本；
- 以“致敬”为由复刻原作具体桥段。

# 第二十二部分　卷级验收标准

## 95. 剧情验收

完成第一卷正文后，应能明确回答：

1. 边境冲突为何需要新的隔离方式？
2. 高维普通边界为何无效？
3. 闭锁工程为何被视为非杀伤方案？
4. 实验为何获得多方批准？
5. 维因具体负责什么？
6. 第一次成核为何被视为成功？
7. 恢复系统为何在测试中有效、成核后却失败？
8. 泡壁为何能继续扩张？
9. 首个殖民文明为何无法完整撤离？
10. 事故数据为何必须公开？
11. 广播为何足以支持独立复现？

# 第二十四部分　第一卷最终摘要

## 108. 一句话故事

在一个拥有九个宏观空间维度的开放宇宙中，真空工程师维因为结束边境战争参与设计可撤销的空间隔离区，却制造出第一个会自行扩张的低维真空泡；当他公开事故以警告所有文明时，这份警告反而让降维技术第一次成为可复制知识。另一个宇宙周期中，宇宙学家弥娅从原初背景噪声里证明了这段历史曾经存在。

## 109. 第一卷因果摘要

```text
开放宇宙并不等于没有冲突
→ 高维空间使普通边界失效
→ 文明寻求非杀伤性物理隔离
→ 维因参与局部维度闭锁系统
→ 多方依据亚临界实验批准成核
→ 第一次人工降维实现隔离目标
→ 新低维真空相脱离装置控制
→ 恢复失败，泡壁持续扩张
→ 无关殖民文明无法完整撤离
→ 第一次文明级降维发生
→ 事故数据作为警告被公开
→ 多个文明据此独立复现
→ 弥娅在新宇宙确认旧宇宙存在
→ 递减序列预示灾难远未结束
```

## 110. 第一卷最终落点

第一卷结束时，旧宇宙仍拥有完整的外部 `S9` 环境，全面维度战争尚未爆发。

真正发生变化的是知识状态：

- 降维从理论可能变成已验证工程事实；
- 不可逆扩张从未知风险变成公共证据；
- 多个文明第一次同时拥有复现路径；
- 维因失去对自己参与建立的知识链的控制；
- 弥娅在另一个宇宙周期中确认，这条知识链最终导致了连续的维数下降。

第一卷必须以这一含义结束：

> 宇宙失去的第一个方向，只存在于一片仍在扩张的区域中；但从事故广播发出的那一刻起，所有方向都已经进入了危险之中。
