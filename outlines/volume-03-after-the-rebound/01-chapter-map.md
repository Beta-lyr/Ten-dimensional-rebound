## 0. 文件职责

本文件把第三卷卷级大纲细化为45章逐章执行地图，并作为全书正文开发前的最终结构约束。

本文件负责固定：
- 45章的编号、暂定标题和建议文件名；
- 九个阶段各五章的固定分配；
- 所有章节的新宇宙纪元、空间状态和主要视角；
- 第三层真空相验证实验从治理、建设、成核、失控到永久缺陷的完整章级因果链；
- 弥娅、赫森、伊蓝在终卷中的独立行动、责任记录和关系变化；
- 事故数据无法彻底删除的多源原因及其政策后果；
- 宇宙静默协议、全域公开协议与有限公开方案的真实收益和固定反作用；
- 公共回声验证网络、最终广播和广播后长期观察的章节位置；
- 遥远空间自由度异常的观测内容、三模型并存和永久不确定性；
- 每章的科学或制度问题、人物选择、选择代价、信息边界、直接后果和伏笔回收；
- 全书结局前必须完成的科学、人物、主题、节奏与原创性验收。

本文件不替代章节细纲。每个 `chapters/ch-XXX-*.md` 仍需补充场景顺序、具体配角姓名、地点、对话目标、科学解释载体、情绪行为和段落节拍。

若本文件与 Canon 或 `00-volume-outline.md` 冲突，应修改本文件。不得通过新增万能技术、单一内鬼、隐藏反派、完整参数公开、宏观降维护盾或确定性结局保留冲突。

## 3. 单一时间线推进

```text
1—5   第三层验证缺口与替代方案审查
6—10  联合组、计量、权限、牺牲区与成核许可
11—15 分段激发、传播自由度损失与第三层见证成立
16—20 自发扩张、路径切断、闭合陷阱与永久缺陷
21—25 复合调查、数据副本、拼接与不可逆扩散
26—30 静默协议、异常监测、强制审查与隐藏反作用
31—35 全域公开、公共镜像、去标识失败与发布暂停
36—40 四层信息、字段审计、公共验证网络与最终广播
41—45 长期复算、降低广播、遥远异常与三模型终局
```

第1—20章发生在连续的实验准备与事故周期内，原则上以日、周、月推进；第21—35章以月、年推进；第36—40章允许跨越数年完成制度建设；第41—45章必须表现一段不可量化的长期和平。

## 4. 第三卷章级因果主链

```text
第三层回声存在现实验证缺口
→ 多个数学模型均可拟合，远程自然样本也不能提供可控因果链
→ 三人以不同条件批准进入实验设计
→ 多文明权限、计量、证据和牺牲区共同建立
→ 微型区域失去一个宏观传播自由度，第三层被证明真实
→ 泡在断能后自持，合理误差耦合形成失控
→ 路径被永久切断，泡进入闭合曲率陷阱
→ 缺陷稳定但无法恢复，宏观防御幻想被排除
→ 多文明副本、求援包、制造档案和调查数据无法统一删除
→ 外部文明独立重建部分理论
→ 赫森以最坏参与者逻辑推动静默与监控
→ 监控促使文明隐藏坐标、能源和研究状态
→ 伊蓝以防止垄断为由推动全域公开
→ 镜像和拼接降低独立研发门槛
→ 弥娅证明全面删除和全参数公开都不可接受
→ 四层有限公开与公共回声验证网络建立
→ 最终广播发出，宇宙获得历史验证权但没有完整制造权
→ 一段长期和平中，文明逐步降低广播和坐标精度
→ 遥远区域出现空间自由度异常
→ 自然相变、受控实验和第一次攻击三种解释永久并存
```

## 6. 章节标题原则

- 实验阶段优先使用校验、授权、基准、阈值、路径、陷阱和缺陷等科学或工程对象；
- 政策阶段优先使用协议、监测、镜像、字段、审计和广播等制度对象；
- 标题不得提前使用“第一击”“武器诞生”“循环重启”等确定性结论；
- 终局标题必须保持观测和解释的不确定，不得确认异常属于攻击；
- 不得借用原作标志性章节名、人物名或句式。

# 第四部分　阶段验收标准

## 1. 第一阶段：见证条件（第1—5章）

- 证明纯数学、模拟和远程自然样本都存在决定性缺口；
- 三人都支持继续理解回声，但支持条件不同；
- 第5章只批准进入设计，不得提前授权真实成核；

## 2. 第二阶段：权限分离（第6—10章）

- 所有关键权限必须分离，任何单一主体不能完成全链路；
- 多文明计量和独立证据同时提高可信度与未来删除难度；
- 牺牲区和闭合路径必须在事故前建立；

## 3. 第三阶段：低维相（第11—15章）

- 第13章真实制造微型S8区域，不使用爆炸式奇观；
- 第15章只确认物理见证成立，不宣称工程安全；
- 事故因素逐步出现，但不得提供单一根因；

## 4. 第四阶段：闭合路径（第16—20章）

- 自动中止必须真实发挥作用，却不能停止已成核泡；
- 人员损失来自撤离连接与陷阱几何的冲突；
- 第20章必须明确限制不等于恢复，也不能成为宏观护盾；

## 5. 第五阶段：无法删除（第21—25章）

- 事故调查保留复合因果，不制造内鬼或替罪者；
- 弥娅删除部分工程参数但保留责任记录；
- 第25章必须确认至少部分理论已被外部独立重建；

## 6. 第六阶段：静默协议（第26—30章）

- 静默协议必须展示真实安全收益与真实支持者；

## 7. 第七阶段：全域公开（第31—35章）

- 全域公开必须降低历史垄断风险；
- 镜像、去标识和拼接必须真实降低研发门槛；
- 伊蓝在第35章主动暂停工程层发布，但不放弃公共验证；

- 第40章广播公开历史和验证权，继续封锁完整工程参数；

## 9. 第九阶段：广播之后（第41—45章）

- 广播与异常之间必须存在长期时间间隔；
- 赫森降低广播是防御性选择，不是秘密攻击准备；
