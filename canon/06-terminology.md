## 0. 文件职责

本文件统一《十维回声》中物理、宇宙学、文明、人物、机构、技术和知识治理相关术语。

本文件负责回答：

- 一个概念在正式设定中应使用什么名称；
- 哪些词是标准术语，哪些只是正文中的文学性表达；
- 同一概念允许使用哪些简称、别称和历史称呼；
- 哪些相近概念不得混用；
- 技术编号、纪元编号和空间维数标记如何书写；
- 某个术语在三卷中的首次允许揭示位置；
- 哪些词会造成超自然化、全能化或物理误解；
- 新增人物、文明、机构和技术名称应遵守什么规则；
- 大纲、正文和研究文件对术语精度的要求有何不同。

本文件不重新定义物理规则，不新增技术能力，也不改变时间线和人物弧线。术语释义必须服从对应专项 Canon 文件。

发生冲突时：

1. 概念是否成立，以对应专项 Canon 为准；
2. 概念如何命名和书写，以本文件为准；
3. 若本文件中的释义与上位设定冲突，应修订本文件，不得通过更换名称保留冲突设定。

# 第一部分　术语管理原则

## 1. 术语的四种状态

项目中的术语分为四类。

| 状态 | 含义 | 使用规则 |
|---|---|---|
| 正式术语 | 已写入 Canon、含义固定 | 大纲和正文必须按本文件使用 |
| 允许简称 | 不改变含义的简化称呼 | 首次出现正式名称后可使用 |
| 叙事称呼 | 人物、媒体或历史形成的非精确称呼 | 可以体现立场，但不能替代设定解释 |
| 待定名称 | 设定已存在，但专名尚未固定 | 使用功能描述或占位标记，不得擅自正式命名 |

“叙事称呼”不自动等于错误。例如，“维度消失”可以用于人物感知，但在科学说明中应写为“该宏观空间方向紧致化到不可访问尺度”。

## 2. 正式定义优先于词面直觉

术语必须按项目定义理解，不能仅凭日常词义解释。

例如：

- “十维宇宙”不是十个空间维度，而是九个空间维度加一个时间维度；
- “回声”不是声波，而是跨宇宙保留的统计编码；
- “闭锁”不是机械封闭，而是局部空间自由度失去宏观可访问性；
- “公共验证”不是公开全部制造参数；
- “文明”不是单一国家或单一物种；
- “小宇宙”不是平行时间线，也不是能完整穿越量子反弹的避难舱。

## 3. 科学术语与文学表达分层

### 3.1 Canon、技术档案和章节大纲

应优先使用精确术语：

- 宏观空间维数；
- 紧致化；
- 低维真空泡；
- 泡成核；
- 维度模态；
- 工程不可逆；
- 原初引力关联；
- 公共验证与工程复现分离。

### 3.2 小说正文中的专业场景

可以使用精确术语与易懂解释并置：

> 谱仪显示目标模态已经紧致化。对实验区中的物质而言，那条空间方向已经消失。

### 3.3 小说正文中的灾难或个体感知

允许使用有限比喻：

- 方向被关闭；
- 路径从空间中退去；
- 身体失去一种连接方式；
- 区域不再允许某类传播；
- 城市的一部分仍可见，却不再能够抵达。

比喻之后若涉及关键因果，必须由观测或后果恢复物理含义。

## 4. 首次出现规则

正式专名首次进入正文时，应满足以下至少一项：

- 由人物基于功能自然说出；
- 由设备、档案或协议界面显示；
- 通过行动让读者先理解功能，再给出名称；
- 名称与其历史形成过程同时出现。

禁止在同一段中连续堆叠大量未解释专名。

一个章节原则上只正式引入一个主要新科学术语。其他辅助术语应能由上下文理解，或已在前文建立。

## 5. 简称使用规则

正式名称首次出现后，可使用本文件列出的简称。

例如：

```text
跨文明极端风险安全委员会
→ 文明安全委员会
→ 安全委员会
```

不得自行缩写成意义可能变化的称呼，例如：

- “宇宙委员会”；
- “最高委员会”；
- “全宇宙政府”；
- “监管者”。

## 6. 人物立场词不等于正式阵营

“开放扩张”“真空稳定”“独立防御”“静默派”“开放派”主要描述立场或政策倾向，不必对应边界清晰、成员固定的政治集团。

正文应避免：

- 把全部文明永久划分成两个阵营；
- 让“静默派”天然服从赫森；
- 让“开放派”天然服从伊蓝；
- 把立场名称写成物种名称或国家名称；
- 用阵营标签替代内部动机。

## 7. 技术名称必须描述功能

正式技术名称优先采用以下结构：

```text
作用对象 + 测量/控制方式 + 装置或网络类型
```

例如：

- 维度模态谱仪；
- 真空状态层析网；
- 各向异性边界阵列；
- 闭合曲率陷阱；
- 原初关联观测网络；
- 公共回声验证网络。

避免：

- 神器式名称；
- 只有气氛、没有功能的代号；
- “终极”“绝对”“无限”“全知”等词；
- 使用“量子”“高维”掩盖具体机制。

## 8. 译名原则

旧宇宙和新宇宙中的文明、机构及生命不必使用汉语思维命名。正文中的名称视为叙事翻译。

翻译应优先保留：

- 功能；
- 结构；
- 历史来源；
- 对外协议中的可识别含义。

例如，“联径共同体”表示“由共享路径维持连续性的共同体”，不意味着其原语言中存在“联”“径”两个汉字概念。

# 第二部分　维度计数、纪元与编号

## 9. 维度计数公式

设：

- `d`：宏观空间维数；
- `D`：完整时空维数。

统一关系为：

```text
D = d + 1
```

额外的 `1` 为时间维度。

## 10. 十维时空

**标准术语：**十维时空  
**定义：**九个宏观空间维度加一个时间维度构成的完整时空。  
**允许称呼：**十维宇宙、完整十维时代、高维完整态。  
**禁止误解：**十个空间维度；十条可删除的空间轴；十个平行世界。

“十维宇宙”用于日常叙述时，必须在项目设定层明确其实际含义是 `S9 + 时间`。

## 11. 宏观空间维数

**标准术语：**宏观空间维数  
**定义：**宏观物质能够实际运动、传播并建立稳定结构的独立空间方向数量。  
**符号：**`d`。  
**推荐简写：**空间维数。  
**谨慎使用：**维度数量。  
**禁止混用：**完整时空维数。

## 12. 完整时空维数

**标准术语：**完整时空维数  
**定义：**宏观空间维数与一个时间维度之和。  
**符号：**`D`。

“从十维降到九维”表示 `D:10→9`，对应 `d:9→8`。

## 13. 空间维数标记

| 标记 | 含义 | 正文常用称呼 |
|---|---|---|
| `S9` | 九个宏观空间维度 | 十维宇宙、完整高维时代 |
| `S8` | 八个宏观空间维度 | 第一次降维后的八空间维环境 |
| `S7` | 七个宏观空间维度 | 七空间维环境 |
| `S6` | 六个宏观空间维度 | 六空间维环境 |
| `S5` | 五个宏观空间维度 | 五空间维环境 |
| `S4` | 四个宏观空间维度 | 四空间维时代 |
| `S3` | 三个宏观空间维度 | 三维宇宙、三维时代 |

`S9` 等标记主要用于 Canon、大纲、技术档案和修订记录。正文中仅在科研界面、历史图表或专业对话中使用。

## 14. 维数下降标记

统一使用：

```text
S9→S8
S8→S7
S7→S6
S6→S5
S5→S4
S4→S3
```

箭头表示主导环境或局部区域的宏观空间维数下降，不表示全宇宙在同一瞬间同步改变。

不得使用 `10D→9D` 作为唯一标记，因为它容易混淆空间维数与完整时空维数。

## 15. 宇宙纪元前缀

| 前缀 | 标准名称 | 含义 |
|---|---|---|
| `O` | 旧宇宙纪元 | 量子反弹之前的宇宙周期 |
| `N` | 新宇宙纪元 | 量子反弹之后的宇宙周期 |
| `R` | 反弹阶段 | 经典时空失效的量子引力过渡 |

`R` 不是第三个宇宙，也不是人物可正常活动的独立时代。

## 16. 主要纪元编号

| 编号 | 标准名称 |
|---|---|
| `O-A` | 完整十维时代 |
| `O-B` | 第一次人工降维期 |
| `O-C` | 技术复制与早期军备化期 |
| `O-D` | 连续维度战争期 |
| `O-E` | 三维形成与黑暗森林成熟期 |
| `O-F` | 三维黑暗森林时代 |
| `O-G` | 旧宇宙末期与回声计划期 |
| `R` | 量子反弹阶段 |
| `N-A` | 新十维宇宙形成期 |
| `N-B` | 新宇宙开放文明时代 |
| `N-C` | 回声发现期 |
| `N-D` | 旧宇宙历史重建期 |
| `N-E` | 实验与泄露期 |
| `N-F` | 知识治理危机期 |
| `N-G` | 有限公开与结尾异常期 |

## 17. 事件编号

格式：

```text
纪元编号 + 两位事件序号 / 空间维数
```

示例：

```text
O-B03 / S9→S8
N-E06 / S9，局部 S8
```

正文不要求显示事件编号。章节大纲、时间线和修订记录应优先使用。

## 18. 时间跨度术语

| 术语 | 适用范围 |
|---|---|
| 即时 | 秒至日，实验、事故、撤离和决策 |
| 短期 | 月至数十年，项目建设与人物弧线 |
| 文明期 | 数百年至数十万年，制度与技术扩散 |
| 宇宙期 | 百万年至数十亿年以上，维度时代和宇宙演化 |
| 反弹期 | 不适用普通经典计时 |

不得把“宇宙期”写成所有人物直接连续经历的个人时间。

# 第三部分　基础物理与宇宙学术语

## 19. 额外空间维度

**标准术语：**额外空间维度  
**定义：**超出三维日常经验、但与普通空间方向同属物理空间的独立运动方向。  
**允许简称：**额外维度、高维方向。  
**禁止等同：**平行世界、灵界、更高意识层、时间分支。

## 20. 宏观展开

**标准术语：**宏观展开  
**定义：**一个空间方向的有效尺度足以允许宏观物质沿其运动并形成稳定结构。  
**反义术语：**紧致化。  
**推荐表达：**“九个空间方向均处于宏观展开状态”。

## 21. 紧致化

**标准术语：**维度紧致化  
**定义：**某个空间方向的有效尺度收缩到接近量子引力尺度，使宏观物质无法继续沿该方向运动。  
**允许简称：**紧致化。  
**叙事称呼：**方向消失、空间自由度关闭。  
**禁止表述：**空间轴被删除；维度被彻底抹去；世界被机械压扁。

## 22. 维度模场

**标准术语：**维度模场  
**定义：**决定各空间方向有效尺度与稳定状态的场自由度，是本项目维度工程的核心物理对象。  
**允许简称：**模场，但必须在上下文中明确是维度模场。  
**禁止泛化：**把模场写成可任意改写所有物理规律的万能场。

## 23. 维度模态

**标准术语：**维度模态  
**定义：**维度模场在特定局部几何与边界条件下的可激发模式。  
**相关术语：**目标模态、模态谱、模态交叉耦合。  
**禁止误解：**全宇宙固定编号的“第七维按钮”。

## 24. 局部空间本征方向

**标准术语：**局部空间本征方向  
**定义：**在特定局部度规和真空状态下，可被区分和选择的空间方向或方向组合。  
**允许简称：**局部本征方向、目标方向。  
**禁止表述：**宇宙绝对第几轴。

不同低维泡可以选择不同取向，由此产生异向低维相和域壁。

## 25. 真空状态

**标准术语：**真空状态  
**定义：**决定场基态、有效物理规律和维度展开方式的局部最低或亚稳能量结构，不等于“什么都没有”。  
**允许简称：**真空。  
**禁止误解：**空无；绝对空白；没有任何物理性质的区域。

## 26. 亚稳高维真空

**标准术语：**亚稳高维真空  
**定义：**能够长期维持九个空间维度宏观展开，但并非绝对最低能状态的真空结构。  
**允许称呼：**高维亚稳态。  
**禁止简化：**高维宇宙天生注定立即坍塌。

“亚稳”表示存在更低能相和转变可能，不表示在无扰动下必然很快失稳。

## 27. 低维真空

**标准术语：**低维真空  
**定义：**至少一个原本宏观展开的空间方向进入紧致化状态后的真空相。  
**允许称呼：**低维相。  
**禁止混用：**低维空间区域、低维真空泡、泡壁。

低维真空是相的性质；低维真空泡是该相在高维环境中的有限区域。

## 28. 真空势

**标准术语：**真空势  
**定义：**用于描述不同真空状态、势垒和能量差的有效势结构。  
**相关术语：**真空势参数、相变势垒、低能真空。  
**禁止用法：**把“真空势”写成一种可直接发射的能量束。

## 29. 真空相变

**标准术语：**真空相变  
**定义：**局部真空从一种稳定或亚稳结构转变为另一种结构的过程。  
**在本书中的核心实例：**宏观空间维度由展开态进入紧致态。  
**禁止等同：**传统爆炸、普通材料相变、空间塌方。

## 30. 泡成核

**标准术语：**泡成核  
**定义：**低维真空相在高维真空中形成初始有限区域的过程。  
**允许简称：**成核。  
**相关术语：**亚临界扰动、临界尺度、低维种子。  
**禁止表述：**凭空打开维度裂缝。

## 31. 亚临界扰动

**标准术语：**亚临界扰动  
**定义：**尚未越过自持扩张阈值、撤去外部激发后仍可能衰减的局部模场偏离。  
**关键区别：**亚临界扰动可以中止；已跨过临界尺度的低维泡不能通过关闭装置恢复。

## 32. 临界尺度

**标准术语：**临界尺度  
**定义：**低维相区域从依赖外部维持转变为能够自发扩张的阈值尺度。  
**允许称呼：**成核临界点，但应避免与时间点混淆。  
**禁止表述：**武器达到某个尺寸后获得意识或自动锁敌。

## 33. 低维真空泡

**标准术语：**低维真空泡  
**定义：**低维真空相在外部高维真空中的有限成核区域及其扩张结构。  
**允许简称：**低维泡、真空泡；上下文必须明确。  
**叙事称呼：**降维区、失维区，仅用于非专业人物或历史传播。  
**禁止称呼：**维度黑洞、空间病毒、二维炸弹的通用代称。

低维真空泡包括：

- 泡内低维相；
- 泡壁；
- 泡外高维相。

## 34. 泡壁

**标准术语：**泡壁  
**定义：**高维真空与低维真空之间的相变边界。  
**固定性质：**扩张接近但不超过局部光速；普通物质屏障不能阻挡。  
**禁止误解：**可见的实体墙；具有固定厚度的机械外壳；可被火力击碎的护盾。

正文可通过粒子传播、引力模式和结构失效表现泡壁，而不必把它描写成发光平面。

## 35. 泡内低维相

**标准术语：**泡内低维相  
**定义：**泡壁之后已经完成真空结构转变的区域。  
**禁止误解：**原高维区域被完整压缩后仍原样保存在内部。

## 36. 泡外高维相

**标准术语：**泡外高维相  
**定义：**尚未被泡壁转化、仍保持较高宏观空间维数的外部区域。  
**注意：**泡外文明能够观测异常，不代表拥有足够时间或能力阻止扩张。

## 37. 同向低维相

**标准术语：**同向低维相  
**定义：**紧致化取向和真空参数相近的低维区域。  
**相遇结果：**边界可能合并或重组，不产生恢复高维的效果。

## 38. 异向低维相

**标准术语：**异向低维相  
**定义：**紧致化的局部本征方向不同的低维区域。  
**相遇结果：**可形成高能域壁、拓扑缺陷和传播畸变。  
**禁止用法：**把异向相遇写成两种降维互相抵消并恢复全部维度。

## 39. 域壁

**标准术语：**真空域壁；上下文明确时可简称域壁。  
**定义：**不同真空相或不同取向低维相之间的稳定或亚稳边界结构。  
**禁止等同：**文明制造的普通防御墙。

## 40. 拓扑缺陷

**标准术语：**拓扑缺陷  
**定义：**真空相变或不同相拼接后，由全局结构约束保留下来的局部异常。  
**用途：**高维战争遗迹、第三卷永久缺陷区、跨宇宙编码讨论。  
**禁止泛化：**任何无法解释的现象都称为拓扑缺陷。

## 41. 工程不可逆

**标准术语：**工程不可逆  
**定义：**理论方程未必绝对排除逆过程，但任何单一文明无法重建全部场状态、物质结构、量子相位、拓扑连接和已扩散信息。  
**允许简称：**宏观不可逆、降维不可逆。  
**禁止曲解：**数学上绝对不允许任何涨落；宇宙重启违反了不可逆规则。

宇宙量子反弹重新初始化新宇宙条件，不是对旧宇宙某一低维区域进行工程逆转。

## 42. 宏观不可恢复阈值

**标准术语：**宏观不可恢复阈值  
**定义：**低维泡跨过临界尺度并开始自持扩张后，已转化区域不再能由原装置恢复。  
**用途：**区分实验前中止、微型限制和宏观逆转。

## 43. 降维

**标准术语：**降维  
**定义：**一个或多个宏观空间方向进入紧致化状态，使可用宏观空间维数减少。  
**适用：**过程、事件、技术或历史。  
**禁止简化：**只写视觉压扁；把降维理解为改变观察视角；把时间维度一并删除。

## 44. 维度下降

**标准术语：**维度下降  
**定义：**描述宇宙环境或文明所处主导空间维数由高到低的历史变化。  
**区别：**“降维”可以指一次具体过程；“维度下降”更常用于时代和总体后果。

## 45. 连续维度战争

**标准术语：**连续维度战争  
**定义：**低维真空技术在进攻、防御和主动适应中反复推动 `S9→S3` 的长期文明战争。  
**允许简称：**维度战争。  
**禁止称呼：**一次大战、单场终局战争。

## 46. 防御性降维

**标准术语：**防御性降维  
**定义：**文明为避免被敌方更不可控的低维泡摧毁，提前降低自身核心区或载体维数。  
**关键含义：**文明可能因成功预测威胁而主动降维，并非只在战败后发生。

## 47. 降维防御悖论

**标准术语：**降维防御悖论  
**定义：**改变或限制既有低维泡传播，通常需要制造不同取向或更低维的真空相，从而产生新的武器和永久代价。  
**允许简称：**防御悖论。  
**禁止改写：**盾牌与武器只是恰巧相似。

# 第四部分　因果、交通、通信与观测术语

## 48. 局部因果律

**标准术语：**局部因果律  
**定义：**物质、能量和可控信息沿所在完整时空的局部路径传播时，不能超过局部光速，也不能向过去发送可用信息。  
**禁止绕过：**以“高维”“量子”“拓扑”为理由实现无代价瞬时通信。

## 49. 高维测地线

**标准术语：**高维测地线  
**定义：**完整高维几何中的局部最短或驻定路径。  
**用途：**高维交通通过使用较短路径缩短低维投影距离。  
**禁止表述：**飞船自身突破光速。

## 50. 低维投影中的超光速假象

**标准术语：**低维投影中的超光速假象  
**定义：**物体沿较短高维路径到达，在低维投影中早于沿低维路径传播的光，但其完整高维局部速度始终不超光速。  
**正文简化：**“它没有更快，只是走了更短的路。”

## 51. 高维交通网络

**标准术语：**高维交通网络  
**定义：**由度规测绘、路径稳定、入口定位、负载调度和坐标转换共同维持的跨区域交通系统。  
**禁止等同：**任意门、瞬移网络、无延迟星门。

## 52. 联径节点

**标准术语：**联径节点  
**定义：**联径共同体维护的共享高维交通节点，同时承担路径连接、坐标交换和身份验证。  
**允许简称：**节点，但上下文须清楚。  
**禁止误解：**只有交通功能的普通车站。

## 53. 因果中继网络

**标准术语：**因果中继网络  
**定义：**沿高维交通与测地线路径布置的通信中继系统，可降低投影延迟但不违反局部因果。  
**禁止简称：**量子瞬时网络。

## 54. 坐标广播

**标准术语：**坐标广播  
**定义：**文明公开交通入口、通信路径、计量基准和协议身份的基础通信。  
**注意：**坐标公开不等于公开全部内部设施。

## 55. 应急广播

**标准术语：**应急广播  
**定义：**事故系统自动发送的设备状态、计量基准、危险区、原始观测片段和最低救援参数。  
**固定作用：**第一次事故和第三卷事故中的知识扩散来源之一。  
**禁止简化：**只有一句警告而没有验证数据。

## 56. 计量基准

**标准术语：**计量基准  
**定义：**不同文明用于转换坐标、时间、能量和误差模型的可重复参照。  
**相关术语：**无量纲比值、基准转换、系统误差。  
**禁止假定：**所有文明天然共享同一单位和坐标系。

## 57. 维度模态谱

**标准术语：**维度模态谱  
**定义：**反映各空间方向有效尺度、稳定性和振荡特征的统计测量结果。  
**禁止表述：**仪器直接拍摄到维度本体。

## 58. 原初引力背景

**标准术语：**原初引力背景  
**定义：**新宇宙早期引力扰动在后续宇宙中留下的统计背景，是弥娅研究和回声承载的主要观测对象。  
**允许简称：**原初背景、引力背景；不得与普通背景噪声完全等同。

## 59. 超因果接触尺度关联

**标准术语：**超因果接触尺度关联  
**定义：**在新宇宙正常演化史中未曾直接因果接触的遥远区域之间出现的统计对应。  
**作用：**构成弥娅发现人工结构的关键异常。  
**注意：**它是初始条件中的相关性，不是当前时刻的超光速通信。

## 60. 纠错结构

**标准术语：**纠错结构  
**定义：**通过多尺度冗余、重复关系和统计约束，使低带宽信息能在反弹噪声后仍被识别的编码结构。  
**禁止写法：**完整信息被秘密备份在宇宙某处。

# 第五部分　物质、生命、意识与文明保存术语

## 61. 直接毁灭

**标准术语：**直接毁灭  
**定义：**高维结构无法映射到低维真空，物质连接和生命功能在泡壁处失效。  
**注意：**不是被外力机械挤碎，而是结构赖以存在的自由度消失。

## 62. 不完整投影

**标准术语：**不完整投影  
**定义：**部分物质或生命结构在低维环境中保留，但器官、记忆、感知、计算或身份连续性大量丢失。  
**禁止表述：**只是外形变薄；主体完整无损地藏在低维截面中。

## 63. 主动低维化

**标准术语：**主动低维化  
**定义：**文明提前设计可在目标维数中运行的新载体，并主动删减无法映射的身体、知识和制度结构。  
**允许简称：**低维化。  
**禁止等同：**无损压缩、上传永生、完整逃生。

## 64. 低维映射

**标准术语：**低维映射  
**定义：**分析高维结构连接，寻找目标低维环境中的近似功能实现，并明确无法保留内容的过程。  
**禁止承诺：**存在唯一正确且无损的映射。

## 65. 低维生命载体

**标准术语：**低维生命载体  
**定义：**为较低空间维数重新设计的生物、机器或混合生命结构。  
**关键限制：**功能继承不自动证明个体连续性。

## 66. 多中心生命

**标准术语：**多中心生命  
**定义：**由多个空间上分离、但通过额外方向持续保持功能连接的生命结构。  
**禁止简化：**多个身体共享一个灵魂。

## 67. 身体结构版本

**标准术语：**身体结构版本  
**定义：**高维文明用于记录个体载体配置、替换历史和连接关系的身份信息。  
**用途：**表达人物阶段，不等同于软件随意更新人格。

## 68. 个体连续性

**标准术语：**个体连续性  
**定义：**记忆、人格、身体因果链和主观经验是否保持足够连接的制度与哲学判断。  
**禁止简化：**只要数据相同就是同一个人；复制体天然共享同一主体。

## 69. 文明连续性

**标准术语：**文明连续性  
**定义：**文明在生物、个体、信息和制度四个方面的延续程度。  
**四个维度：**

- 生物连续性；
- 个体连续性；
- 信息连续性；
- 制度连续性。

不得把其中任一项自动等同于完整文明延续。

## 70. 维度难民

**标准术语：**维度难民  
**定义：**原生存结构因空间维数下降即将失效，必须迁移、重构或被转化为信息载体的个体、群体或文明结构。  
**范围：**不只指飞船逃亡者。

## 71. 信息删减

**标准术语：**信息删减  
**定义：**在低维环境无法保存全部连接和数据时，文明主动选择保留与放弃内容的过程。  
**允许称呼：**文明删减、知识删减，须根据对象使用。  
**禁止淡化：**清理冗余文件。

## 72. 六类文明保存方案

| 标准术语 | 技术编号 | 核心目标 |
|---|---|---|
| 个体保全型 | `LIF-A` | 尽量保留少量原个体 |
| 人口保全型 | `LIF-B` | 保存较大规模低复杂度人口 |
| 信息档案型 | `CMP-C` | 保存知识、历史与语言 |
| 机器继承型 | `LIF-D` | 由低维机器延续功能与部分人格模型 |
| 生态种子型 | `LIF-E` | 保存可重新演化的生命体系 |
| 规则核心型 | `GOV-F` | 保存最低制度、价值与重建规则 |

以上方案均不等于完整文明无损穿越降维。

## 73. 文明档案核

**标准术语：**文明档案核  
**定义：**面向低维环境保存知识、历史、语言和必要解释结构的档案载体。  
**禁止误解：**档案核内存在完整活文明。

## 74. 机器继承体

**标准术语：**机器继承体  
**定义：**以低维机器运行文明核心规则、功能和部分人格模型的后继载体。  
**禁止结论：**机器继承体必然是原文明或原个体的无争议延续。

## 75. 生态种子

**标准术语：**生态种子  
**定义：**可在低维环境中重新发展或演化的生命系统及最低引导结构。  
**禁止表述：**旧文明会按原样从种子中复活。

## 76. 规则核心

**标准术语：**规则核心  
**定义：**被压缩到最低规模的制度、价值约束和重建程序。  
**固定限制：**规则可能失去语境，后继文明可以拒绝执行。

# 第六部分　宇宙周期与十维回声术语

## 77. 旧宇宙

**标准术语：**旧宇宙  
**定义：**量子反弹之前、从 `S9` 逐步降至 `S3` 并最终坍缩的宇宙周期。  
**允许称呼：**前一宇宙周期、上一宇宙。  
**禁止称呼：**前世宇宙、祖先宇宙人格。

在第一卷前段，“旧宇宙”属于尚未向读者完全公开的真相，不应由维因线人物自称。

## 78. 新宇宙

**标准术语：**新宇宙  
**定义：**量子反弹后重新膨胀、九个空间维度重新宏观展开的宇宙周期。  
**允许称呼：**当前宇宙，限弥娅时代人物视角。  
**禁止误解：**旧宇宙的平行分支；旧文明直接迁居的新世界。

## 79. 宇宙整体坍缩

**标准术语：**宇宙整体坍缩  
**定义：**在大部分小宇宙归还质量后，旧宇宙由持续膨胀转入整体收缩的演化阶段。  
**允许简称：**整体坍缩、宇宙坍缩。  
**禁止简化：**文明按下按钮重启宇宙。

## 80. 量子反弹

**标准术语：**量子反弹  
**定义：**经典广义相对论在极端尺度失效后，宇宙避免经典奇点并进入新膨胀阶段的整体物理过程。  
**固定限制：**不是设备、仪式或高级生命控制的行为。  
**禁止称呼：**宇宙复活术、时间倒流、文明重启装置。

## 81. 维度模场重新初始化

**标准术语：**维度模场重新初始化  
**定义：**量子反弹后的新宇宙初始条件重新允许九个空间维度宏观展开。  
**关键区别：**不是把旧宇宙已降维物质恢复成原状。

## 82. 小宇宙

**标准术语：**小宇宙  
**定义：**从母宇宙中隔离并保存有限物质、人口和知识的独立工程空间。  
**允许称呼：**小宇宙避难区，限功能说明。  
**禁止误解：**无限资源空间；能完整穿越量子反弹；平行时间线。

## 83. 母宇宙

**标准术语：**母宇宙  
**定义：**小宇宙从中抽取质量并与之建立历史关系的主宇宙。  
**注意：**“母”是关系性称呼，不表示宇宙具有人格或生育意志。

## 84. 母宇宙质量缺失

**标准术语：**母宇宙质量缺失  
**定义：**大量物质被长期保留在小宇宙中，使母宇宙整体演化条件发生变化。  
**禁止淡化：**普通资源短缺。

## 85. 质量归还

**标准术语：**质量归还  
**定义：**小宇宙文明将占用的物质重新送回母宇宙，使其恢复满足整体演化所需条件的行为。  
**禁止误解：**所有文明同时被强制召回；归还者必然存活。

## 86. 质量归还广播

**标准术语：**质量归还广播  
**定义：**包含母宇宙质量不足证据、演化后果、验证方法和责任请求的公开广播。  
**允许简称：**归还广播。  
**禁止称呼：**宇宙命令、神谕、绝对召回令。

## 87. 归还者集合

**标准术语：**归还者集合  
**定义：**出于不同理由响应质量归还请求的多个文明和小宇宙，不构成统一政治实体。  
**禁止称呼：**归还联盟，除非后续另行建立正式组织。

## 88. 十维回声

**标准术语：**十维回声  
**定义：**旧宇宙末期被编码进整体拓扑关联和原初引力统计结构、在量子反弹后保留的低带宽信息。  
**允许简称：**回声。  
**标题性称呼：**宇宙回声，谨慎使用。  
**禁止误解：**声波；维因的意识；旧宇宙实时发来的通信；宇宙人格的声音。

“十维”指其来源与内容涉及完整十维时空历史，不表示信号沿第十个空间方向传播。

## 89. 跨宇宙信息

**标准术语：**跨宇宙信息  
**定义：**通过宇宙整体初始条件的统计结构从旧宇宙保留到新宇宙的有限信息。  
**禁止表述：**人物穿过宇宙边界发消息；反弹两侧实时对话。

## 90. 低带宽原则

**标准术语：**低带宽原则  
**定义：**跨宇宙回声只能保存高度压缩的数学结构、历史序列和有限概念，不能保存完整个体、数据库或技术图纸。  
**允许简称：**回声带宽限制。

## 91. 回声第一层：存在证明

**标准名称：**第一层回声；正式功能名为“存在证明”。  
**内容：**证明当前宇宙并非唯一宇宙周期，异常不是新宇宙文明制造。  
**首次确认：**第一卷末，`N-C05`。  
**禁止提前明确：**回声计划创建者、完整降维史和量子反弹工程细节。

## 92. 回声第二层：历史骨架

**标准名称：**第二层回声；正式功能名为“历史骨架”。  
**内容：**维度递减序列、战争后果和关键因果关系。  
**首次系统解码：**第二卷，`N-D01—N-D04`。  
**禁止误解：**逐字逐句历史档案。

## 93. 回声第三层：实验见证

# 第十一部分　知识、证据与治理术语

## 145. 事实层

**标准术语：**事实层  
**定义：**旧宇宙存在、维度递减和实验事故确实发生等结论性事实。  
**公开原则：**在有限公开方案中公开。

## 146. 观测层

**标准术语：**观测层  
**定义：**支持事实的统计特征、误差范围、仪器来源和独立复核结果。  
**公开原则：**公开到足以独立验证，但不包含完整设备复现参数。

## 147. 理论约束层

**标准术语：**理论约束层  
**定义：**说明哪些物理关系必须成立、哪些模型被排除的数学与逻辑结构。  
**公开原则：**公开不直接给出成核阈值和工程实现的部分。

## 148. 工程参数层

**标准术语：**工程参数层  
**定义：**真空势具体参数、泡成核阈值、场调制结构、边界算法和可扩展设备配置。  
**公开原则：**有限公开中继续封锁。  
**禁止混用：**把“理论公开”自动写成“工程参数已公开”。

## 149. 结论可验证

**标准术语：**结论可验证  
**定义：**其他文明能够利用独立观测或安全方法确认历史与风险结论。  
**禁止等同：**能够制造同类装置。

## 150. 工程可复现

**标准术语：**工程可复现  
**定义：**拥有足够参数、设备、材料和控制链，能够重新制造同一物理过程。  
**关键区别：**有限公开追求“结论可验证”，主动限制“工程可复现”。

## 151. 验证权

**标准术语：**验证权  
**定义：**文明有能力独立检查证据来源、推理过程和历史真实性。  
**伊蓝立场核心：**没有验证权会形成永久知识垄断。

## 152. 制造权

**标准术语：**制造权  
**定义：**文明获取完整参数并实际建设危险技术的能力和制度许可。  
**关键区别：**验证权不自动包含制造权。

## 153. 知识垄断

**标准术语：**知识垄断  
**定义：**少数机构不仅控制危险工程参数，也控制其他文明确认事实真假的渠道。  
**禁止扩大：**任何暂时保密都必然等于永久垄断。

## 154. 危险知识扩散

**标准术语：**危险知识扩散  
**定义：**能够降低降维理论推导、设备制造或风险误用门槛的信息在多文明间传播。  
**固定结论：**事故数据和多文明副本使其无法被彻底收回。

## 155. 分层证据包

**标准术语：**分层证据包  
**技术编号：**`COM-N4`。  
**定义：**将事实、观测、理论约束和工程参数按风险分层的数据结构。  
**禁止误解：**简单删掉几个关键数字即可永久阻止复现。

## 156. 权限分离

**标准术语：**权限分离  
**定义：**启动、校准、能量供给、中止、记录和公开由不同主体掌握，防止单个人物或机构完全控制技术链。  
**固定应用：**第三层验证实验。  
**禁止写法：**弥娅、赫森或伊蓝任一人拥有总开关。

## 157. 不可回滚记录

**标准术语：**不可回滚记录  
**定义：**一旦由多个独立节点签名保存，单一机构无法删除或修改全部副本的观测记录。  
**注意：**不可回滚不等于永不损坏，也不等于向所有文明公开全部内容。

## 158. 有限公开的固定公开内容

统一表述为：

1. 旧宇宙存在的证据；

统一表述为：

- 场调制工程结构；
- 边界稳定算法；
- 可扩展武器化方法；

# 第十三部分　叙事用词规范

## 168. 推荐使用的物理表达

- 一个宏观空间自由度停止传播；
- 目标模态越过了紧致化阈值；
- 泡壁脱离了装置控制；
- 关闭激发器终止了能量输入，但没有终止相变；
- 结构无法嵌入剩余空间维数；
- 路径解不再存在；
- 观测只支持概率，不能确认唯一来源；
- 该区域被限制为永久拓扑缺陷；
- 新宇宙重新展开维度，不是恢复旧宇宙物质。

## 169. 可以谨慎使用的文学表达

以下表达可以用于人物感知、媒体或标题，但不能独自承担物理解释：

- 方向死去；
- 空间失去一条道路；
- 城市被从一种连接中剥离；
- 宇宙留下伤疤；
- 维度之墓；
- 回声穿过重启；
- 光抵达以前，边界已经决定了结果。

## 170. 不推荐的误导性表达

- 空间被压成纸片；
- 高维生物可以看穿一切；
- 降维把物质完整投影到低维；
- 量子纠缠实现瞬时通信；
- 回声保存了维因的灵魂；
- 宇宙记住了所有人；
- 高维文明跳出时间；
- 低维泡吞噬能量后成长；
- 闭合曲率陷阱消灭了真空泡；
- 小宇宙逃过了宇宙重启。

## 171. 禁止作为真实机制的词语

以下词可以出现在宗教、哲学、比喻或人物误解中，但不得成为真实物理机制：

- 神迹；
- 宇宙意志；
- 灵魂；
- 转世；
- 预言；
- 维度威压；
- 精神力改写现实；
- 命运安排；
- 造物主指令；
- 不可名状力量；
- 超脱因果；
- 意识场永久存在。

## 172. “无法理解”的使用限制

“无法理解”只能描述人物当前缺乏模型、感官或信息，不能代替作者建立规则。

推荐改写：

- 现有模型无法解释该谱线；
- 观测网络缺少该尺度的数据；
- 目标结构无法投影到当前感知接口；
- 人物只能看到低维截面，因此暂时误判连接关系。

## 173. 降维灾难的差异化词汇

不同阶段优先强调不同能力损失：

| 阶段 | 推荐核心词汇 | 避免重复 |
|---|---|---|
| `S9→S8` | 路径断裂、连接失效、节点分离 | 只写压扁 |
| `S8→S7` | 材料失稳、化学体系崩溃、设备重制 | 只写建筑坍塌 |
| `S7→S6` | 连接度下降、计算拆分、记忆删减 | 只写算力变慢 |
| `S6→S5` | 身体重构、人格分叉、连续性危机 | 所有人上传成功 |
| `S5→S4` | 交通终止、信息延迟、制度分裂 | 只写距离变远 |
| `S4→S3` | 坐标隐藏、猜疑链、先发风险 | 黑暗森林突然出现 |

## 174. “十维回声”的修辞边界

“回声”可以承载以下文学意义：

- 旧宇宙只能留下被严重压缩的后果；
- 新宇宙听到的是结构，不是说话者；
- 回声既是警告，也是重建危险知识的起点。

不得把回声拟人化为：

- 主动选择弥娅；
- 判断新宇宙道德；
- 有意诱导文明毁灭；
- 在关键时刻回答人物问题。

- 第三层验证联合组；
- 宇宙静默协议；
- 全域公开协议；
- 分层证据包；
- 有限公开方案；
- 公共回声验证网络；
- 黑暗森林行为；
- 空间自由度异常。

## 180. 全书结尾必须保持不确定

可以使用：

- 疑似降维异常；
- 空间自由度异常；
- 局部传播模态减少；
- 边界缓慢变化；
- 三种解释并存。

不得使用确定表述：

- 第一次新宇宙降维攻击已经发生；
- 某文明完成武器化；
- 循环必然重启；
- 弥娅方案已经失败；
- 异常只是自然现象。

## 184. 新机构命名规则

机构名称优先采用：

```text
作用范围 + 风险或对象 + 机构功能
```

技术名称必须能回答“测量什么、改变什么、如何工作或属于什么系统”。

推荐后缀：

- 仪；
- 谱仪；
- 阵列；
- 网络；
- 节点；
- 激发器；
- 选择器；
- 编码器；
- 调制器；
- 接口；
- 系统；
- 陷阱；
- 载体。

谨慎后缀：

- 炮；
- 神器；
- 核心；
- 引擎；
- 门；
- 奇点。

这些词并非绝对禁止，但必须具有明确工程含义。

## 186. 新人物命名规则

核心人物现有姓名保持不变。

新增人物应避免：

- 与维因、弥娅、赫森、伊蓝读音过近；

- 仅凭名称标记其文明立场。

## 187. 暂定名称管理

尚未正式命名的对象使用功能性占位称呼，例如：

- 首个受灾殖民文明；
- 某独立防御文明；
- 边缘观测节点；
- 第一次泄露副本；
- 结尾异常区域。

占位称呼不得悄然在正文中变成正式专名。

## 188. 维度相关

| 错误或模糊写法 | 标准写法 | 原因 |
|---|---|---|
| 十个空间维度 | 九个空间维度加一个时间维度 | 维度计数错误 |
| 第十个空间方向 | 第十个方向仅作文学标题 | 不存在第十个空间维度 |
| 维度被删除 | 维度紧致化到宏观不可访问 | 数学结构并未绝对消失 |
| 时间也被降维 | 普通降维只作用于空间维度 | 时间维度固定保留 |
| 全宇宙同时降一维 | 不同区域和文明逐步进入低维环境 | 时间线不要求同步 |

## 189. 真空泡相关

| 错误或模糊写法 | 标准写法 | 原因 |
|---|---|---|
| 降维爆炸 | 低维真空泡成核并扩张 | 不是传统爆炸 |
| 泡吞噬物质获得能量 | 泡因真空能差自发扩张 | 机制错误 |
| 关闭装置就能停泡 | 只能终止外部输入 | 跨临界后相变自持 |
| 曲率陷阱消灭了泡 | 将微型泡限制为永久缺陷 | 没有恢复原状态 |
| 两个泡互相抵消 | 可能合并、形成域壁或更低维结构 | 不会无代价恢复 |

## 190. 回声相关

| 错误或模糊写法 | 标准写法 | 原因 |
|---|---|---|
| 维因给弥娅留言 | 弥娅读取包含维因记录片段的回声 | 不是定向私人通信 |
| 维因意识穿越重启 | 只有极低带宽统计信息保留 | 禁止人格穿越 |
| 回声是完整数据库 | 回声是三层压缩结构 | 带宽限制 |
| 第三层是武器图纸 | 第三层是实验见证结构 | 不含完整工程参数 |
| 回声主动选择弥娅 | 弥娅通过研究发现异常 | 回声无主观意志 |

## 191. 文明与机构相关

| 错误或模糊写法 | 标准写法 | 原因 |
|---|---|---|
| 文明一致决定 | 获授权机构代表文明作出对外决定 | 文明内部存在异议 |
| 安全委员会统治宇宙 | 安全委员会只约束授权成员和接入设施 | 非宇宙政府 |
| 开放派公开全部参数 | 伊蓝最终接受封锁部分工程参数 | 人物弧线要求 |
| 静默派都是独裁者 | 静默是有现实安全基础的倾向 | 不得脸谱化 |
| 联径共同体是国家 | 联径共同体是共享路径维持的文明群 | 高维社会结构不同 |

## 192. 知识治理相关

| 错误或模糊写法 | 标准写法 | 原因 |
|---|---|---|

# 第十八部分　不可修改的术语结论

## 195. 固定结论

以下术语结论不得在低优先级文件中改变：

1. “十维时空”固定指九个宏观空间维度加一个时间维度。
2. `S9—S3` 只表示宏观空间维数。
3. `O` 表示旧宇宙，`N` 表示新宇宙，`R` 表示量子反弹阶段。
4. 普通降维只作用于空间维度。
5. “降维”在物理上以维度紧致化和真空相变解释。
6. “低维真空泡”是正式核心术语。
7. 泡壁不是物质墙，也不超过局部光速。
8. “局部维度闭锁系统”是第一次隔离工程的正式名称。
9. “降维武器”是失控和军事化后的历史类别称呼。
10. `VAC-08` 不能称为能够恢复宏观维度的装置。
11. “主动低维化”不等于无损压缩。
12. “文明连续性”包含生物、个体、信息和制度四个维度。
13. “十维回声”不是声波、意识或双向通信。
14. 回声固定分为存在证明、历史骨架和实验见证三层。
15. “量子反弹”不是文明技术。
16. “质量归还广播”是证据与责任请求，不是宇宙命令。
17. “联径共同体”是维因所属文明群的正式名称。
18. “边界协调工程署”是第一次隔离工程机构的正式名称。
19. “原初关联观测网络”是弥娅所属研究网络的正式名称。
20. “跨文明极端风险安全委员会”可简称文明安全委员会或安全委员会。
21. “开放科学协作网”是伊蓝所代表制度网络的正式名称。
22. “宇宙静默协议”由赫森主要提出。
23. “全域公开协议”由伊蓝主要提出。
24. “有限公开方案”由弥娅主要提出。
25. “公共回声验证网络”不等于降维技术公开制造平台。
26. “验证权”与“制造权”必须分开表述。
27. “结论可验证”与“工程可复现”必须分开表述。
28. “黑暗森林行为”不等于成熟黑暗森林已经形成。
29. 结尾只能称为“疑似降维异常”或“空间自由度异常”，不得确认唯一来源。
30. 维因与弥娅的关系只能称为单向历史关系，不得使用转世、血缘或双向通信术语。
31. 高维文明、静默派和开放派均不得用单一正邪标签命名。
32. 新增技术名称必须说明功能、限制和编号归属。
33. 新增文明名称必须反映结构、功能或历史，不得只反映正邪立场。
34. 待定对象必须继续使用功能性占位称呼，直至专项 Canon 正式命名。
35. 本文件中的简称不得扩大机构权限或技术能力。
36. 文学表达不得覆盖科学定义。

# 第二十部分　术语主题摘要

## 203. 物理术语因果链

```text
亚稳高维真空
    → 维度模场可被激发
    → 局部低维相成核
    → 低维真空泡越过临界尺度
    → 泡壁自发扩张
    → 宏观空间自由度减少
    → 物质、生命和文明结构失去可嵌入性
```

## 204. 技术术语因果链

```text
局部维度闭锁系统
    → 第一次人工降维
    → 事故广播与独立复现
    → 降维武器军事化
    → 防御性降维与真空相对冲
    → 连续维度战争
```

## 205. 回声术语因果链

```text
质量归还
    → 旧宇宙整体坍缩
    → 回声计划编码
    → 量子反弹
    → 原初关联异常
    → 三层回声解码
    → 第三层真空相验证实验
```

## 206. 知识治理术语因果链

```text
实验数据不可彻底删除
    → 宇宙静默协议
    ↔ 全域公开协议
    → 两种方案均产生反作用
    → 有限公开方案
    → 公共回声验证网络
    → 风险被延缓而非消除
```

## 207. 最终术语原则

《十维回声》的术语必须让读者始终能够区分：

- 物理现象与文学比喻；
- 历史称呼与工程正式名称；
- 结论验证与技术复现；
- 文明立场与固定政治阵营；
- 微型限制与宏观逆转；
- 信息保存与人格存活；
- 跨宇宙回声与跨宇宙通信；
- 延缓风险与解决风险。

术语的作用不是让世界显得更加神秘，而是让每项选择的真实边界更加清楚。
