## 0. 文件职责

本文件定义《十维回声》中各类技术的工程组成、使用条件、能力边界、代价、失效方式、可观测特征和制度接口。

本文件负责回答：

- 完整十维时代的高维交通、定位、通信、计算和生命维护如何运作；
- 维因参与设计的维度隔离工程由哪些模块组成；
- 第一次人工降维为何需要文明级基础设施，而不是单个天才或便携装置；
- 降维技术如何从隔离工程演化为战略武器；
- 为什么降维防御会推动更低维技术出现；
- 文明如何进行主动低维化、生命载体重构和信息删减；
- 小宇宙、质量归还广播和回声计划分别依赖哪些工程系统；
- 弥娅如何观测、识别和解码十维回声；
- 第三层回声实验如何实施、为何失控、又为何只能被一次性限制；
- 赫森能够调用哪些监测和权限系统，以及这些系统为何无法实现全宇宙控制；
- 伊蓝如何建立公共验证网络，同时避免直接公开完整武器参数；
- 后续新增技术必须说明哪些工程字段，不能绕过哪些硬性限制。

本文件不重新定义维度、真空相变、量子反弹或信息传播的基础物理规律。相关规则以 `canon/01-physics-rules.md` 为准。

本文件不决定技术由哪个文明合法拥有、由谁授权使用或社会如何评价。相关制度以 `canon/04-civilizations.md` 为准。

若本文件与低优先级大纲或正文冲突，应修改低优先级内容。若与 `canon/00-series-bible.md` 或 `canon/01-physics-rules.md` 冲突，则必须修改本文件，不得为保留某段情节临时增加技术例外。

# 第一部分　技术设计总原则

## 1. 技术不是能力标签

任何重要技术都必须被写成一个由多个模块、人员、基础设施和制度共同组成的系统，而不是一句“高等文明已经掌握”。

一项正式技术至少需要明确：

1. **目标：**它试图解决什么问题；
2. **物理作用：**它实际改变或测量什么；
3. **输入：**需要何种能量、材料、数据和边界条件；
4. **输出：**产生何种可测结果；
5. **基础设施：**依赖哪些预先建设的网络或设备；
6. **精度：**能够控制到什么程度；
7. **尺度：**微观、局部、文明级还是宇宙级；
8. **代价：**能源、时间、信息、生命、环境或政治成本；
9. **失效方式：**技术如何偏离目标；
10. **外部特征：**其他文明如何发现其正在运行；
11. **权限边界：**谁能启动、校准、终止或验证；
12. **不可实现事项：**该技术不能做什么。

任何不能回答以上多数问题的“新技术”，不得直接写入正式正文。

## 2. 技术必须服从局部因果

所有技术系统必须遵守：

- 信号沿完整时空中的局部路径传播时不超过局部光速；
- 高维交通通过缩短路径实现低维投影中的快速到达，不是局部超光速；
- 控制命令必须经历实际传播过程；
- 远距离设备不能在无预置网络、无同步误差和无延迟的情况下同时动作；
- 越接近光速扩张的低维泡壁，远方文明能够获得的有效预警时间越短；
- 量子纠缠不能用于无信号通信、复制未知量子态或保留可直接读取的隐藏备份。

不得用“高维通信”“量子网络”或“拓扑通道”等词绕过因果限制。

## 3. 技术越强，系统依赖越重

本项目固定采用以下关系：

```text
作用尺度增大
    → 能量与校准需求增加
    → 设备数量和协作主体增加
    → 数据副本与制度接口增加
    → 保密难度、误差来源和失控后果同时增加
```

因此：

- 文明级工程不可能只依赖一个按钮；
- 宇宙性技术不可能完全没有外部特征；
- 多文明参与可以提高可信度，却会降低绝对保密性；
- 集中权限可以减少操作主体，却会制造单点失效和权力垄断；
- 分布式验证可以防止历史被篡改，却会增加不完整参数被拼接的风险。

## 4. 工程控制不等于物理控制

文明可以通过技术提高某种过程的发生概率、选择初始条件或改变局部路径，但不能因此完全支配自然过程。

尤其是维度工程：

- 可以选择大致成核区域；
- 可以选择一个局部维度本征方向或方向组合；
- 可以调节初始泡壁形状；
- 可以在微型成核期设置曲率和真空能梯度；

但不能保证：

- 泡壁永远保持设计形状；
- 宏观扩张随时停止；
- 泡自动避开友军；
- 泡内物质按预期无损映射；
- 不同真空域相遇后仍服从原计划；
- 已经降维的区域被完整恢复。

## 5. 任何防御都必须改变风险分布

本项目不允许无副作用的终极防御。

防御技术只能在以下代价中进行选择：

- 将风险从核心区域转移到牺牲区；
- 将立即毁灭转化为长期结构损失；
- 以主动低维化换取部分文明延续；
- 以更低维真空相改变来袭泡的传播；
- 切断交通和通信以降低暴露；
- 建立监控体系并牺牲科研自由和跨文明信任；
- 公开部分证据并承担知识扩散风险。

不得设计“防住降维但不损失任何空间、生命、信息或制度自由”的设备。

## 6. 技术进步不能抹除历史成本

后期文明可以改进效率、精度、可靠性和部署方式，但不得让技术演化自动消除早期限制。

固定原则：

- 小型化不等于无能源需求；
- 自动化不等于无决策责任；
- 算法进步不等于可以预测所有多文明行为；
- 更高精度不等于零误差；
- 更强材料不等于能够阻挡真空相变；
- 更完整数据库不等于能够恢复已丢失的维度和人格；
- 更先进的监测不等于能够证明遥远异常的唯一来源。

## 7. 技术必须有可观测痕迹

大型技术活动至少会留下下列一种或多种痕迹：

- 能量和热排放；
- 引力或曲率扰动；
- 维度模态谱变化；
- 交通网络负载异常；
- 材料和设备的大规模调配；
- 计量基准同步请求；
- 通信流量和权限结构变化；
- 周围真空涨落统计偏离；
- 长期准备设施或牺牲区建设。

文明可以伪装、延迟或分散这些痕迹，但不能无成本完全消除。

## 8. 技术与制度不可分离

任何危险技术都必须同时描述技术链和权限链。

例如，第三层实验的“启动”不是一个动作，而是：

```text
观测模型通过复核
    → 多文明计量基准完成转换
    → 成核区与牺牲区完成隔离
    → 能量系统分段授权
    → 模场激发器获得短时运行权限
    → 独立观测节点开始不可回滚记录
    → 自动中止系统进入本地控制
    → 实验窗口开启
```

只要其中任何一环由不同主体掌握，就不存在单个人物完全控制全部技术的情节。

## 9. 技术名称应描述功能，不制造神秘感

正式技术名称优先采用：

- 被测对象；
- 作用对象；
- 工程功能；
- 网络结构；
- 所处阶段。

推荐：

- “维度模态谱仪”；
- “各向异性边界阵列”；
- “多尺度原初关联观测网”；
- “闭合曲率陷阱”；
- “分层证据包”。

谨慎使用：

- 神器式专名；
- 无法从名称判断功能的代号；
- “终极”“绝对”“全知”“无限”等词；
- 用“量子”“高维”作为万能形容词。

# 第二部分　技术分类与成熟度

## 10. 技术分类编号

为便于大纲和技术档案引用，本文件使用以下类别编号。

| 前缀 | 类别 | 主要内容 |
|---|---|---|
| `MET` | 计量与观测 | 时空测绘、真空测量、维度模态、原初关联观测 |
| `TRN` | 交通与定位 | 高维测地线、交通节点、坐标网络、低维时代航行 |
| `COM` | 通信与证据 | 因果中继、广播、分布式记录、公共验证 |
| `CMP` | 计算与记忆 | 高维计算、模型求解、档案删减、身份记录 |
| `MAT` | 材料与制造 | 高维材料、相结构、设备制造、跨维适配 |
| `LIF` | 生命与连续性 | 多中心身体、载体重构、主动低维化、生态种子 |
| `VAC` | 真空与维度工程 | 模场激发、成核、边界控制、低维泡监测 |
| `DEF` | 防御与风险控制 | 曲率引导、牺牲区、主动低维化、异常监测 |
| `COS` | 宇宙尺度工程 | 小宇宙、质量归还、回声编码、反弹前准备 |
| `GOV` | 技术治理 | 权限分离、审计、参数封锁、分层公开 |

编号用于设定管理，不要求正文频繁展示。

## 11. 技术成熟度等级

技术成熟度采用六级描述。

| 等级 | 名称 | 定义 |
|---|---|---|
| `T0` | 理论假说 | 只有数学结构或间接观测，没有可控实验 |
| `T1` | 观测确认 | 已确认相关物理现象存在，但不能主动制造 |
| `T2` | 受控微型实验 | 能在严格条件下制造短时或微小效应 |
| `T3` | 工程原型 | 能重复运行，但依赖大型设施且失效风险高 |
| `T4` | 文明级部署 | 可用于交通、生产、防御或战略行动 |
| `T5` | 广泛基础设施化 | 技术被大量节点采用，成为文明日常结构的一部分 |

成熟度只描述工程普及程度，不表示技术更安全、更道德或更容易控制。

例如：

- 高维交通网络在 `O-A` 可达到 `T5`；
- 第一次人工降维在 `O-B02` 由 `T2/T3` 直接暴露出宏观失控能力；
- 降维武器在 `O-C` 至 `O-D` 逐步达到 `T4`；
- 新宇宙第三层实验在 `N-E` 只允许达到 `T2`，不得在第三卷公开进入 `T4`。

## 12. 技术系统的六层结构

任何复杂技术可拆分为六层：

1. **物理层：**实际场、材料、能量和时空过程；
2. **计量层：**如何测量、校准和判断状态；
3. **控制层：**如何改变参数和执行中止；
4. **计算层：**如何建模、预测和处理数据；
5. **网络层：**设备、节点和文明之间如何协作；
6. **治理层：**权限、责任、审计和公开边界。

技术失控可以发生在任一层，也可以由多层误差共同作用。

第三卷实验事故固定采用“模型缺失 + 计量转换偏差 + 模态交叉耦合 + 中止时机滞后”的复合失效，不得简化为单个操作员按错按钮。

# 第三部分　完整十维时代的基础技术

## 13. 高维计量体系 `MET-S9`

完整十维时代的工程首先依赖对九个宏观空间方向、局部度规和维度模态的持续测量。

### 13.1 核心设备

#### 高维度规测绘阵列

功能：

- 测量局部空间方向之间的距离关系；
- 重建可用高维测地线；
- 识别交通节点附近的曲率变化；
- 为大型结构提供统一坐标基准。

限制：

- 只能测量因果可达区域；
- 测绘结果随大规模工程和真空扰动变化；
- 不同文明的坐标基准需要转换；
- 无法给出全宇宙实时地图。

#### 维度模态谱仪

功能：

- 测量各空间方向的有效尺度和稳定性；
- 识别维度模场的低频振荡；
- 判断某一方向是否接近紧致化阈值；
- 为维度工程提供反馈。

限制：

- 输出是统计谱和模型参数，不是直接“看见维度”；
- 测量精度受探针能量、背景噪声和设备耦合影响；
- 接近相变时，测量本身可能扰动局部模场。

#### 真空状态层析网

功能：

- 通过多个位置和尺度的探测器重建局部真空势形态；
- 区分普通物质扰动、设备噪声和真空结构变化；
- 估计成核概率和泡壁方向。

限制：

- 不能获得真空的“完整精确状态”；
- 结果依赖理论模型；
- 对未知相结构只能给出异常，而不能自动解释。

### 13.2 计量基准

不同文明的工程系统不能天然共享同一套坐标、时间和能量单位。

跨文明协作必须建立：

- 无量纲比值基准；
- 可重复的局部物理过程；
- 多点时钟同步；
- 坐标变换和误差传播规则；
- 校准记录与责任签名。

第三卷实验中的微小偏差，部分来自不同文明基准转换后仍保留的系统误差。

## 14. 高维交通系统 `TRN-S9`

### 14.1 基本原理

高维交通系统不提高局部速度上限，而是通过：

- 测绘更短的高维测地线；
- 在关键位置维持稳定曲率结构；
- 建立允许大型物体安全通过的路径窗口；
- 以共享坐标网络进行入口、出口和负载协调。

### 14.2 标准组成

一个成熟交通节点至少包括：

- 高维度规测绘阵列；
- 路径稳定器；
- 入口定位场；
- 交通负载调度系统；
- 局部因果与碰撞预警；
- 多文明坐标转换接口；
- 失效时的隔离和疏散路径。

### 14.3 联径节点

维因所属的联径共同体主要维护一种共享高维交通节点，正式统称：

**联径节点。**

联径节点的社会意义大于单纯交通设施：

- 它决定哪些区域在实际几何上互为近邻；
- 它承载坐标公开、身份验证和资源交换；
- 节点关闭会改变文明边界；
- 节点被降维摧毁时，原本统一的文明可能在短时间内被分裂为多个因果共同体。

### 14.4 固定限制

联径节点不能：

- 将未测绘区域直接连接；
- 瞬时穿越任意距离；
- 在失去所依赖空间方向后继续工作；
- 无视入口和出口的局部物质环境；
- 让文明对全部节点同时保持零延迟控制。

### 14.5 降维后的失效

当某个节点所依赖的空间方向紧致化时：

- 路径解不再存在；
- 入口与出口的坐标转换失效；
- 已在路径中的交通体可能被迫退出、失联或解体；
- 路径负载转移到剩余节点，引发级联拥堵；
- 文明的政治与资源网络随之重新分区。

## 15. 高维通信系统 `COM-S9`

### 15.1 因果中继网络

高维文明依赖沿交通和测地线节点布置的中继系统传递信息。

它可以：

- 利用较短高维路径降低低维投影中的延迟；
- 在多个节点之间进行冗余传输；
- 为跨文明协议提供时间戳和来源证明；
- 在路径失效时选择替代路线。

它不能：

- 无视节点距离瞬时广播；
- 在网络被降维切断后保持原同步速度；
- 证明遥远文明的“当前”状态；
- 防止所有消息伪造、延迟和选择性转发。

### 15.2 坐标广播

完整十维时代的文明通常公开：

- 主要交通入口；
- 可用通信路径；
- 计量基准；
- 协议身份；
- 基础设施状态。

公开坐标不是把所有内部结构暴露给所有人，而是维持交通和信任的必要条件。

### 15.3 应急广播

大型工程事故会自动生成多层应急包：

- 设备状态；
- 计量基准；
- 失效类型；
- 周边危险区；
- 可验证的原始观测片段；
- 请求支援所需的最少工程参数。

第一次降维事故和第三卷实验事故的数据扩散，都部分来自自动应急广播。

应急广播不能只发“危险警告”而完全不包含可验证数据，否则其他文明无法判断其真实性并采取行动。

## 16. 高维计算系统 `CMP-S9`

### 16.1 多向连接计算结构

九个宏观空间方向允许计算结构具有远高于三维系统的连接度。

其优势包括：

- 大量功能单元可保持短路径连接；
- 并行数据交换成本较低；
- 群体计算结构可以分布于多个空间中心；
- 某些拓扑算法可直接映射到物理结构。

其限制包括：

- 仍需要有限能量与散热；
- 计算速度不突破局部因果；
- 高连接度增加校准和故障传播复杂度；
- 一旦失去依赖方向，原有连接图无法完整嵌入低维空间。

### 16.2 高维模型求解器

维度工程依赖大型分布式求解系统，用于：

- 重建局部真空势；
- 估计成核概率；
- 搜索维度取向；
- 模拟泡壁初始演化；
- 评估设备误差和环境扰动。

模型输出是概率分布和可信区间，不是绝对预测。

### 16.3 记录与身份账本

高维文明使用分布式因果记录维护：

- 身体版本；
- 记忆分叉；
- 决策授权；
- 工程责任；
- 文明成员资格；
- 交通和研究访问权。

记录系统不能判定“哪个复制体在哲学上是真正原人”，只能保存可验证的因果与制度关系。

## 17. 高维材料与制造 `MAT-S9`

### 17.1 高维材料结构

高维材料可利用额外方向形成：

- 三维截面无法实现的连接；
- 高表面积散热结构；
- 多层互不相交的流体和信号通道；
- 复杂拓扑支撑；
- 对特定空间方向敏感的各向异性构件。

### 17.2 固定限制

高维材料并非无坚不摧。

其稳定性依赖：

- 当前宏观空间维数；
- 维度模态尺度；
- 局部真空状态；
- 温度、能量密度和结构取向；
- 制造误差和长期疲劳。

当其依赖的方向紧致化时，材料可能：

- 失去化学稳定性；
- 断开原有连接；
- 释放储存能量；
- 退化为另一种低维材料；
- 完全解体。

### 17.3 制造基础设施

大型真空工程设备必须由分布式制造系统完成，无法由单个实验室临时打印。

所需基础包括：

- 高维材料提纯；
- 大尺度结构同步装配；
- 局部真空洁净区；
- 多文明计量兼容；
- 长期应力和曲率测试。

## 18. 高维生命维护 `LIF-S9`

### 18.1 多中心生命协调

部分高维生命由多个结构中心组成，需要：

- 持续同步的生理信号；
- 高维路径维持；
- 结构版本管理；
- 局部损伤隔离；
- 身份连续性记录。

### 18.2 医疗和身体重构

高维医疗可以：

- 修复局部结构；
- 替换部分身体中心；
- 重建连接路径；
- 根据环境调整身体版本。

但不能：

- 从无信息状态恢复完整人格；
- 让所有复制分支保持同一主体；
- 在宏观降维后无损恢复被破坏的高维结构；
- 让核心人物无限复活。

# 第四部分　维度隔离工程

## 19. 工程正式名称

第一次人工降维项目的正式技术名称为：

**局部维度闭锁系统。**

在边界协调工程署内部，也可简称：

**闭锁系统。**

其原始设计目标是让一个受控区域暂时失去某一宏观空间通行方向，从而阻断舰队和大型交通体通过，而不是摧毁区域内物质。

“降维武器”是该技术失控并军事化后的历史称呼，不应在项目初期由维因团队主动使用。

## 20. 原始工程目标

局部维度闭锁系统的五项原始指标固定为：

1. 在无人或低人口区域制造局部闭锁区；
2. 阻断指定高维交通路径；
3. 不产生传统爆炸和直接能量打击；
4. 在撤去外场后保持边界稳定；
5. 在未来通过反向调制恢复原空间自由度。

第五项在第一次实验后被证明错误。

维因和团队在实验前有理由相信其可能实现，但不得写成已经有充分证据证明可逆、仍故意忽视。

## 21. 标准模块

局部维度闭锁系统由八个必需模块组成。

### 21.1 真空状态层析阵列 `VAC-01`

负责：

- 测量实验区真空势；
- 识别局部不稳定模态；
- 提供成核前基线；
- 监测外部环境扰动。

限制：

- 只能在模型允许的变量空间内重建状态；
- 对未知相变路径可能给出错误低风险估计。

### 21.2 维度模态选择器 `VAC-02`

负责：

- 从局部本征方向中选择目标模态；
- 调节激发频率和取向；
- 避免同时触发多个方向。

限制：

- 只能选择局部方向，不存在全宇宙固定“第几轴”；
- 模态之间可能发生交叉耦合；
- 相变后取向可能受环境重新选择。

### 21.3 维度模场激发器 `VAC-03`

负责：

- 向目标维度模态输入高密度、精确调制的能量；
- 将局部场推过相变势垒；
- 建立低维相初始种子。

限制：

- 不是“压缩空间”的机械装置；
- 能量输入不能决定泡壁长期命运；
- 激发器关闭后，已成核低维相可继续存在。

### 21.4 各向异性边界阵列 `VAC-04`

负责：

- 在成核区周围建立不同方向的场强梯度；
- 让相变优先沿预定取向形成；
- 降低初始泡壁随机变形。

限制：

- 只能影响成核早期；
- 不构成普通物质屏障；
- 泡越过临界尺度后无法靠阵列维持静止。

### 21.5 高维曲率锚定结构 `VAC-05`

负责：

- 固定实验区与外部交通网络的几何关系；
- 降低成核造成的整体漂移；
- 为恢复序列提供参考边界。

限制：

- 曲率锚并不能阻挡低维泡；
- 相变会改变锚定结构所依赖的几何本身；
- 过强锚定可能把应力转移到其他方向。

### 21.6 成核隔离腔 `VAC-06`

负责：

- 提供低噪声真空环境；
- 限制普通物质进入；
- 收集初始泡壁和粒子传播数据；
- 在事故早期隔离设备碎片和能量释放。

限制：

- 只能隔离普通物质过程；
- 不能作为真空相变的永久容器。

### 21.7 泡壁监测网 `VAC-07`

负责：

- 测量泡壁位置、速度和维度取向；
- 检测传播模态减少；
- 比较不同方向的引力和色散变化；
- 触发本地应急逻辑。

限制：

- 监测信号必须返回设备，存在传播延迟；
- 泡壁接近光速时，远方中央控制无法及时干预；
- 部分探测器会在泡壁到达时先于数据回传被破坏。

### 21.8 恢复与中止系统 `VAC-08`

原计划负责：

- 在泡未稳定时撤回激发；
- 反向调制维度模场；
- 将系统带回原真空态；
- 切断能量和交通连接。

实际结果：

- 在真正成核前可以中止；
- 在亚临界扰动阶段可能恢复；
- 一旦低维泡跨过临界尺度，反向调制不能恢复已转化区域；
- 关闭激发器只能终止外部输入，不能终止自发相变。

## 22. 维因的具体工程职责

维因不是全部八个模块的唯一设计者。

他的正式职责集中于：

- `VAC-04` 各向异性边界阵列的边界条件设计；
- `VAC-05` 高维曲率锚定结构与交通路径的兼容；
- `VAC-08` 恢复序列的理论和工程接口；
- 闭锁区对舰队通行能力的几何评估；
- 实验风险模型中的边界扩张项。

维因不独立掌握：

- 全部能源系统；
- 所有真空势参数；
- 全部材料制造；
- 所有观测数据；
- 工程署最终政治授权；
- 后续文明重建出的全部军事化变体。

维因的核心误判是：

> 他正确计算了装置对局部边界的控制，却错误外推了边界在形成新真空相后仍属于装置的一部分。

## 23. 第一次实验的启动链

第一次实验必须经过以下阶段：

1. 实验区完成长期真空和曲率测绘；
2. 相邻殖民区和交通网络完成风险距离评估；
3. 模态选择器锁定一个局部空间本征方向；
4. 边界阵列建立非对称梯度；
5. 曲率锚定结构稳定实验区；
6. 激发器以多阶段功率提升目标模场；
7. 成核隔离腔出现低维相种子；
8. 观测网确认一个传播自由度消失；
9. 外部激发停止；
10. 恢复系统执行反向序列；
11. 低维泡保持存在并继续扩张；
12. 工程从受控实验转为不可逆事故。

不得让事故在启动瞬间表现为普通爆炸。

## 24. 工程为何获得批准

技术层面的合理依据包括：

- 既有微弱模态扰动曾在撤去外场后衰减；
- 模型预测低维相需要持续外部能量维持；
- 成核区与有人区域之间存在当时看来足够的距离；
- 多个独立计量系统得到相近结果；
- 目标是非杀伤性边界而非攻击；
- 闭锁可替代更高伤亡的传统战争方案。

批准错误不能归因于所有人忽视明显常识，而应归因于：

- 对未知真空基态的错误模型；
- 把亚临界实验外推到真正成核；
- 低估低能真空泡的自发扩张；
- 高估恢复序列对新相的控制；
- 政治和战争压力使可接受风险阈值上升。

## 25. 第一次事故的技术数据

事故广播包含的公开信息必须至少能够证明：

- 某一宏观空间自由度确实消失；
- 成核需要定向模场激发；
- 泡壁会在撤去外场后继续扩张；
- 普通物质屏障无效；
- 高维生命在泡壁处发生结构丢失；
- 初始装置存在可被其他文明重建的功能模块。

事故广播不需要包含完整制造图，但足以让多个先进文明独立推导并复现核心过程。

# 第五部分　降维技术的军事化

## 26. 军事化的本质

军事化不是发现另一套新物理，而是将局部维度闭锁系统的工程链改造成：

- 更可靠的成核；
- 更远距离的投送；
- 更快的部署；
- 更隐蔽的准备；
- 更适合目标区的维度取向；
- 更少的本地操作人员；
- 更完整的自毁和参数封装。

低维泡的基本物理性质不随军事化改变。

## 27. 早期战略隔离器 `VAC-W1`

### 27.1 用途

早期使用方式包括：

- 切断高维航道；
- 关闭共享交通节点；
- 在交战区之间制造低维缓冲带；
- 破坏资源区与中心区域的几何邻接；
- 迫使舰队绕行。

### 27.2 特征

- 仍需大型固定设施；
- 成核准备时间长；
- 能量和曲率异常容易被发现；
- 攻击者也可能失去相关交通区域；
- 低维泡最终扩张范围无法保证只覆盖目标。

## 28. 可部署成核平台 `VAC-W2`

随着技术发展，文明将系统拆分为：

- 预先制造的模场激发核心；
- 目标区测绘探针；
- 远程校准节点；
- 一次性能源与热管理结构；
- 延时或条件触发系统。

它可以由专用舰队或隐蔽工程体投送，但仍不是手持武器。

固定限制：

- 目标区必须经过足够测绘；
- 投送平台必须接近可成核区域；
- 激发过程存在可探测的真空和引力特征；
- 设备很难在完全未知环境中稳定选择维度取向；
- 远程触发仍受因果延迟。

## 29. 战略低维种子 `VAC-W3`

后期文明可以把成核装置压缩为一次性“低维种子”。

低维种子包含：

- 预编码的模态选择；
- 高密度能源；
- 自校准探针；
- 短时边界阵列；
- 成核后失效的控制结构。

它的危险在于：

- 一旦成功成核，装置本身不再重要；
- 摧毁投送平台不能消除已形成低维泡；
- 预警系统必须在成核前识别；
- 错误取向可能产生攻击者也无法预测的新真空域。

低维种子仍不能：

- 任意远距离瞬时启动；
- 无准备穿透所有环境；
- 选择只杀死特定生命；
- 在完成任务后自动关闭；
- 让攻击者安全回收区域。

## 30. 降维投送方式

允许的投送方式包括：

- 专用高维舰队近距离部署；
- 隐蔽探针长期测绘后启动；
- 伪装成交通或观测设施的成核平台；
- 预埋在共享节点附近的工程核心；
- 沿既有高维短路径送达目标外围；
- 在低维时代通过普通远程航行或延时装置投送。

禁止：

- 无需接近目标的全宇宙瞬时投放；
- 通过意识锁定目标；
- 仅凭坐标字符串从任意地点直接成核；
- 在没有目标区物理模型的情况下保持高精度。

## 31. 武器的可探测性

军事化系统可以降低但不能消除以下特征：

- 大规模能量调集；
- 模态谱异常；
- 目标区长期测绘活动；
- 特殊材料和曲率设备；
- 交通节点负载异常；
- 成核前真空涨落偏离；
- 自动控制通信和时间同步。

战争后期，文明的主要竞争之一就是：

```text
更早识别成核准备
    与
更晚暴露成核意图
```

而不是单纯比较武器爆炸威力。

# 第六部分　降维防御系统

## 32. 防御层级

降维防御分为五个层级：

1. **预防：**限制高风险研究和设备；
2. **侦测：**识别成核准备和早期模态异常；
3. **逃逸：**在泡壁到达前离开未来影响区；
4. **引导：**在微型或早期阶段改变泡壁传播路径；
5. **适应：**主动改造文明，使部分结构能在低维环境生存。

不存在第六层“无损阻挡并恢复原空间”。

## 33. 成核预警网 `DEF-01`

### 33.1 功能

- 长期监测维度模态谱；
- 识别异常能量调制；
- 比较目标区交通与材料活动；
- 对已知成核设备特征进行模式匹配；
- 提供风险概率而不是确定结论。

### 33.2 限制

- 自然真空涨落和合法研究可能产生相似信号；
- 隐蔽平台可能只在最后阶段显现；
- 泡壁扩张速度接近光速，成核后远程预警价值有限；
- 误报会推动先发制人；
- 对未知技术变体的识别能力有限。

## 34. 高维逃逸系统 `DEF-02`

逃逸依赖：

- 泡壁尚未切断的高维路径；
- 预先准备的交通容量；
- 可用目标区域；
- 对泡壁方向和速度的估计；
- 对人员、知识和设备的优先级选择。

逃逸不能保证：

- 所有成员撤离；
- 逃离区域不会被另一个低维泡覆盖；
- 迁移文明保持原制度和身体结构；
- 路径在整个撤离过程中持续存在。

## 35. 曲率引导阵列 `DEF-03`

### 35.1 原理

在泡壁尚小且附近几何已被预先设计时，通过高维曲率梯度改变泡壁局部传播代价，使其优先沿某条路径扩张。

### 35.2 能力

- 偏转微型泡；
- 为撤离争取有限时间；
- 将泡引向无人牺牲区；
- 在第三卷实验中形成闭合路径的一部分。

### 35.3 限制

- 不能让宏观泡停止；
- 需要在事故前建设；
- 作用范围有限；
- 曲率结构本身可能切断交通；
- 偏转只是改变受害区域，不消除相变。

## 36. 真空相对冲 `DEF-04`

### 36.1 原理

在来袭低维泡附近制造另一种更低能或不同取向的真空相，使泡壁发生：

- 偏折；
- 分裂；
- 局部减速；
- 域壁锁定；
- 向其他区域重定向。

### 36.2 防御悖论

要稳定一个已经更低能的真空泡，防御方通常必须：

- 使用更低维的相；
- 制造新的永久真空缺陷；
- 接受另一种不可逆降维；
- 公开或研发更危险的模场控制方法。

因此，`DEF-04` 同时也是下一代降维武器的技术来源。

## 37. 闭合曲率陷阱 `DEF-05`

### 37.1 定义

闭合曲率陷阱是在有限区域内预先建立一条高曲率闭合路径，使微型低维泡沿该路径传播并最终被限制为永久拓扑缺陷。

### 37.2 第三卷用途

第三卷实验采用的限制系统由以下部分组成：

- 多层曲率梯度；
- 非对称真空能井；
- 可切断的高维连接；
- 无人或低价值牺牲区；
- 本地自动控制；
- 独立泡壁监测。

### 37.3 固定限制

- 只适用于预设实验环境中的微型泡；
- 必须在泡越过更大尺度临界点前完成引导；
- 陷阱内区域永久失去一个空间自由度；
- 设施和仍在其中的生命可能被牺牲；
- 无法扩展为行星、星系或全宇宙护盾；
- 不能恢复泡内原始状态。

## 38. 防御技术的制度后果

任何成核预警和防御网络都会要求：

- 监测高能实验；
- 审查特殊材料和能源流；
- 记录交通与坐标活动；
- 限制匿名研究；
- 对异常设施进行干预；
- 建立先发制人的风险阈值。

因此，防御系统本身会推动：

- 科研转入秘密区域；
- 文明降低广播；
- 监测机构扩大权限；
- 正常研究被误判；
- 黑暗森林式行为提前出现。

# 第七部分　文明主动低维化与保存技术

## 39. 主动低维化的定义

主动低维化不是把原文明整体无损“压缩”到更低维，而是提前构造能够在目标维数下运行的新载体、材料和制度核心。

其基本过程为：

1. 识别目标维数中可稳定存在的物质；
2. 建立高维到低维的信息映射；
3. 选择需要保留的个体、知识和规则；
4. 重构生命或机器载体；
5. 在受控低维区进行长期测试；
6. 放弃无法映射的结构；
7. 迁移到已经低维化的环境；
8. 承认原文明连续性已经发生不可逆变化。

## 40. 低维映射器 `LIF-01`

功能：

- 分析高维身体和设备的连接图；
- 找出无法嵌入目标维数的结构；
- 设计低维近似功能；
- 估计记忆、感知和计算损失；
- 生成多个迁移方案。

限制：

- 不能证明哪种方案保留“真正人格”；
- 不能无损映射所有连接；
- 功能相似不等于个体连续性；
- 目标维数越低，必须删除的结构越多。

## 41. 低维生命载体 `LIF-02`

低维生命载体可以采用：

- 重新设计的生物体；
- 生物—机器混合载体；
- 纯机器继承体；
- 生态种子；
- 可重新演化的发育程序。

所有载体都必须付出：

- 身体结构损失；
- 感知范围下降；
- 记忆或人格删减；
- 计算能力下降；
- 繁殖和修复方式改变；
- 身份法律重新定义。

## 42. 信息删减系统 `CMP-LOW`

### 42.1 功能

在计算和存储结构无法全部迁移时，文明使用信息删减系统进行：

- 知识重要度排序；
- 依赖关系分析；
- 冗余压缩；
- 低维可执行性检查；
- 文化和制度规则抽取；
- 删除后果模拟。

### 42.2 固定冲突

删减系统不能提供客观唯一答案。

必须由文明作出选择：

- 保存更多个体还是更多知识；
- 保存历史还是生存技术；
- 保存原人格还是提高低维适应性；
- 保存复杂制度还是减少运行成本；
- 保存多样性还是提高迁移成功率。

## 43. 六类保存载体

### 43.1 个体保全舱 `LIF-A`

目标：最大程度保留少量原个体。

代价：

- 人数极少；
- 需要大量定制；
- 个体仍发生结构损失；
- 难以维持完整文明。

### 43.2 人口重构群 `LIF-B`

目标：保存较大人口规模。

代价：

- 大幅统一身体和认知结构；
- 个体差异被压缩；
- 原有身份和文化细节丢失。

### 43.3 文明档案核 `CMP-C`

目标：保存知识、历史和语言。

代价：

- 不保存原个体；
- 需要后继生命重新解释；
- 数据完整不等于文明延续。

### 43.4 机器继承体 `LIF-D`

目标：以低维机器运行核心规则和部分人格模型。

代价：

- 群体意识和高维连接大量消失；
- 模拟人格不自动等于原个体；
- 计算能力随维度下降。

### 43.5 生态种子 `LIF-E`

目标：保存可在低维环境重新演化的生命系统。

代价：

- 原文明知识可能不被继承；
- 演化结果不可控；
- 后继生命不等于原文明复活。

### 43.6 规则核心 `GOV-F`

目标：保存最少量制度、价值和重建规则。

代价：

- 需要未知后继者执行；
- 规则可能失去语境；
- 无法保证未来文明接受。

# 第八部分　三维时代技术边界

## 45. 高维技术残迹

三维文明可能发现：

- 紧致化维度的异常尺度；
- 高维交通节点的失效残骸；
- 不符合三维自然形成过程的拓扑缺陷；
- 低维化文明留下的材料和信息核；
- 大规模二维化或其他降维区域；
- 无法完整解释的物理常数与遗迹。

这些残迹不能自动提供完整高维历史。

## 46. 三维降维武器

三维时代的降维武器仍属于真空相变技术，其特点是：

- 设备可能比旧宇宙早期显著小型化；
- 投送和触发更适合三维航行；
- 目标识别和参数封装更成熟；
- 泡壁依旧不可停止；
- 武器依旧会永久改变宇宙环境；
- 使用者仍必须承担低维区域扩张的长期后果。

本书不大篇幅复述原作武器细节，不为原作中所有技术给出唯一解释。

## 47. 坐标保护与静默技术

三维文明常用：

- 降低广播功率；
- 采用方向性通信；
- 分散或伪装发射源；
- 延迟发布坐标；
- 使用中继掩盖真实位置；
- 将重要设施迁移到低可见区域。

固定限制：

- 任何通信仍可能泄露统计特征；
- 完全静默会削弱协作和技术交流；
- 中继系统可能被追踪或欺骗；
- 长期隐藏不能保证不被独立观测发现。

## 48. 远程威慑技术

远程威慑依赖的不是绝对控制，而是让其他文明相信：

- 坐标或危险信息可能被传播；
- 报复能力可能在攻击后仍保留；
- 信息发布不完全受单一中心控制。

任何威慑系统都存在：

- 误判；
- 延迟；
- 节点失效；
- 授权争议；
- 被对方视为先发攻击准备的风险。

# 第九部分　小宇宙与质量归还技术

## 49. 小宇宙的定义 `COS-01`

小宇宙是从母宇宙中分离或弱连接出来的受控时空区域。

其技术目的包括：

- 避开母宇宙局部灾难；
- 保存有限生命、物质和信息；
- 获得相对独立的内部演化环境；
- 在三维宇宙末期提供长期避难。

## 50. 小宇宙的工程组成

一个可用小宇宙至少需要：

- 拓扑分离或弱连接结构；
- 出入口控制；
- 内部度规与能源管理；
- 物质迁移系统；
- 时间和坐标基准；
- 与母宇宙有限通信的接口；
- 失效时的质量回流方案。

## 51. 固定限制

小宇宙不能：

- 完整穿越量子反弹；
- 容纳无限物质；
- 脱离能量和熵约束；
- 保证入口永久存在；
- 让内部生命自动免于所有宇宙末期风险；
- 在不影响母宇宙的情况下无限抽取质量。

## 52. 母宇宙质量缺失

大量小宇宙带走质量后，会改变母宇宙整体演化条件。

此处固定采用：

- 单个小宇宙影响有限；
- 大量文明长期抽取产生累积效应；
- 是否归还质量成为文明伦理和生存冲突；
- 没有任何单个文明能独自补足全部质量。

## 53. 质量归还接口 `COS-02`

小宇宙必须保留能够将物质和能量重新耦合回母宇宙的接口。

归还过程需要：

- 重新确认母宇宙状态；
- 校准出入口；
- 释放内部物质；
- 避免局部能量集中造成额外灾难；
- 接受避难结构失效或永久关闭。

归还不是远程发送一串数据，而是实际归还质量。

## 54. 质量归还广播 `COM-COS`

广播内容至少包括：

- 母宇宙质量缺失问题的可验证证据；
- 归还质量对整体坍缩条件的影响；
- 小宇宙接口的通用校准方法；
- 分阶段归还时间窗口；
- 防止单点机构控制的多来源证明。

广播不能强制所有文明服从。

它的成功依赖：

- 足够多文明理解共同风险；
- 多个独立来源验证结论；
- 归还者接受自身避难空间可能消失；
- 没有任何文明能确认其他所有文明都会同时归还。

# 第十部分　十维回声工程

## 55. 回声计划的技术目标

回声计划不是保存旧宇宙数据库，而是在量子反弹后留下能够被新宇宙文明识别的低复杂度统计结构。

其目标分为四级：

1. 让后继宇宙发现“之前存在过一个宇宙阶段”；
2. 让其识别宏观空间维数曾连续下降；
3. 让其理解战争与防御共同推动了降维；
4. 提供足够的实验性证据，使警告不被视为纯粹神话。

第四级目标同时制造最大风险。

## 56. 回声工程组成

### 56.1 宇宙末期背景观测网 `COS-E01`

负责：

- 测量坍缩阶段的整体引力和拓扑状态；
- 识别哪些统计关系可能跨越量子引力阶段；
- 提供编码可用的全局边界条件。

限制：

- 不能直接观测量子反弹后的新宇宙；
- 只能基于理论估计信息存活概率；
- 观测范围随宇宙坍缩和因果范围缩小而下降。

### 56.2 拓扑关联调制器 `COS-E02`

负责：

- 在宇宙尺度关联结构中引入低复杂度模式；
- 调制无量纲比例和重复序列；
- 将信息分散到多个尺度和区域。

限制：

- 不能精确写入长文本；
- 调制过强可能被坍缩动力学抹除或引入不可控后果；
- 调制结果只保证统计倾向，不保证逐比特保存。

### 56.3 原初涨落编码器 `COS-E03`

负责：

- 将数学结构映射为可能在新宇宙原初引力涨落中留下的统计偏差；
- 设计跨尺度重复；
- 为不同宇宙初态提供容错版本。

限制：

- 旧宇宙文明无法直接控制新宇宙每一个局部涨落；
- 编码只能影响统计关系；
- 不存在可在新宇宙直接播放的普通文件。

### 56.4 多尺度纠错结构 `COS-E04`

负责：

- 在不同尺度重复同一整数、比例或因果关系；
- 让局部扰动不会摧毁全部信息；
- 为新宇宙解码者提供自然噪声检验。

固定规则：

- 第一层可由纯观测完成；
- 第二层需要长期统计重建；
- 第三层必须通过真实真空相变验证。

### 56.5 历史压缩与选择系统 `CMP-E05`

负责从旧宇宙历史中选择：

- 不可修改的因果链；
- 维度递减序列；
- 文明损失类型；
- 有限个人陈述；
- 可验证但不直接武器化的理论约束。

它必须删除：

- 大量具体人物和文明历史；
- 完整工程参数；
- 绝大多数文化和语言信息；
- 可直接制造战略武器的图纸。

## 57. 维因记录的技术格式

维因在回声中不以完整人格存在。

其信息被压缩为：

- 第一次实验关键决策节点；
- 边界模型中的错误假设；
- 事故后防御研究的失败结果；
- 知识公开与封锁的因果摘要；
- 极少量第一人称责任陈述。

新宇宙无法通过这些记录：

- 重建维因全部记忆；
- 与维因对话；
- 判断他每个私人动机；
- 复活或模拟一个被视为维因本人的完整人格。

## 58. 回声工程不能控制量子反弹

回声计划可以：

- 选择编码结构；
- 调节旧宇宙末期可控关联；
- 提高某些统计模式存活概率；
- 建立大量冗余。

它不能：

- 启动或停止量子反弹；
- 指定新宇宙在哪个位置出现文明；
- 保证新文明何时发现回声；
- 向旧宇宙接收回复；
- 让新宇宙自动理解旧宇宙语言；
- 保证警告被正确使用。

# 第十一部分　新宇宙回声观测与解码

## 59. 原初关联观测网络 `MET-N1`

弥娅所属的原初关联观测网络由多个文明共同维护，用于研究新宇宙原初引力背景。

### 59.1 组成

- 多尺度引力背景探测器；
- 长基线时空相关阵列；
- 高维传播模态观测站；
- 独立计量基准节点；
- 公共噪声模型仓库；
- 跨文明数据转换系统；
- 原始数据长期归档。

### 59.2 观测对象

网络测量：

- 原初引力涨落；
- 不同空间方向的相关谱；
- 超出普通因果接触范围的统计对应；
- 跨尺度重复结构；
- 可能由仪器和局部文明活动造成的污染。

### 59.3 固定限制

- 不能直接观看旧宇宙；
- 只能识别新宇宙初始条件中的残留统计结构；
- 单个节点不足以证明回声；
- 所有结果必须经过不同文明设备复核；
- 数据量巨大，任何结论依赖模型和长期统计。

## 60. 弥娅的技术职责

弥娅主要负责：

- 长程关联统计；
- 跨尺度纠错结构识别；
- 排除仪器同步和坐标转换误差；
- 建立“信号早于所有已知文明”的证据链；
- 将回声层级与可验证观测对应；
- 组织第三层理论结构的解码。

她不能独立：

- 控制全部观测节点；
- 删除所有原始数据；
- 授权第三层实验；
- 制造全部实验设备；
- 判断所有文明是否秘密复现技术。

## 61. 回声解码系统 `CMP-N2`

### 61.1 自然噪声排除层

用于：

- 比较不同宇宙学模型；
- 检验异常是否来自选择偏差；
- 分析仪器系统误差；
- 计算自然形成相同结构的概率。

### 61.2 跨尺度纠错层

用于：

- 寻找不同尺度重复的整数和比例；
- 重建局部缺失结构；
- 验证每层对上一层的校验；
- 区分编码结构与偶然模式。

### 61.3 历史骨架重建层

用于：

- 将递减维数序列与文明损失类型对应；
- 识别事件的因果顺序；
- 区分直接历史记录和后人压缩解释；
- 标注不确定内容。

### 61.4 实验见证层

用于：

- 提取低维相的可观测关系；
- 给出成核临界行为的范围；
- 预测特定传播模态如何消失；
- 判断真实实验结果是否符合回声。

它不能直接输出完整设备设计图。

## 62. 第一层解码技术

第一层通过以下证据联合成立：

- 异常横跨多个远超因果接触范围的区域；
- 多个独立设备获得一致结构；
- 结构具有低复杂度纠错模式；
- 信号统计年龄早于所有已知文明；
- 已知自然模型难以同时解释全部相关性。

第一层结论是：

> 当前宇宙的初始状态中存在来自前一宇宙阶段的人工统计结构。

它不直接证明完整维度战争史。

## 63. 第二层解码技术

第二层通过：

- 递减整数序列；
- 每个维数对应的传播自由度变化；
- 文明能力损失的压缩模式；
- 反复出现的“防御导致下一次下降”因果标记

重建旧宇宙历史骨架。

第二层不能提供：

- 每次战争的全部文明名单；
- 精确日期；
- 完整战场记录；
- 武器制造参数。

## 64. 第三层为何必须实验

第三层编码不包含一段可直接翻译的文字，而包含一组只有低维真空相真实形成后才会出现的关系。

纯数学分析可以得到多个候选模型，但无法区分：

- 一种自然真空现象；
- 一种抽象数学构造；
- 一种可制造的低维相；
- 一个故意误导后继宇宙的危险结构。

只有实验测得：

- 一个传播自由度真实消失；
- 模态谱变化符合预测；
- 泡壁具有自发扩张趋势；
- 临界行为落入回声给出的范围

才能完成第三层验证。

# 第十二部分　新宇宙第三层验证实验

## 65. 实验正式名称

第三卷中的实验正式名称为：

**第三层真空相验证实验。**

执行机构为：

**第三层验证联合组。**

不得在事故发生前将项目正式称为“新宇宙降维武器实验”。

## 66. 实验目标

实验只允许验证：

1. 维度模态能否被局部推入紧致态；
2. 回声预测的传播自由度损失是否出现；
3. 低维相是否具有自发扩张倾向；
4. 旧宇宙回声是否对应真实可实现物理。

实验不以测试以下内容为目标：

- 战略投送；
- 宏观扩张；
- 武器化目标选择；
- 大范围泡壁控制；
- 文明低维化。

## 67. 实验设施

实验设施必须包括：

### 67.1 微观成核腔 `VAC-N01`

提供极小、低噪声、低物质密度的成核区域。

### 67.2 多文明计量环 `MET-N02`

由不同文明设备同时测量，防止单一机构伪造结果。

### 67.3 分段模场激发器 `VAC-N03`

能源和控制被拆分为多个阶段，任何单一主体无法直接完成完整激发。

### 67.4 多层曲率梯度 `DEF-N04`

预先规定泡壁优先传播路径，并为闭合曲率陷阱提供几何条件。

### 67.5 非对称真空能井 `DEF-N05`

使成核区不同方向的相变代价不同，降低泡向关键设施扩张的概率。

### 67.6 本地自动中止系统 `GOV-N06`

在通信延迟使中央指令无效时，根据本地传感器自动切断激发、断开交通并启动曲率陷阱。

### 67.7 独立观测与证据节点 `COM-N07`

保存：

- 原始读数；
- 校准参数；
- 权限记录；
- 自动求援包；
- 事故前后模型版本。

这些节点是实验可信度的基础，也是数据无法彻底删除的原因之一。

### 67.8 牺牲区与永久缺陷区 `DEF-N08`

在最坏情况下允许：

- 放弃部分设施；
- 切断高维路径；
- 将低维泡限制在永久缺陷中；
- 牺牲仍未撤出的设备或人员。

## 68. 权限分离

实验权限必须至少拆分为：

- 理论模型批准；
- 设备校准批准；
- 能源分段授权；
- 成核窗口授权；
- 本地中止逻辑维护；
- 原始数据保管；
- 对外事故通报。

弥娅、赫森、伊蓝都不能单独完成全链路操作。

### 弥娅

能够：

- 提交理论模型；
- 解释观测目标；
- 参与结果判断；
- 建议中止阈值。

不能：

- 独自供能；
- 绕过多文明授权；
- 删除全部记录。

### 赫森

能够：

- 提出安全条件；
- 要求权限隔离；
- 启动紧急封锁程序；
- 调用事故调查和异常监测网络。

不能：

- 修改物理结果；
- 远程瞬时终止已经成核的泡；
- 代表所有文明永久封锁知识。

### 伊蓝

能够：

- 要求多文明见证；
- 审核证据链；
- 维护公共验证副本；
- 反对单一机构垄断原始结论。

不能：

- 在实验前公开全部工程参数；
- 单方面释放所有安全数据；
- 保证公开信息不会被拼接使用。

## 69. 复合失控机制

实验失控必须由以下因素共同构成：

1. 回声只提供统计范围，不提供完整真空势参数；
2. 多文明计量基准转换保留微小系统偏差；
3. 目标维度模态与邻近模态发生交叉耦合；
4. 非对称真空能井改变了泡的取向；
5. 自动中止切断外部激发时，泡已经跨过局部临界尺度；
6. 初始安全场降低了一个方向的扩张，却提高了另一方向的稳定性；
7. 部分观测节点因保护机制延迟共享原始读数。

没有任何一个因素单独足以造成事故。

## 70. 事故限制过程

事故限制按以下顺序发生：

1. 模场激发被切断；
2. 交通连接进入隔离状态；
3. 泡壁监测确认扩张未停止；
4. 多层曲率梯度提高关键区域方向的传播代价；
5. 真空能井将泡引向预定牺牲区；
6. 若干高维连接被永久切断；
7. 泡沿闭合曲率路径进入陷阱；
8. 陷阱收缩为稳定但不可恢复的低维缺陷；
9. 实验设施和部分人员或设备损失；
10. 缺陷区域被永久隔离和持续监测。

正文必须明确：

- 泡没有被“消灭”；
- 受影响区域没有恢复；
- 成功的是限制扩张，而不是逆转降维；
- 方案无法扩展到宏观战争。

## 71. 事故数据为何无法彻底销毁

数据分布在：

- 多文明计量环；
- 本地自动中止日志；
- 原始观测节点；
- 能源授权记录；
- 自动求援广播；
- 设备制造和校准档案；
- 参与者各自的模型副本；
- 公共见证系统的校验摘要；
- 事故后独立调查数据。

即使删除中央数据库，其他主体仍可从不完整数据中重建部分理论。

泄露不得归因于单一内鬼窃取一份“完整武器图纸”。

# 第十三部分　新宇宙安全监测技术

## 72. 异常真空活动监测网 `DEF-N1`

赫森可推动建立跨文明异常监测系统，主要检测：

- 高密度模场激发；
- 真空涨落异常集中；
- 特殊曲率设施建设；
- 大规模低噪声成核区；
- 特定高维材料调配；
- 已知泡壁观测特征；
- 交通和能源系统的危险组合。

## 73. 监测网的能力

监测网可以：

- 对已知技术路径进行风险评分；
- 识别部分大规模实验准备；
- 向成员文明发出联合检查请求；
- 关联多个不完整信号；
- 在发生异常后快速共享观测结果。

## 74. 监测网的固定限制

监测网不能：

- 实时覆盖整个宇宙；
- 进入未授权文明的所有设施；
- 从单一异常确定研究意图；
- 区分所有自然真空现象和人工实验；
- 发现尚未出现可测特征的纯理论研究；
- 保证成员文明如实上报；
- 阻止秘密文明独立推导技术；
- 在泡壁成核后从远方瞬时关闭它。

## 75. 风险评分系统 `DEF-N2`

风险评分综合：

- 能源密度；
- 模态匹配程度；
- 设施几何；
- 材料流向；
- 研究者历史；
- 数据访问模式；
- 文明是否拒绝检查。

固定风险：

- 合法研究可能被高估；
- 拒绝监控不等于正在制造武器；
- 评分模型会继承委员会的最坏情况偏见；
- 被监控文明会改变行为，使后续数据更加不可信；
- 评分可能成为先发制人干预依据。

## 76. 强制干预技术

安全委员会可在成员授权范围内使用：

- 切断共享能源接口；
- 暂停公共交通节点访问；
- 撤销高风险设备的跨文明校准证书；
- 隔离公共数据和制造服务；
- 派出检查节点；
- 对正在成核的设施实施局部破坏。

固定限制：

- 只能影响依赖公共基础设施的研究；
- 独立文明可以脱离网络；
- 破坏成核设施必须发生在低维泡形成前；
- 错误干预会强化其他文明对委员会的不信任；
- 委员会不存在全宇宙主权。

## 77. 降低广播技术

赫森最终降低自身文明广播功率时，可以采用：

- 减少全向广播；
- 提高方向性；
- 缩短公开坐标有效期；
- 通过多级中继隐藏核心位置；
- 将研究和居住节点拆分；
- 降低公共交通节点暴露的信息。

代价包括：

- 科学合作效率下降；
- 边缘成员与中心失联风险上升；
- 其他文明将这一行动解读为防御或敌意；
- 监控体系获得更多保密权限。

# 第十四部分　开放科学与公共验证技术

## 78. 开放科学协作网 `COM-N3`

伊蓝所代表的开放科学协作网不是一个中央数据库，而是由多个文明维护的：

- 模型复算服务；
- 来源和版本记录；
- 参数访问分层；
- 异议和复核通道；
- 防篡改证据摘要。

## 79. 公共验证与工程复现的分离

技术上必须把信息分为四层。

### 79.1 事实层

公开：

- 旧宇宙存在证据；
- 维度递减历史；
- 实验确实产生低维相；
- 事故和永久缺陷的观测结果。

### 79.2 观测层

公开：

- 经脱敏的原始读数；
- 计量基准；
- 仪器误差模型；
- 多文明复核结果；
- 不涉及成核控制的分析方法。

### 79.3 理论约束层

有限公开：

- 可验证的临界关系；
- 维度模态变化范围；
- 不含具体真空势的数学结构；
- 风险下界和不可逆结论。

### 79.4 工程参数层

继续封锁：

- 真空势具体参数；
- 成核阈值和能量波形；
- 模场激发器结构；
- 各向异性边界算法；
- 泡壁引导和武器化方法；
- 设备材料与制造配置。

## 80. 分层证据包 `COM-N4`

有限公开方案使用“分层证据包”发布信息。

每个证据包包括：

- 来源说明；
- 时间和计量基准；
- 数据完整性摘要；
- 可公开观测数据；
- 独立复算方法；
- 被删除或封锁字段的类别说明；
- 多机构签署的风险记录；
- 争议和不确定项。

分层证据包不能保证工程参数永远无法被推导，只能提高验证历史所需的信息量，同时降低直接复制装置的便利性。

## 81. 公共回声验证网络 `COM-N5`

### 81.1 主要职责

- 保存第一层和第二层回声的公共证据；
- 验证第三层实验确实发生；
- 保存事故损失和不可逆性记录；
- 允许不同文明复算非武器化结论；
- 防止任何单一机构修改旧宇宙历史；
- 发布结尾异常的多模型观测结果。

### 81.2 网络结构

网络采用：

- 多文明镜像；
- 分区数据；
- 版本链；
- 交叉校验；
- 独立噪声模型；
- 延迟公开策略；
- 风险字段审计。

### 81.3 固定缺陷

- 不完整数据可被不同文明拼接；
- 长期独立研究可能重新推出封锁参数；
- 镜像越多，统一删除越不可能；
- 延迟公开会被部分文明视为垄断；
- 完全公开会降低武器研发门槛；
- 网络无法保证所有成员永远诚实。

## 82. 伊蓝的技术职责

伊蓝主要负责：

- 设计公共证据的可复算结构；
- 组织跨文明镜像和版本校验；
- 证明历史真实性不依赖安全委员会单一声明；
- 维护公开层与工程层之间的边界；
- 为被封锁字段建立类别和审计记录。

他不能：

- 保证公开永远不会促进独立研发；
- 单独决定全部参数释放；
- 证明所有秘密研究已经停止；
- 让透明自动转化为信任。

# 第十五部分　有限公开技术方案

## 83. 技术目标

有限公开方案同时追求：

1. 让所有文明能够确认旧宇宙历史没有被伪造；
2. 让所有文明能够确认降维不可逆且具有宇宙性风险；
3. 防止安全委员会永久垄断历史；
4. 不直接提供可复制的成核设备和武器参数；
5. 保留未来研究和风险复核的最低公共基础。

## 84. 公开技术内容

固定公开：

- 回声第一层和第二层解码方法；
- 宏观空间维度递减序列；
- 每次降维造成的能力损失；
- 第三层实验的存在和伦理决策记录；
- 低维相观测特征；
- 泡壁自发扩张与宏观不可逆结论；
- 实验事故完整风险与损失；
- 不涉及具体成核参数的复核方法；
- 永久缺陷的持续观测结果。

## 85. 继续封锁的技术内容

固定封锁：

- 维度模场的精确激发频谱；
- 真空势具体参数；
- 泡成核阈值；
- 各向异性边界阵列控制序列；
- 可部署成核平台结构；
- 低维种子制造方法；
- 曲率引导的可扩展军事化算法；
- 高能设备配置和材料配方；
- 提高宏观成核可靠性的工程数据。

## 86. 技术封锁的现实边界

有限公开不能保证：

- 所有文明永远无法独立发现相同理论；
- 已泄露的实验数据被全部收回；
- 参与实验者忘记知识；
- 所有安全机构不保留秘密副本；
- 公共观测不会被用于反向推导；
- 未来技术进步不会降低复现门槛。

其真实作用是：

> 延长从“确认危险存在”到“获得稳定武器工程”的时间，并让任何声称掌握历史或风险的机构必须接受公共复核。

## 87. 三人对技术方案的不同接受理由

### 弥娅

接受原因：

- 历史必须可验证；
- 完整理解本身会制造危险；
- 科学责任不等于公开所有工程细节。

### 赫森

接受原因：

- 全面删除已经不可能；
- 公共风险记录有助于降低无知实验；
- 参数封锁仍保留安全缓冲。

### 伊蓝

接受原因：

- 历史和验证权不被单一机构垄断；
- 被封锁字段必须公开说明类别并接受审计；
- 延迟公开优于秘密永久化。

# 第十六部分　结尾异常观测系统

## 88. 空间自由度异常监测 `MET-NG`

全书结尾的遥远异常由多个独立观测系统共同发现。

可观测特征包括：

- 某类粒子在一个传播方向上的模态减少；
- 局部引力相关谱偏离背景；
- 高维路径在异常边缘失配；
- 异常边界缓慢变化；
- 内部直接信号不足；
- 没有完整人工能量调制记录。

## 89. 三种解释为何都保留

### 89.1 自然真空相变

支持证据：

- 缺乏明确设施和能源输入；
- 初始形状可能符合罕见自然涨落；
- 新宇宙真空稳定性仍不完全已知。

### 89.2 受控实验

支持证据：

- 某些取向和边界变化接近工程模型；
- 区域附近可能存在未登记文明；
- 已知数据已经足以支持秘密研究。

### 89.3 第一次降维攻击

支持证据：

- 异常可能位于文明活动区；
- 边界扩张与旧宇宙武器记录相似；
- 部分文明已开始隐藏和降低广播。

## 90. 不得提供的确定性证据

结尾不得出现：

- 可识别的攻击者签名；
- 完整设备残骸；
- 明确承认攻击的广播；
- 足以排除自然相变的能量记录；
- 足以证明受控实验的权限日志；
- 弥娅或任何系统给出百分之百结论。

观测技术越先进，只能缩小可能性范围，不能消除故事要求保留的不确定性。

# 第十八部分　技术场景写作规范

## 96. 科学说明必须进入行动

技术说明必须至少完成一项功能：

- 改变人物是否启动设备；
- 决定哪些人能够撤离；
- 解释某项控制为何失败；
- 迫使文明删减信息或生命；
- 改变安全机构权限；
- 证明某段历史可信；
- 暴露公开或封锁的真实代价；
- 修正读者对前文技术的理解。

不得连续介绍与当前选择无关的设备参数。

## 97. 技术场景的最低结构

任何关键技术场景至少包含：

1. 当前目标；
2. 一个可测状态；
3. 一个限制或误差；
4. 一个需要人物作出的选择；
5. 一个无法同时避免的代价；
6. 一个对后续产生影响的结果。

## 98. 实验场景

实验场景应优先描写：

- 仪器之间为何出现微小不一致；
- 人物如何解释数据；
- 是否继续提高能量；
- 中止阈值由谁决定；
- 自动系统和人工判断如何冲突；
- 实验记录由谁保存；
- 失败后哪些区域和人员被放弃。

减少：

- 纯倒计时；
- 单纯按钮操作；
- 依靠灯光颜色代替数据含义；
- 让一个人瞬间理解所有异常。

## 99. 高维交通场景

必须通过具体效果表现高维交通：

- 低维投影距离与完整路径距离不同；
- 路径需要节点、测绘和坐标转换；
- 多条路径可能在三维投影中相交却实际不接触；
- 节点故障会改变文明的实际邻接关系；
- 降维使某些路径从“很近”变为“永远无法到达”。

不得直接写“进入高维后瞬间抵达”。

## 100. 降维场景

应描写：

- 传播自由度和连接方式减少；
- 仪器模型无法闭合；
- 材料和生命因结构不可嵌入而失稳；
- 泡壁前后的信息不对称；
- 撤离、保留和牺牲选择；
- 相变没有爆炸式中心冲击却造成永久环境改变。

不得把每次降维都写成相同的视觉压扁。

## 101. 技术辩论场景

辩论必须围绕可执行选项，而不是抽象口号。

例如：

- 是否公开某类原始读数；
- 是否允许其他文明复算；
- 谁能修改中止阈值；
- 哪些设备必须拆除；
- 监测系统能否读取私人实验能源；
- 封锁字段由谁审计；
- 结尾异常是否足以触发干预。

每一方必须说明其方案无法消除的风险。

## 102. 技术造成情感的方式

人物情感优先通过以下动作表现：

- 维因删除恢复序列中的一个虚假安全指标；
- 弥娅把一组足以继续推导的参数移入封锁层；
- 赫森关闭一个开放交通接口以换取监测盲区减少；
- 伊蓝保存一份只证明事故发生、却不能直接复现实验的证据包；
- 某文明在低维映射中放弃一种感官或人格分支；
- 实验团队切断仍连接着人员的高维路径。

6. 不只是为了临时解决当前章节困境；
7. 至少在出现前有理论、设备、资源或制度铺垫；
8. 不产生无代价超光速、无限能源、全知监控或宏观逆降维；
9. 不使某个角色单独控制宇宙尺度能力；
10. 不破坏结尾异常的不确定性。

# 第二十部分　禁止使用的技术设定

## 105. 全书禁止项

不得出现：

1. 可随身携带并无准备摧毁整个宇宙的个人降维武器；
2. 无能源、无设备、无传播过程的维度控制；
3. 能够在宏观尺度停止并恢复低维真空泡的护盾；
4. 自动识别敌我、只摧毁目标文明的降维技术；
5. 无代价超光速通信或传送；
6. 利用量子纠缠直接发送普通信息；
7. 无限能源、永动机或凭空产生物质；
8. 完整意识脱离物质永久存活；
9. 通过备份让人物无限复活且无身份代价；
10. 完整数据库、飞船或人物穿越量子反弹；
11. 文明启动装置直接控制宇宙反弹；
12. 单个安全机构实时监控全宇宙所有研究；
13. 一次命令删除所有文明中的危险知识；
14. 公开某个算法便自动建立跨文明信任；
15. 通过“更高级维度”解释一切未知现象；
16. 临时发明更强武器解决既有降维危机；
17. 没有准备设施便精确引导宏观低维泡；
18. 小宇宙不消耗母宇宙质量；
19. 回声包含完整武器图纸或可交互人格；
20. 结尾观测系统直接确认异常来源。

## 106. 不得使用的技术叙事捷径

不得通过以下写法绕过工程过程：

- “计算机很快算出了唯一答案”；
- “人工智能预测了所有文明选择”；
- “高维设备自动修复了一切”；
- “系统没有记录，所以知识已经消失”；
- “量子加密绝对不可破解，因此制度风险消失”；
- “设备由远古文明制造，所以无需解释限制”；
- “维因早已秘密准备好解决方案”；
- “弥娅凭直觉找到了正确参数”；
- “赫森通过权限关闭了宇宙中的所有实验”；
- “伊蓝公开数据后所有文明停止猜疑”。

任何包含重要技术的章节进入正式稿前，检查：

1. 当前技术属于哪个分类和成熟度？
2. 它在当前纪元是否已经存在？

10. 是否把微型限制扩展成宏观防御？
11. 是否说明技术的可观测痕迹？
12. 是否说明至少一种失效模式？
13. 是否说明技术代价由谁承担？
14. 是否让某个核心人物单独掌握完整技术链？

19. 是否使公开与封锁冲突失去意义？

## 108. 降维技术专项检查

1. 成核区域是否经过测绘？
2. 目标维度取向是否是局部本征方向？
3. 装置是否包含测量、激发、边界和监测功能？
4. 泡是否越过临界尺度？
5. 控制能力是否与泡尺度相符？
6. 泡壁是否接近但不超过局部光速？
7. 预警信息是否能在泡壁到达前返回？
8. 物质和生命损失是否符合当前维度差异？
9. 防御是否制造新的真空或文明代价？
10. 事故是否由多因素共同形成？

## 109. 信息技术专项检查

1. 数据来自哪些物理记录？
2. 是否存在多个副本和缓存？
3. 删除是否真的覆盖所有主体？
4. 是否误用量子纠缠保存可读信息？
5. 公开内容是否区分事实、观测、理论和工程参数？
6. 验证权是否被误写成制造权？
7. 安全封锁是否具备审计和权限来源？
8. 公共网络是否仍存在拼接和独立推导风险？
9. 回声内容是否超过低带宽限制？
10. 是否保留必要的不确定性？

# 第二十二部分　不可修改的技术结论

## 110. 固定结论

以下结论不得修改：

1. 高维交通通过较短高维测地线工作，不突破局部光速。
2. 高维交通依赖测绘、节点、坐标转换和持续维护。
3. 维度工程必须包含测量、模场激发、边界、曲率、成核和监测系统。
4. 第一次人工降维是文明级大型工程，不是个人实验。
5. 局部维度闭锁系统的原始目标是隔离，不是灭绝。
6. 维因主要负责边界条件、曲率兼容和恢复序列，不是全部技术的唯一发明者。
7. 真正成核后，关闭装置不能关闭低维泡。
8. 泡越过临界尺度后会自发扩张。
9. 军事化只能提高成核、投送和部署能力，不能改变相变基本性质。
10. 降维武器不能识别敌我，也不能在完成任务后自动关闭。
11. 降维防御分为预防、侦测、逃逸、引导和适应，没有无损恢复层。
12. 阻止低维泡通常要求制造另一种低维或不同取向真空相。
13. 主动低维化必然删除身体、感知、记忆、计算或制度结构。
14. 每次维数下降必须破坏不同的技术基础能力。
15. 小宇宙会从母宇宙带走有限质量，并影响整体演化。
16. 质量归还必须实际把物质和能量重新耦合回母宇宙。
17. 回声计划只能调制统计结构，不能控制量子反弹。
18. 十维回声不包含完整数据库、人格或直接武器图纸。
19. 第一层回声由观测验证，第二层重建历史骨架，第三层必须通过真实实验验证。
20. 弥娅依赖多文明原初关联观测网络，不能独自控制全部数据。
21. 第三层实验必须由多文明权限分离系统执行。
22. 第三层实验事故由多项合理误差共同造成，不是单一低级失误。
23. 闭合曲率陷阱只能限制预设环境中的微型泡，并留下永久低维缺陷。
24. 实验数据因多文明计量、自动求援和分布式记录而无法彻底删除。
25. 赫森的监测系统只能覆盖成员和可观测活动，不能全宇宙全知。
26. 伊蓝的公共网络能够验证历史，却不能保证危险知识永不扩散。
27. 有限公开必须区分事实、观测、理论约束和工程参数四层。
28. 有限公开只能延长武器化时间，不能永久阻止独立发现。
29. 四名核心人物都不能单独掌握完整降维技术链。
30. 全书结尾的观测技术不能唯一确认异常属于自然现象、实验或攻击。

# 第二十三部分　与其他 Canon 文件的接口

## 111. 与 `canon/01-physics-rules.md` 的接口

本文件所有技术必须服从：

- 局部因果和光速限制；
- 维度模场与真空相变机制；
- 低维泡近光速扩张；
- 宏观降维工程不可逆；
- 微型限制不等于恢复；
- 主动低维化的信息损失；
- 量子反弹不可由文明控制；
- 回声低带宽和统计性载体。

物理文件定义“能否发生”，本文件定义“文明如何尝试实现以及为何失败”。

## 112. 与 `canon/02-universe-timeline.md` 的接口

技术成熟必须与纪元一致：

- 高维基础设施在 `O-A` 已成熟；
- 局部维度闭锁系统在 `O-B` 完成第一次真正成核；
- 军事化和防御技术在 `O-C`、`O-D` 扩散；
- 连续低维化技术随 `S8→S3` 逐步重构；
- 小宇宙和质量归还属于 `O-F`、`O-G`；
- 回声工程完成于 `O-G`；
- 原初关联观测和解码发生于 `N-C`、`N-D`；
- 第三层实验和数据泄露发生于 `N-E`；
- 监测、公开和有限公开制度发生于 `N-F`、`N-G`；
- 结尾异常观测不得早于 `N-G07`。

## 113. 与 `canon/03-characters.md` 的接口

技术不得改变人物弧线：

- 维因必须因合理工程模型犯错，而非恶意制造武器；
- 弥娅必须通过观测和验证逐步接近真相，不能凭直觉直接解码；
- 赫森拥有现实监测工具，但不能成为全知独裁者；
- 伊蓝拥有公共验证技术，但不能让开放自动消除风险；
- 三人共同参与第三层实验和有限公开，但任何人都不拥有全部权限；
- 技术必须让人物承担选择，而不是替人物作出正确答案。

## 114. 与 `canon/04-civilizations.md` 的接口

- 联径共同体维护高维交通和共享坐标基础；

## 120. 最终技术结论

《十维回声》中的技术不是比文明更高的独立力量。

它始终由以下部分共同构成：

- 可被验证但不能被完全控制的物理规律；
- 有限精度、有限能源和有限因果范围的工程；
- 必须协作又无法绝对互信的文明网络；
- 会被复制、删减、误读和重新组合的知识；
- 需要具体人物承担后果的选择。

维因的技术失败，不是因为工程毫无价值，而是因为一旦新真空相形成，边界便不再属于装置。

弥娅的实验危险，不是因为理解历史本身邪恶，而是因为可信的物理警告必须允许现实验证。

赫森的监测无法带来绝对安全，因为技术活动可以被分散，而监控会推动文明隐藏。

伊蓝的公共验证无法带来绝对信任，因为足够公开的证据也可能成为独立重建技术的起点。

技术能够延长选择时间、改变风险分布、保存部分历史。

它不能替文明作出选择，也不能替文明承担选择的后果。
