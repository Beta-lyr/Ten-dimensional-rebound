# Ten-dimensional-rebound

《十维回声》是一部长篇硬科幻小说项目。

故事横跨两个宇宙周期：旧宇宙从完整十维时空逐步跌落至三维，新宇宙在量子反弹后重新开始，并发现了旧宇宙留下的警告信息。

旧宇宙试图留下避免毁灭的经验，但解读这份经验本身，可能使新宇宙重新获得降维武器。

## 项目定位

* 类型：硬科幻、宇宙文明、维度战争
* 结构：三卷长篇
* 核心人物：维因、弥娅、赫森、伊蓝
* 核心主题：知识传播、文明安全、黑暗森林与历史循环
* 创作性质：非官方、非商业同人外传

本项目使用原创人物、原创情节和原创表达，不复制原作正文，也不改写原作主要人物的既定结局。

## 三卷规划

1. 第一卷《第十个方向》
2. 第二卷《诸维之墓》
3. 第三卷《重启之后》

### 目录职责

| 目录            | 用途                           |
| ------------- | ---------------------------- |
| `canon/`      | 保存正式世界观、物理规则、人物设定与技术约束       |
| `outlines/`   | 保存全书总纲、卷级大纲、章节地图与章节细纲        |
| `manuscript/` | 保存小说正式正文与每卷写作记录              |
| `research/`   | 保存现实科学资料、未证实理论与小说外推          |
| `revisions/`  | 保存待确认事项、连续性问题和修订记录           |
| `drafts/`     | 保存废稿、备选大纲和写作实验               |
| `assets/`     | 保存封面、示意图和时间线资源               |
| `exports/`    | 保存导出的 Markdown、EPUB 和 PDF 文件 |

### 文件优先级

项目内容发生冲突时，按照以下优先级处理：

```text
canon/00-series-bible.md
    ↓
canon/ 中的专项设定
    ↓
outlines/00-master-outline.md
    ↓
卷级大纲
    ↓
章节地图
    ↓
章节大纲
    ↓
小说正文
    ↓
草稿与临时笔记
```

低优先级内容不得擅自修改或覆盖高优先级设定。


## 写作原则

1. 正文必须服从 `canon/` 中的设定。
2. 每章正文必须先有对应章节大纲。
3. 新技术必须说明原理、限制和代价。
4. 不使用超自然力量解释科学现象。
5. 不把高维文明写成全知全能的神。
6. 不通过临时新增技术解决既有困境。
7. 科学资料应记录来源和最后检查日期。
8. 废弃内容不得直接成为正式设定。

## 设定优先级

发生冲突时，按照以下顺序处理：

1. `canon/00-series-bible.md`
2. `canon/` 中的专项设定
3. `outlines/00-master-outline.md`
4. 卷级大纲
5. 章节大纲
6. 小说正文
7. 草稿和临时笔记

低优先级内容不得擅自修改高优先级设定。
