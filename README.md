# Ten-dimensional-rebound

《十维回声》长篇硬科幻小说项目。

故事横跨两个宇宙周期：旧宇宙从完整十维时空逐步降至三维；量子反弹后，新宇宙重新开始，并发现旧宇宙留下的警告信息。

## 三卷规划

1. 第一卷《第十个方向》
2. 第二卷《诸维之墓》
3. 第三卷《重启之后》

## 目录

- `canon/`：正式设定与最高约束
- `outlines/`：全书、卷级和章节大纲
- `manuscript/`：正式正文
- `research/`：现实科学资料与科幻外推
- `revisions/`：待确认事项和一致性检查
- `drafts/`：废稿与备选方案
- `assets/`：封面、图表和时间线
- `exports/`：导出文件
